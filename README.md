# ExcelLens 1.17.1

ExcelLens 是面向高性能阅读设计的 Windows 表格与数据查看工具。它适合打开大型明细表、财务台账和数据库导出文件，在同一个界面里完成浏览、查找、核对与分析。

程序围绕大表阅读组织数据：首次打开时建立索引，滚动和定位时按显示区域读取，重新打开文件时复用缓存。原文件保持原样，批注、计算表和分析设置保存在独立的本机工作区。

通过预检的 CSV、TSV、XLSX 和 XLSM 可在原工作表布局内编辑副本。在网格里可拖动填充柄、从 Excel 或另一标签页粘贴公式和合并区域，也可复制整张工作表。在表尾追加明细时，计算列和汇总行随之更新。透视布局支持多值汇总、标签和日期筛选、日期分组及关联图表刷新。修改可撤销、重做，并保存为独立文件。 [编辑副本](docs/user/editing.md)

1.17.1 将数据库快照独立留存，支持离线核验、加密备份和迁移。XLSB 源码测试自带 Excel 同源样本和兼容性矩阵。[本版说明](docs/releases/1.17.1.md)

## 下载与使用

1. 解压完整包；已公开的版本可从[发行页](https://github.com/habacat/ExcelLens/releases)下载。
2. 运行 `ExcelLens.exe`，选择文件或将文件拖入首页。
3. 选择工作表，索引完成后即可浏览、搜索、筛选和分析。

支持 Windows 10/11 x64。程序通过本机页面展示数据，托盘菜单可以重新打开界面和管理缓存。

## 阅读大表

ExcelLens 把文件索引、数据读取和界面绘制分开处理。界面加载当前需要显示的行列，打开过的文件可以继续使用已有索引；大范围筛选和排序则借助磁盘组织结果。这样既方便反复查阅同一份资料，也能在大表中跳转、筛选后继续阅读。

阅读界面提供多工作表切换、冻结行列、合并单元格、图片和超链接。宽表可以用记录卡片逐条查看，也可以从名称目录、搜索结果或分析结果跳回原单元格。“查找功能”随窗口宽度伸缩，按 `Ctrl+K` 可以查找功能或工作表。

## 大表实测

1.16.0 发行候选在 Windows 10 x64、i7-9750H、64 GB 内存和无头 Chrome 上打开合成文件。每种规模使用新的程序和索引，每组测量一次。首格计时从浏览器选定文件开始，索引计时从发起请求到收到完成响应。

| 格式 | 行数 | 首个可见数据格 | 索引请求至完成 | 服务峰值工作集 |
| --- | ---: | ---: | ---: | ---: |
| CSV | 100 万 | 0.71 秒 | 0.67 秒 | 168.8 MiB |
| CSV | 500 万 | 2.60 秒 | 2.62 秒 | 212.5 MiB |
| CSV | 1000 万 | 5.86 秒 | 4.97 秒 | 211.1 MiB |
| XLSX | 10 万 | 1.00 秒 | 0.67 秒 | 31.7 MiB |
| XLSX | 50 万 | 0.64 秒 | 3.34 秒 | 71.1 MiB |
| XLSX | 100 万 | 0.72 秒 | 5.34 秒 | 127.0 MiB |

500 万行 CSV 有 50,000 个机构匹配项。从提交全量查询至返回完成状态用时 5.53 秒，流式导出并逐条核对坐标用时 0.14 秒。连续滚动 60 秒记录 50.7 FPS，P95 帧间隔 35.8 毫秒，空白帧 0 个。更多场景与原始记录见[发行基准](docs/development/reading-benchmarks.md)。

## 支持格式

| 格式 | 内容 |
| --- | --- |
| XLSX、XLSM、XLSB | Excel 工作簿，XLSB 支持原生只读 |
| ODS | OpenDocument 电子表格，支持按源坐标只读核查 |
| XLS | Excel 97–2003工作簿、Office/WPS导出的HTML表格 |
| CSV、TSV、TXT | 分隔文本和数据库导出报表 |
| SQLite | 数据库中的表 |
| ZIP、7z、RAR、TAR、GZ、BZ2、XZ | 打开压缩包后选择其中的文件 |

通过「打开 → 在线数据库」可连接 MySQL、MariaDB、PostgreSQL、Oracle、SQL Server 和 ClickHouse。所选表或视图在同一个工作簿网格中打开。 [连接和读取说明](docs/user/formats.md#在线数据库)

各格式的读取、布局和导出说明见[格式说明](docs/user/formats.md)。

## 查找、核对与分析

- **查找和筛选**：全文搜索、正则查找、条件筛选、多级排序和自然排序，结果保持原单元格位置。
- **表间核对**：双表对账、多表追加、关联与未匹配提取，适合对齐字段、比对名单和整理明细。
- **数据分析**：分组汇总、层级透视、占比累计、分布与分位数、疑似重复文字核对，以及选区快速分析。
- **计算和导出**：精确数值计算、独立计算表、选择性复制、数据导出和PNG/SVG图表导出。
- **保存工作步骤**：命名视图、分析方案、比较快照，以及查询和导出的任务恢复。
- **阅读辅助**：记录卡片、单格解释、名称目录、数据规则、局部转置和分页预览。

具体入口和操作见[用户文档](docs/README.md)。

## 开发

Go工具链版本见[go.mod](go.mod)，开发检查使用Node.js 22+，Windows发布构建使用UPX。依赖源码随`vendor/`提供。

```powershell
go run ./tools/project check
.\build.ps1
```

构建完成后，完整包和校验文件位于`release/`。工程结构和验证流程见[贡献指南](CONTRIBUTING.md)及[架构说明](docs/development/architecture.md)。
