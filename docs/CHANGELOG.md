# ExcelLens 1.8.20 — 长表滚动修复（2026-11-17）

- 修复百万行文本表格上下滚动时多行重叠、部分区域间歇空白的问题；每次滚动从公共数值行几何重新计算，避免浏览器CSS坐标字符串的舍入误差。
- 保留源值、类型、坐标、只读语义和缓存编码；缓存内细滚动不增加数据读取。
- 修改前已在2907951行合成TXT复现，修复后70%/100%/125%及冻结六组合、360次细滚动自动化通过。完整标准、构建及验收边界见[版本记录](releases/1.8.20.md)。

# ExcelLens 1.8.19 — 只读分析增强与稳定性优化（2026-11-17）

- 首页作者署名更新为`Qiu Sheng`。
- 修复右键菜单被彩色Sheet标签遮挡；固定菜单及提示与网格隔离层分开，点击仍落在菜单。
- 修复切回冻结工作表时重复刷新互相取消、误报整表读取失败；相同读取复用在途任务，真实错误继续保留，原文件验证不变。
- 工具栏按实际空间保留常用操作，低频功能从命令面板进入；小窗口保留字号和必要分行，命令浏览超过30项后也始终显示当前选择。
- 完善完整筛选、外部排序和自然排序；双表对账、多表追加和关联提取保留精确值、源类型及原格追溯。
- 新增层级透视、占比累计、选区快速分析、全量精确分布、疑似重复原文核对，以及分析方案和比较快照。
- 阅读提供名称目录、宽表记录卡片、单格解释、只读数据规则、局部转置和分页预览；支持选择性复制及PNG/SVG图表导出，模板与结果卡片随容器自适应。
- 查询和六格式导出恢复绑定原来源、规则及完整确认点，由用户明确继续。集中优化关联CSV/ZIP、任务历史和资源回收，修复取消搜索立即重试和旧来源请求。
- 本版验证、构建及未覆盖边界见[版本记录](releases/1.8.19.md)，接续工作以[实施进度](development/improvement-progress.md#接续入口)为准。源文件编辑和保存继续暂缓，不新增XLSB。
