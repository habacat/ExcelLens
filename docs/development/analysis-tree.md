# 按需层级透视

F08底层和界面已实现。当前开发树仍为1.8.18，尚未发布。底层当前层聚合、展开任务、来源绑定、前缀下钻及持久化边界已有完整标准/竞态、百万CSV和真实HTTP专项证据；界面及新增数字显示设置的整包验证单独记录，不能沿用底层收据宣称界面通过。状态见[实施进度](improvement-progress.md)。

## 聚合与路径

`analysis.Query.layout="tree"`声明层级布局，行维度仍为1至3个有序字段。旧查询省略layout，平铺语义不变。普通`Run`在层级模式只计算首层；`RunTreeLevel`接受父级的精确文字路径，复用同一转换、筛选、类型、十进制、诊断和累加器。每条记录只运行一次显式转换；路径不编码成新增筛选，因此不会占用8项分析筛选容量，也不把星号、空白或冒号解释为特殊条件。

每次只分组至当前层，不创建未展开后代、全表行号向量或整棵分组树。普通层级读取只请求当前分组、指标、筛选及显式转换需要的字段；分析方案重放另外读取所有已声明绑定，维持完整输入类型守卫。源数值、源类型、前导零、公式缺缓存和源坐标不变，不新增日期检测。

父级平均值、去重、最小/最大值及各列合计均从同一范围的源记录重新聚合，不把子级平均值或去重数相加。`Result.tree`携带父路径、总层数及是否还有下一层，`rowFields`和行键描述实际计算的当前层。排序及前N项在每层独立应用，合计仍覆盖该父级全部纳入记录；原有每层5000分类、32列、20000指标格、去重及256MiB工作预算继续约束，超限明确失败，不改为采样。

## 任务与资源

`POST /api/analysis/tree/start`接收已完成根任务的`jobId`、`workbookKey/book`和精确`path`；只接受已完成层级结果，不接受任意Query、临时筛选或视图ID。后续使用`status/cancel/clear`。根层已存在于普通分析结果中，展开接口不重复请求空路径或已到末级的路径。

子任务在排队前独立持有来源范围和工作簿固定，复用共享分析槽位；原拥有者清除、根任务淘汰不会提前回收排队子任务。工作簿对象、原始来源、索引和源摘要在读取时再次校验，编辑表内容改变但修订号不变同样拒绝。取消或切档不发布部分结果；App关闭等待全部自有子任务退出。清除运行任务先取消并保留其归属直到退出，不能漏掉关闭等待。

子任务使用独立历史池，不挤占普通12项报表任务。容量由formats集中定义：每页最多8项历史、2项活动、单项序列化结果16MiB及池内32MiB；完成结果仅保留JSON字节，按实际切片容量计费。该预算不包含活动聚合、在途HTTP响应及浏览器，不等于应用总内存上限。前端取得结果后立即清除服务端子任务；取消后迟到的开始响应仍回收自身ID。

## 明细、输出及兼容

层级查询的下钻和提取明细接受父级路径前缀；平铺查询继续要求完整维度键。新增可选`columnSelected`明确区分行小计与真实空白列：false读取全部列分组，true配合空columnKey只读取空白列，省略时沿用原接口约定。

已有分析导出及结果表按实际根结果的已计算层输出表头与精确合计，不制造尚未展开的维度列。入口明确为“导出首层”和“首层编辑表”；尚未提供“整个已展开树”导出。

保存含层级报表的工作区升至版本3，并维持版本不降级；旧版本1和2继续读取。旧应用拒绝版本3，不能忽略layout后重新平铺。分析方案的层级分组使用步骤版本2，旧平铺方案继续版本1；新读取器同时验证，版本1不能携带层级布局，版本2必须明确为层级布局。索引、值缓存、源范围及运行依赖均不改变。

## 已实现的界面

1. Builder明确选择平铺或层级，保存实际Query.layout；当前结果依据完成Query和Result.tree显示，不能因后来修改Builder而改标旧结果。根结果只有首层，表头不能照搬全部行维度。
2. 分支控制器按根任务、内容/路径身份和完整文字路径绑定；使用独立请求序号、取消和有界缓存。成功后清除对应服务端子任务，取消后的迟到ID同样清除；不得误清新分支或淘汰根结果。
3. 展开、折叠、逐步显示、重试及键盘操作保留父行和精确小计；对子层缺少的列分类，按根列键对齐，不按数组位置错配。分支错误保留其他已完成分支。
4. 小计和真实空白列分别传columnSelected，根/父/末级都能下钻及提取；保存报表、仪表盘和分析方案重放恢复层级布局。导出和结果表只输出根结果的已计算层时，入口必须明确“首层”，不能声称整个已展开树都已导出。
5. 缓存预算由formats注入：最多24个分支节点、保守估算结构与UTF-16文本24MiB、每页150行、最多2个活动请求。LRU按子树淘汰，不删除正在加载节点的祖先；错误文本也计费。进度只更新对应状态文字，不在轮询时反复重建表格；取消后立即重试和旧根任务退出均有独立意图守卫。

## 数字显示偏好

`analysis-numbers.js`仅接收聚合Cell。千分位默认开启，大数科学计数法默认开启且门槛为10¹²，可独立关闭或选择10⁹/10¹²/10¹⁵。科学表示从精确十进制或有理数一次舍入为3位有效数字，不将金额转为Number；普通显示仍保留分析的小数位。异常或超出格式化工作边界的输入保留服务端显示与精确提示，不伪造零。

`analysis-settings.js`的原生对话框提供预览、保存、恢复默认及明确重载。`/api/settings/analysis-display`将全局偏好存入用户配置目录的`ExcelLens/settings/analysis-display.json`，复用校验封套、Sync和原子替换，并通过按路径锁与预期修订号拒绝跨页覆盖；缺字段、损坏文件及保存失败均不覆盖旧设置。偏好与工作簿、随机端口、查询、结果缓存、方案及工作区备份分离。

切换偏好重绘已有卡片、平铺/树表及已加载图表，不运行查询。精确标题及导出保持不变，下钻原文和编号不参与自动格式化。图表仍只对绘图值近似，提示使用精确Cell；真实空白行键、字面标签及无维度总计分开，空白列图例不再显示为空文字，点击继续传原始键。
