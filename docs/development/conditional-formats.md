# 条件格式和源显隐元数据

本记录保留条件格式和源显隐的实现及历史验证。公共读取、主/冻结网格、复制、HTML/XLSX快照、显隐/大纲、命名视图v2，以及后续分析来源、按需透视和只读选择性复制均已接通；各层证据分别记录，不以底层回归代替完整界面。当前版本、后续修复和候选状态只见[实施进度](improvement-progress.md#接续入口)，不在本文保留过期下一步。

## 统一模型及只读约定

`SourceLayout`在原索引扫描中记录条件块的缓存XML字节范围、祖先命名空间和行列状态。尺寸、网格线和合并也统一在正确父节点捕获；单元格内联扩展中的同名标签不再污染整表布局，冷索引和旧布局迁移共用这一入口。状态区分显式显示、隐藏、0尺寸、0～7级大纲及折叠，连续相同状态压缩，不为每个隐藏行创建map。列声明重叠时后者替换该范围的全部状态。默认零行高、零列宽与普通缺省尺寸分开；无效、负数、NaN/Inf和超限保留说明。空白隐藏尾行、样式和规则不扩展真实已用区域。

`DifferentialStyle`独立于源Style编号，保存DXF字体、填充、边框、数字格式及对齐差异；缺省、显式false和none分开。空border容器不清除边框，明确的空边或none才表示清除对应边。字体及颜色复用已有解析；未知属性、命名空间、无效颜色或格式保留不完整状态，不伪装成已还原。

源文件、原文、类型、坐标、普通Style和公式缓存状态不变。`formats`集中维护`ConditionalMetadata`能力及容量，目前只有XLSX/XLSM具备此元数据能力；这不表示完整视觉还原。没有增加格式支持名单、生产运行依赖或源写入。

## 按需求值

`Workbook.SourceConditionalFormats(ctx, meta, idx)`建立不可变二维范围索引；`NewEvaluator(ctx).Evaluate(row,col,cell,resolver)`仅计算明确请求的格子。同一组重叠sqref只执行一次，多个不连续范围共享首范围锚点。高优先级先占各属性，显式取消仍阻挡低优先级，只有已证明命中的stopIfTrue才停止。

当前可证明的规则包括cellIs常见比较、between/notBetween、常量/单格引用和简单expression，以及经声明公式校验的文本、空白与错误规则。相对/绝对行列均按源坐标处理。数值使用已有十进制有效数字/指数模型精确比较，不经float，不展开巨大科学指数；原生Excel文本编号不转数值。任意表达式、全范围统计、色阶、数据条、图标集、文本通配等尚未求值，保留原因。无法确定的规则不能当false；保留已证明的高优先级效果并停止低优先级覆盖。

resolver的available=false表示尚未读取，不能当空白或零；只有来源明确为空的格子才返回空CellData及true。公式缺缓存不当错误值或默认零。求值器本身不读取依赖；本轮`RowReadOptions.ConditionalFormats`显式启用呈现读取，通过同一源文件句柄按需解析被引用单格，限制4,096次及16MiB原XML行跨度，并使用最多2MiB的有界引用缓存。没有启用普通搜索、筛选或分析的条件求值，不扫描整表。

本轮派生结果另存`CellData.Conditional`，原Raw、Display、Type、Style、Ref和公式/缓存状态不改写。仅为呈现生成的空白格带`PresentationOnly`标志；按明确源行号读取可覆盖没有索引记录的空白行，但不加入值索引或扩展已用区。请求最多20,000个求值格和4MiB条件元数据；流式访问逐行重置预算，复制另行累计整体字节限制。超限保留行级或单格说明。稀疏列按所选列遍历，不为两端之间未选中的列逐格求值。客户端共用字体覆盖、派生显示值和样式模型，并计入视口/跨Sheet缓存。

条件字体按属性覆盖片段字体，再继承普通单元格字体；用户字体覆盖继续优先决定显示字体。复用节点先清理旧呈现属性，避免上一格的填充、加粗或数字格式颜色残留。条件与普通样式的常见定点小数、千分位、百分比和会计显示共用源十进制舍入，避免大数尾数和1.005等边界先转float失真。General保留条件显示的精确原文，精确负零规范化；超浮点范围和非零下溢仍保留原文及原因。没有改动文本编号、源类型或日期转换触发方式，也不表示所有Excel数字格式均已精确还原。

HTML快照逐行求值并保留可证明的差异及原因；XLSX已接通下述样式去重和冻结写出，已证明的效果变为普通样式，未知规则、缺少所需公式缓存、依赖或容量不足仍使带格式任务失败，不发布下载。可选择带说明的HTML或关闭原格式后导出。

元数据块、规则及DXF各8,192，范围65,536，单公式4KiB、最多8段，源XML元数据16MiB；每求值器2,000,000工作量和8MiB文本预算。单源行/列状态最多100,000区间。预算耗尽保留原因，不静默丢失或改写数据。具体常量只由`internal/formats`维护。

## 缓存与迁移

条件索引合并同表并发加载，取消等待者可退出，错误不永久缓存。按保守模型字节使用32MiB LRU；不包含Workbook已有DXF、源字符串、源布局及活跃调用者，不能解释为进程总内存上限。返回的样式容器及标量指针复制，调用方修改不污染源样式表。sqref按字段逐段读取并在容量边界停止，不先按全部空白或冒号拆成大型临时切片；超限整块拒绝，不能返回前一部分范围的成功结果。

源布局侧缓存当前为v6，文件名和封套共用唯一版本常量。旧v2～v5不复用布局；OOXML首次按缓存XML标签流重建，跳过值字节且不构建第二份行索引，包含已用区域之外的空白隐藏行、尾部规则和命名空间；BIFF8重读布局记录。v6保留显式正尺寸`PositiveSize`，避免默认零尺寸时把`hidden=false`误当成正尺寸，同时不把超几何显示上限的正尺寸误当零。暖读复用校验和正确的v6。原生值索引仍为`XLIDX009`，外部行编码仍为`ELNROW02`，富文本侧文件仍为`ELRICH01`。历史v4检查只证明当时工作包，当前显隐模型、迁移和独立验证见[源呈现记录](source-fidelity.md)。

源值、类型和缓存编码不变。普通XF新增字体上下标、下划线种类及显式apply=false的named-style继承，重开时从源样式元数据重新解析；外部行显示按原值即时格式化。搜索结果缓存升v3，旧v1/v2中按旧显示生成的命中和摘要不复用，用户再次查询时重算，不重建源行索引或修改用户工作区。

布局IO及迁移不持有全工作簿布局map锁，同表合并读取，其他表及取消等待者无需等待扫描完成；取消扫描在有界读取边界检查，不能中断已经发起的操作系统磁盘IO。索引尚未就绪且无有效侧文件时不缓存空布局，后续挂接索引仍能迁移真实元数据。侧文件先写、Sync及关闭后重命名，失败保留旧目标，未改写源文件或用户设置。

## XLSX快照实现与边界

1. 按源XF与已证明差异全局去重，字体/填充/边框组件也共享。逐行输出工作表，最后写出样式表；不按格创建活动条件规则，也不驻留整张工作表。
2. XML标签流只索引需要的源目录/记录。克隆被覆盖组件并按字节补丁写出，保留未覆盖属性、未知扩展、命名空间和QName值。原记录及编号不重排，默认目录仅为隐式样式0补齐；显式越界或缺失依赖拒绝。
3. 条件字体同步覆盖富文本片段；重开可合并相邻相同字体，全文不变。数字格式按code复用，保留源编号，避开所有源占用编号。DXF字体颜色覆盖原数字格式颜色时，派生格式只移除真实颜色指令，保留引号内文字、条件及其他指令；原格式不原地修改。
4. 冻结源坐标上的当前效果，覆盖紧凑输出、排序/筛选和空白行/格；不搬移相对条件公式。源Raw、类型及1904日期系统不因冻结而改变，只有样式的空白不扩大已用数据区。输出仍是新快照，不是完整原包保存或源文件写回。
5. 源样式和主题在输出单元格前捕获，前后核对来源，检查ZIP CRC和重名路径。每个样式/主题部件64MiB，派生去重工作预算64MiB，各目录65,536项、每片段直接子项65,536项、XML深度64、标签64KiB；常量由formats维护。工作预算不包括已有源模型和整个进程内存。解析与32KiB输出边界检查取消，短写、超限或不完整任务不发布下载。
6. 重开回归核对多表、乱序/真实空白、文本编号、大数、日期、布尔/错误公式缓存、源XF继承、主题及未知XML保留；故障回归覆盖同大小来源改写、CRC、取消、写入失败及最终发布失败。完整ZIP生成后取消也不得发布，已有目标保持不变。

百万行专项逐格核对300万个输出格，单一源XF加一个派生XF即覆盖全部重复效果，源哈希不变；样式空白C列不把源已用列数从2增为3，实际读取仍可取得C列样式。记录流式输出及活动取消，不把观测耗时或抽样堆内存当作普遍性能结论。首次规模/浏览器断言曾把样式空白当作数据范围、把相同片段归并当作样式丢失，已修正为核对真实数据范围、全文及每段有效字体。

XML属性模糊测试57,663次通过，十进制定点舍入模糊测试与有理数参考核对114,304次通过。高基数组件含大量未知源字体数据时，工作预算会明确拒绝，保留完整原源；不静默减少样式。

显隐/大纲、主/冻结网格、导出和命名视图v2界面已在后续工作包接通，见[源保真记录](source-fidelity.md)。分析来源、F08及F10只读范围也已分别完成，当前工作只由实施待办维护。后端、界面和人工验收仍分别记录。
