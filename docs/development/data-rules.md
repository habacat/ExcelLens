# 数据规则读取与解释

F15普通OOXML/BIFF8底层、x14扩展、BIFF续记录与复杂公式读取已通过各工作包验证；来源绑定的HTTP和只读规则界面已实现，并通过本次定向、最终代码真实服务浏览器、完整标准及竞态验证。第三阶段只读工作包已收尾，规则写入和下拉值修改仍未开放。实际状态和下一步以[接续入口](improvement-progress.md)为准。应用仍为1.8.18，开发收据放在`validation/1.8.19/`，不自动发布或替换发行包。

## 读取与共用模型

`Workbook.SourceDataRules(ctx, meta, idx, progress)`只接受同一Workbook中已经准备的工作表索引，并在读取前后核对真实来源。打开、普通索引、滚动和分析值读取均不调用此接口；它不建立其他Sheet索引、不读取列表引用中的单元格、不运行源公式或自动日期转换。

首个显式OOXML读取遍历所选Sheet缓存XML的标签，并以源ZIP部件CRC核对全部缓存字节；只保留根命名空间和有界规则块，不解码或存下sheetData。没有用最后一个有值行的位置猜测尾部，因此稀疏数据和超已用区域的规则仍能保留。BIFF8显式读取只遍历所选工作表子流的记录，复用公共BOF/EOF读取器，不读取Globals/SST或解码单元格；嵌入图表中的规则与EOF不属于父表规则。

`SourceDataRule`共用规则种类、运算符、错误级别、空白/下拉/提示开关、输入/错误文案、条件定义和源范围。保留OOXML原属性及每项原始XML，BIFF8分别保留Dv、每条CONTINUE记录和两份逻辑公式令牌。容器另保留命名空间、提示总开关及原始属性，不把普通规则和扩展规则合并成一个虚构的源容器。状态只说明元数据能否解释，不代表当前格或整表已经通过数据校验。缺失、错误、未知和未求值不改写为成功或默认合法值。

适用范围保持矩形，独立于覆盖的单元格数量；区域树构建与条件格式共用`source_range_index.go`。`At`按源行列查询，单条规则的重叠区域只返回一次，不合并不同规则；分页维持源声明顺序。公开页、属性、列表和提示均复制后返回，调用方不能修改共享规则。

范围无效的原规则仍保留在总目录，计入`UnknownScopes`。存在未知范围或未完整读取的规则时，分页的`scopeComplete=false`；单格零命中只能说明没有已识别的覆盖规则，不能证明该格没有数据验证。

## 格式与解释边界

- 普通OOXML `dataValidations/dataValidation`：只解释源工作表命名空间下的真实直接子节点，支持默认或显式前缀。声明数量、重复属性/容器、源范围、公式结构和根结束均核对；保留显式属性与模式缺省值的区别。属性`showDropDown`沿Excel普通验证规则的保存语义映射为抑制下拉标记，原始属性同时保留。
- 直接文字列表仅展开可完整确认的引号文字，保留前导零、空列表项、文字顺序、Unicode和引号。引用、命名区域和其他表达式保留原定义及未展开原因，不临时扫描列表来源。复杂公式保持源文字，不以运行它来解释规则。
- BIFF8：核对DVal声明及Dv数量，读取规则标志、XLUnicodeString、两个DVParsedFormula和真实SqRefU。结构和公式字节按实际边界跨CONTINUE；仅文字字符续段读取新宽度标志，支持压缩/宽字符切换和跨记录代理对，坏Unicode或缺少续段整次失败。数字/文字常量、明确文字列表及可可靠还原的公式可描述，未确认的令牌保留原文和原因。显示列表使用原NUL分隔，不能按逗号错误拆开其文本。
- x14：只读取真实`worksheet/extLst/ext`下、扩展URI为`{CCE6A557-97BC-4B89-ADB6-D9C93CAAB3DF}`的验证集合；分别核对x14规则、xm公式及xm范围命名空间，支持祖先处的前缀声明。嵌套`formula1/2`必须各含唯一xm:f，范围来自唯一xm:sqref，不拼接重复或外来结构。按x14列表的保存语义解释`showDropDown`，原始属性保留；其他未知扩展明确标记覆盖不完整。x12ac:list仅保留扩展列表定义和未确认原因，不据普通公式猜测其候选值或替代关系。
- 公共BIFF公式解释区分Ref/Area中的源坐标和RefN/AreaN中的相对偏移；前者的相对标志仅控制显示中的`$`，不能再叠加公式所在行列。规则没有可确认的计算基准时不解释相对偏移。补齐零参数函数、严格布尔/字符/非有限数值及唯一栈结果校验；文字64KiB、累计表达式工作1,000,000的预算由formats维护，避免复杂拼接无限放大。不可还原表达式不伪装成以`=`开头的有效公式，源缓存值不重算。
- CSV/TSV/TXT/HTML内容的XLS/SQLite不推断Excel源验证规则，能力与容量只在`internal/formats`维护。功能只读，规则写入和下拉选值修改仍依赖第四阶段。

## 容量与生命周期

最多8192条规则、65536个源区域、8个规则容器，单项原始XML或条件文字64KiB，单个XML规则块4MiB、编码元数据合计16MiB；文字列表最多4096项、每页最多50条。XML深度64，规则属性最多32项，根命名空间等属性最多128项。BIFF单条逻辑规则最多64KiB、256个物理分段和432个范围。源格式行列边界仍由formats维护，不把完整列区域展开为单格。

完成结果不可变，内存LRU最多16张Sheet、按保守估算最多32MiB；这是驻留规则缓存预算，不是进程内存上限。并发读取共用一个加载拥有者，IO和进度回调不持有缓存锁；拥有者取消后，活跃等待者可重试，单个等待者取消不取消其他请求。失败、来源变化和取消不发布部分结果；淘汰不会使现有读取者的快照失效。

当前没有新增磁盘规则缓存。`XLIDX009`、`ELNROW02`、SourceLayout v6和目录证明版本均不变。公共公式语义修复将BIFF行缓存路径从`-biff2`升为`-biff3`，旧BIFF行缓存不复用，按需从只读源重建；其他格式值缓存不变。普通索引不捕获规则模型；进程重启后第一次显式读取规则需要重新扫描，后续可在真实收益和来源证明充分时引入独立缓存。

## 来源绑定的HTTP与只读界面

`server/source_metadata_tasks.go`与名称目录共用泛型任务生命周期：App锁保护状态，排队复用公共查询槽位，工作簿独立固定，取消/来源替换/退出不发布部分结果，锁外等待结束。已完成快照不可变，迟到的未采用任务即使已经完成也可取消回收。规则另有2个活动任务、4个任务历史、最多2份且保守预算合计64MiB的保留快照；容量只由formats维护，不代表进程内存上限。底层驻留LRU仍独立限制为32MiB，实际共享的规则指针可能被两类预算保守重复计费。

`server/data_rules.go`提供`/api/data-rules/{start,status,cancel,clear,items,detail,resolve}`，按会话、Workbook对象、内容与路径身份、Sheet及已经准备的精确索引绑定。请求最大8KiB，不静默建立其他工作表索引；索引更换或来源变化后拒绝沿用快照。`List`仅返回摘要，复用单格压缩树命中及声明顺序，不复制完整原文/列表。`Detail`逐条返回原始定义，范围和列表项各按50项独立分页；`Area`取得单个可靠矩形，不展开单元格。解析/CRC失败进入错误状态，不能输出空的成功列表。

`ui/web/data-rules.js`复用已有任务控制器和公共源坐标导航。入口位于名称框旁、右键菜单和命令面板；当前源格/全表、类型和定义状态筛选，保留未完整读取/未知范围提示。详情展示条件、提示和设置，文字列表先显示候选项；原始定义折叠显示且全部使用textContent。切档/切表/取消、分页/详情序号和来源/路径守卫共同拒绝迟到响应；新快照首屏成功后才替换旧结果。源区域允许已用范围之外的空白，重排视图中的矩形定位复用现有明确拒绝语义。

后端定向通过，覆盖元数据摘要、独立分页及不可变数组、源格重叠、未知覆盖、精确金额/原生文本/缺缓存、排队取消与源固定、会话/路径隔离、历史淘汰、来源改写、坏声明/缓存CRC及失败结果拒绝。10项新增前端回归与10项目录回归通过；另覆盖来源不匹配的已完成状态回收与未知源枚举原文展示。完整竞态通过；Go代码随后未改动，最后JS补强后重新构建并通过浏览器及最终完整标准检查，含311项前端。

实际服务规则浏览器通过，包含131条规则、各121个范围/列表项分页、普通/x14重叠、实际排序后的源格命中、视图拒绝定位、类型/问题筛选、可靠空目录、BIFF续记录、取消后立即重试、同内容不同路径、原文安全、原值/类型/缺缓存及源哈希。桌面/420px/深色截图已复核；新增几何断言确保翻页和页脚真实可见。名称目录浏览器在共用生命周期改造和同类列表布局修复后也通过。保留规则分页负对照、目录分页负对照及首次脚本等待时读取临时空DOM的失败，后者是验证脚本问题，已改为等待实际节点就绪。未进行Office/WPS或桌面人工验收。

## 下一工作包接续定位

普通/x14/BIFF底层及HTTP/只读界面的实现和本包完整验证均已完成并回写[接续入口](improvement-progress.md#接续入口)，后续工作只以主待办为准，不在本记录保留已过期的下一工作包。规则写入和下拉值修改仍依赖第四阶段。

- OOXML入口为`data_rules_xml.go`、`data_rules_xml_extensions.go`及`data_rules_xml_fields.go`，真实来源与未知覆盖标记必须继续沿用。x14依据为微软[x14 CT_DataValidation](https://learn.microsoft.com/en-us/openspecs/office_standards/ms-xlsx/89029dfc-1ca8-4ff9-afe0-46f9454d09c6)。
