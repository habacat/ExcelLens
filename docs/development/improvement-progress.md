# 当前版本实施与验证状态

## 接续入口

1.14.0 提供可选加密的异步备份和可重放迁入事务。编辑与任务记录保留原路径，并通过内容核验绑定目标电脑的新位置。已提交的搜索、筛选、分析、对账与导出允许在关页后完成并接回。当前验证边界和结果见[本版说明](../releases/1.14.0.md)及[工作流收据](../../validation/1.14.0/workflow-verification.json)。

## 1.13.4 历史记录

1.13.4 增加浏览器会话租约与定期回收，本地数据管理可保护旧布局、核验备份和迁入工作成果。隔离浏览器已通过刷新接管、关页回收、备份及迁入。独立计算面板对照覆盖 Excel 原生的 278 个参考结果，包含 243 个函数名和两种日期系统。桌面人工验收及原生 WPS 对照仍待单独验证。[本版说明](../releases/1.13.4.md) · [工作流核验](../../validation/1.13.4/workflow-verification.json)

## 1.13.3 历史记录

本次 v1.13.3 同版修订让行列高亮按点击位置贯穿合并单元格。已复现旧版的整块着色和漏色，并通过 23 组合成工作表、4 组实际费用表的像素对照，覆盖阅读、编辑、缩放和冻结窗格。Windows 工程六步及 560 项前端回归通过。桌面人工验收未执行。[本版说明](../releases/1.13.3.md) · [工作流核验](../../validation/1.13.3/workflow-verification.json)

1.13.3 同版更新将选框调整为固定 2 CSS 像素宽，7 CSS 像素见方的填充柄居中在右、下框线的交点。实际明细账、费用报表和合成表共 56 组像素检查通过，并已验证拖动填充及撤销。Windows 工程六步及 559 项前端回归通过。[本版说明](../releases/1.13.3.md) · [工作流核验](../../validation/1.13.3/workflow-verification.json)

## 1.13.2 历史记录

1.13.2 默认使用经典单行工具栏，可在顶部或 Windows 托盘右键切换选项卡布局。托盘提供程序目录和全部工作簿缓存清理，清理后页面返回首页。已验证 Windows 长短路径混用时的原件保护。[本版说明](../releases/1.13.2.md) · [工作流核验](../../validation/1.13.2/workflow-verification.json)

## 1.12.2 历史记录

1.12.2 将工作簿版本比较、可重跑的核查包、分级复制、分页底稿、传统批注交换、ODS 和独立模型试算纳入发行。HTTP 按实际监听端口校验 Host 及来源，后台扫描为前台保留名额。

本版对两张各 25,000 行的台账核验了插行、删除、相对移位和数值变化。金额容差保持精确差额，规则 1 的核查包可按原语义重跑。独立复核覆盖三份 ODS、传统批注的 Excel 另存重开、目标求解和双变量结果，以及两表 126 条明细的分页输出。[本版说明](../releases/1.12.2.md) · [自动化与原生核验](../../validation/1.12.2/workflow-verification.json)

正式发行在工程门禁中重建 Windows 资源并与已提交的 COFF 逐字节核对，涵盖图标、应用版本及 DPI 清单。从对应 Git 标签生成完整源码，在同一暂存目录核验 Windows 包、源码包和校验清单。[构建方法](../../CONTRIBUTING.md)
