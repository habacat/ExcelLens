# 命名视图实现与验证

F05继续使用纯Go服务与现有前端网格，没有引入格式库、运行依赖或源文件写入。开发树仍为1.8.18，第二阶段尚未发布。

## 方案

`FilterResult.Spec`在成功生成不可变行序时捕获实际规则、表头与排序方式；保存视图时从仍有效的结果取得该配置，不信任尚未执行的界面值。过期筛选不能降级成无筛选视图。保存的数据只包括规则、用户布局、源绑定及少量字段签名，不序列化源数据或行序。`workbook.ValidateFilterSpec`与实际查询共用规则验证，不另建DSL。

`server/named_views.go`绑定内容指纹、格式、Sheet路径、表头、列范围和被引用字段。引用列在元数据读取范围之外时保留未读取状态；同内容身份仍必须相同，不靠未读取名称或C1列号跨文件猜测。实时来源检查沿用F02，TXT字段栏从真实表头行重建。不同内容文件的复用属于F03分析方案，不能借命名视图绕过字段核对。

`server/saved_config.go`提供视图和分析方案共用的持久化封套：有界读取、严格结构及UTF-8校验、版本与SHA256、临时文件Sync和替换。文件位于用户配置目录，缓存维护不触及；替换失败不会先删除旧文件。按路径的文件锁串行化跨App事务，预期修订号拒绝旧列表覆盖。未知版本、损坏或超限保留原文件，不重置为空列表。

`named-views.js`只负责配置列表和应用任务，复用公共作业所有权模型。公共任务模型可分别指定上下文身份与请求工作簿身份，避免把Unicode表名放入HTTP头；筛选状态可直接作为结果返回，默认分析行为不变。过期列表不能覆盖新的保存确认。校验完成和查询成功之前不改变当前网格；查询后复用公共筛选结果接入及原生布局读取。

普通筛选同时补强开始响应的所有权：开始前占有本次请求身份，切Sheet、切档和取消会失效该身份；迟到ID只取消自身，不发布旧行序。取消接口在任务发布锁内撤回已发布结果，独立读取引用仍可完成；状态接口取得独立快照，过期结果明确报错。

## 当前证据

- 服务回归：实际规则捕获、精确值清单和自然排序重放；配置目录持久化、清理缓存、同内容改名及重启；过期筛选、重复名称、并发修订冲突、变化来源、字段签名及规则版本拒绝。
- 故障注入：Sync和替换失败保留旧确认文件，临时文件回收；校验损坏、未知封套版本、多余内容及超大读取拒绝并保留证据。
- 前端回归：跨Sheet/切档的迟到响应、待开始任务取消、查询失败不覆盖当前视图、旧列表响应不能覆盖新保存确认。
- 真实服务浏览器专项：完整布局、筛选及自然排序重放、逐行源坐标、取消迟到开始、失败保留当前视图、重启不自动运行、名称安全、TXT字段栏及跨Sheet原生精确数值筛选；420px和桌面截图保存于忽略的private目录。
- 完整标准检查：Go、vet、离线依赖、架构及202项JavaScript回归通过。共享链路另外重跑F02浏览器和262,145条行序浏览器，均通过。
- 完整竞态检查：指定MinGW工具链的完整`check -race`通过，包括跨页面文件修订、取消/发布竞争、独立行序引用及设置写入失败测试。

未进行桌面人工验收，不据合成资料宣称所有客户文件已验收或性能已经普遍提升。命名视图没有扩大格式容量，也没有实现源文件编辑或自动重放分析方案。

## 第三阶段的显隐快照扩展

开发树新增命名视图`ruleVersion=2`，`config.rowVisibility`记录已成功可见快照的声明式显隐设置；原版本1继续可读及应用。保存需携带`viewId`，同时核对源对象、精确索引、Sheet及`filterId`。实际规则、表头和行显隐均从被固定的成功结果取得，前端未执行的设置不能替代；原筛选map条目清除后，只要快照仍有效即可保存其完整规则。

持久化文件只包含规则及显隐设置，不保存临时视图ID、索引对象或全部行序。恢复前再核对源与字段，并使用共享SourceLayout/AxisVisibility校验组键和源格式边界；不存在的组不能静默忽略。随后仍须重建查询和行投影，不能把已保存设置当作已经恢复的画面。

接口工作包定向验证成功捕获、错误控件不覆盖、清除、同内容改名/重启、重新排序/投影、缺失快照和未知组拒绝；其完整标准、完整竞态、230项前端及既有浏览器专项通过。前端保留显式能力守卫，缺少显隐支持时在查询前拒绝v2，避免部分应用。

随后界面工作包已启用v2。应用时先构建目标Sheet的显隐快照，再替换查询和布局；未采用的准备结果释放拥有者，迟到视口不覆盖新视图的选择。显隐浏览器专项验证保存成功设置、改变显隐后重放、父/子组、排序及冻结一致性。应用命名视图属于临时画面选择，不自动覆盖单独保存的行显隐偏好；显式定位的临时显示同样不持久化。当前完整检查状态见[第三阶段进度](improvement-progress.md)，接口旧收据不替代界面工作包新检查，也不表示桌面人工验收。

## 复现

```powershell
go build -o artifacts/qa/uiprobe.exe ./tools/uiprobe
$env:QA_OUTPUT_VERSION='1.8.19'
node tools/qa/named_views_qa.cjs
```

浏览器及应用服务使用自有进程和隔离配置，输入均为生成的CSV/TXT/XLSX，不读取用户浏览器资料。
