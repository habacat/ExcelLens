## 设计与工作包

1. 统一只读打印设置：源纸张/方向/缩放与适配页数、页边距、居中/网格/行列标题、页眉页脚、分页符、打印区域和重复标题。保留源XML/属性或BIFF物理记录，不执行源名称公式、页眉字段或打印机配置。
2. 打印几何及分页：与显示网格限幅分开，压缩表示真实行列尺寸、隐藏状态和重复标题；用物理单位和独立页数/工作预算计算，不展开百万个空白格。自动分页、手工分页与部分行列范围分别保留。
3. 来源绑定任务及预览：复用元数据任务和公共源格读取，按页读取及渲染，保留不完整、未知纸张/打印机默认值及近似字体测量的真实限制。验证普通/扩展定义、纸张边界、取消/切档、分页编号、源哈希及窄窗口后再记完整F22。

## 不变量

- 打开、索引及滚动不扫描打印元数据，不修改源值、类型、坐标、缓存值或源文件。
- 源格式能力和容量仍只由formats维护，不新增格式支持名单或XLSB。
- 名称按真实作用域及源定义处理。不存在、未完整读取、动态/外部引用和无效定义分别保留，不能把解析失败变成默认整表打印。
- 缺省、显式值和不可解释状态分开。BIFF Setup的`fNoPls`为真时，部分纸张/缩放/打印机字段没有定义，不能读取其垃圾值后生成看似可靠的分页。
- 网格`SourceLayout`的显示像素和尺寸限幅不作为打印几何的源事实。本工作包不改变XLIDX009、ELNROW02、SourceLayout v6或现有BIFF行缓存版本。
- IO与进度回调不持缓存锁，快照不可变，取消/来源变化/结构损坏不发布部分成功结果。只为显式读取建立有界元数据缓存。

## 打印几何的已核对边界

## 独立打印几何实施

`print_geometry*.go`保留源磅/缇和字符宽度、尺寸相关原始属性及源区间。未保存的默认高度不补成15磅；未知/无效的可见尺寸使相交范围查询明确失败。隐藏行列贡献精确零，源零尺寸与正尺寸分开；自定义视图和图表尺寸不替代当前工作表。BIFF8行高按真实格式范围核对，高位占位值不转换成看似有效的默认高度。

字典复用相同尺寸与标志，行区间不展开空白源行；列覆盖受独立工作量预算限制。范围长度用整数纳磅及128位前缀计算，避免巨大前缀后的短区间丢失；超过返回长度容量时拒绝，不能截断或回绕。低于纳磅的正尺寸向上量化并标为近似；列宽按Normal字体96DPI度量换算，始终保留字体/打印机近似提示。JSON中的纳磅长度用字符串编码。容量由formats维护：单索引96MiB、最多4表/合计128MiB缓存、100段分页及4096项临时测量复用。

## 来源绑定分页核心

当前分页实现位于`internal/printing`，设置与几何从`ReadPrintSource`联合获取，不能把其他Workbook、路径或精确索引的数据拼入；创建和取页保留活源校验。仅缺失的默认尺寸可用显式预览配置派生，通过前缀计数共享已有几何，不复制百万段数据、不掩盖坏源尺寸。

分页将纸张/边距、缩放或适配页数、打印区域、重复行列、页序/起始页码及居中转换为有界源区间和物理偏移。整数/有理数转换不累计浮点误差；源超大行列按连续物理切片保留，标题重复不计入正文覆盖。全隐藏与空数据不生成假空白页，标题占满正文、坏范围、未知设备、超限和取消明确失败，不发布部分结果。未保存打印区域时使用已索引数据范围并提示，不能称为涵盖所有格式空白区域。应用、规范及源值的来源分别记录。

已按微软[缩放规则](https://support.microsoft.com/en-us/excel/scale-a-worksheet)处理适配页数忽略手工分页；按[Office分页兼容说明](https://learn.microsoft.com/en-us/openspecs/office_standards/ms-oi29500/77730f13-7af9-42e0-96c7-0b349853617e)将源局部分页范围用于整页兼容预览，同时保留源min/max及兼容说明。未把这些计算称为Office/WPS实际打印验收。源行列标题采用明确的预览尺寸估算，字体及设备限制保留近似状态。

定向回归、1200组独立物理覆盖和最小适配容量随机核对、100万实际源行分页/逐行核对、849,533次模糊均通过。隐藏零前缀之后超大行及空索引假A1范围问题已修复。补齐有效设置/范围/标题的不可变摘要及`Plan.Geometry`批量只读尺寸入口后，最终完整标准及竞态检查所有步骤通过，含311项前端；最终日志时间2026-11-16 03:46:18。

## 来源绑定任务与按页读取

`server/printing_tasks.go`复用公共元数据任务、查询槽位、来源固定及有界历史。`start`只接受当前Workbook内容身份、路径身份、工作表和已准备的精确索引；打开或滚动不会自动准备预览。`printing.Plan`只计算分页，实际源格读取仍归server和Workbook公共读取链路。

接口都在`/api/printing/`下：

| 接口 | 契约 |
| --- | --- |
| `POST start` | `workbookKey`、`book`、`sheet`及`printing.Options`；返回任务和来源身份，参数/来源错误明确拒绝 |
| `GET status?id=…` | 公共任务状态、进度、错误及来源身份，取消和失败不发布部分分页 |
| `POST cancel` / `POST clear` | 任务`id`；已快速完成的未采用结果也释放，重复清理可安全重试 |
| `GET summary?id=…` | 不可变有效设置/范围/标题/页数、来源属性及未完整状态；不把所有原始XML、分页符和源格附在每个摘要响应里 |
| `GET page?id=…&page=…` | `page`为从0开始的页序，与源起始打印页码分开；按需读取本页，返回源坐标、原始CellData、引用样式和整数纳磅的完整矩形/实际切片 |

每页同时持有缓存读锁和来源引用，在共享查询槽位执行，发布前再次核对任务/Workbook/路径/精确索引/活源内容。HTTP取消、任务清除、历史淘汰、切档或关闭都会使取页请求退出，排队请求不用等其他查询完成才释放来源。公共任务清除和淘汰也取消已经完成任务的上下文，目录/规则原有定向继续通过。

`printing_page.go`按前缀长度跳过隐藏零尺寸，不为百万隐藏区间创建百万行对象。源单元格与本页物理切片分别传输，超大行列保留完整源尺寸和偏移；重复标题和源合并跨片段时保留原锚点，隐藏锚点通过`hiddenAnchor`明确标记，不把其值挪到可见覆盖格。富文本、条件呈现、样式、前导零、金额精度和公式缺缓存使用公共读取结果；没有存储单元格的坐标不伪造CellData。

OOXML显式打印扫描顺带校验合并声明、数量、范围和命名空间，再与公共SourceLayout合并结果核对，防止旧显示缓存忽略坏定义后生成看似有效的预览。BIFF沿用公共严格合并读取；相交的重叠合并明确失败。该计数只在内存元数据中保留，现有值、行、SourceLayout缓存编码不变。公共合并记录达到100,000项时拒绝确认完整预览，不把显示容量边界误写为完整还原。

容量统一来自formats：2活动任务、4历史、最多2快照且合计保守预算256MiB，预算包含绑定的几何/源设置及分页片段；单页最多8192行、2048列、20,000格、16MiB及2,000,000次工作。额外合并锚点也计入读取限额，重复输出的锚点每份计入字节。超限返回失败而不截断，以上是独立逻辑容量，不是进程总内存或性能提升承诺。
