# 发行性能基准

1.16.0 起，正式构建以同一组确定性合成文件运行下表。每个读取规模使用新的服务、缓存及浏览器配置。计时包括本机页面和真实读取接口，操作系统文件缓存沿用机器当时状态。首个可见数据格和整屏覆盖分别记录。每组运行一次，跨版比较需同时核对主机、系统、工具链、浏览器、测试代码及样本摘要。

| 场景 | 规模 | 记录或核对 |
| --- | --- | --- |
| CSV／XLSX | CSV 100 万、500 万、1,000 万行；XLSX 10 万、50 万、100 万行 | 选择文件至首个数据格、首屏覆盖、索引请求至完成响应、服务峰值工作集 |
| 滚动 | 百万行 CSV 连续 60 秒 | 浏览器动画帧率、P95 间隔、网格节点与占位层均缺失的帧数、DOM 覆盖状态 |
| 全量搜索 | 500 万行 CSV 中一个机构 | 服务完成时间、CSV 流读取核验用时、每条命中的源坐标 |
| 双表对账 | 两份各 100 万条的合成台账 | 完成时间、数据目录新增逻辑字节的采样峰值、逐类记录数 |
| 多页 | 10、30、64 个独立标签页，每页打开同一份 501 行工作簿 | 并发状态请求的 P95、服务及浏览器工作集和句柄数 |
| 关闭与回收 | 100 轮实际打开、关页并通过任务中心释放 | 每 10 轮采样服务工作集和句柄 |
| 编辑并保存 | 10 万行双表 XLSX | 保存及应用内核验用时、目标值/样式、其他单元格、合并、冻结、跨表公式及部件 |

多进程浏览器的工作集之和包含共享页的重复计数。历史基准仅在测量条件一致时计算差值。24 小时长跑不在发行流程中。

```powershell
node tools/bench/release.cjs --smoke
node tools/bench/release.cjs --out=validation/1.16.0/private/run.json --save-baseline=validation/1.16.0/performance-baseline.json
```

脚本按场景增量写入 JSON。样本使用前后逐一核对 SHA-256，断言失败会终止发布。完整候选基准可签入源码，标签构建会重新测量。发行附件 `ExcelLens_<版本>_Performance.json` 含该提交的实际指标和可比基准差值，SHA-256 随包提供。单场诊断可使用 `--only=reading`、`reconcile`、`tabs`、`lifecycle` 或 `edit`。[1.16.0 候选基准](../../validation/1.16.0/performance-baseline.json)

## 1.19.0 综合基线

超长工作表会压缩浏览器的物理滚动范围。测量使用网格公开的缩放比例换算逻辑位移，再用源坐标和样本原值验证命中位置。每条条件轨迹记录实际逻辑纵向位移及当时的比例；后端每一轮独立保留结果，即使后续浏览器场景失败也可定位。

正式构建使用第二版报告格式。上表的七类通用场景继续运行，另外测量以下条件格式工作负载。操作系统文件缓存保持当时状态，“冷建”指隔离的应用缓存。普通滚动、条件格式滚动及逐格 Go 微基准各自有独立口径。

| 工作负载 | 重复与口径 | 输出与核对 |
| --- | --- | --- |
| 100 万行，1 万／50 万个键 | 每组 3 轮新进程和独立缓存，交替执行顺序 | 行索引、统计准备、首次视口、重开索引及重开后首个视口，各阶段分别计时 |
| 六种条件统计规则 | 每次冷建后 16 个分散视口，每视口 20 行、120 个命中样式 | 每组 48 个暖视口样本的中位数和 P95，核对物理坐标、样式、缓存复用与原件摘要 |
| 筛选和多列排序 | 从百万行 CSV 挑出同一机构记录，显式按金额数值降序、固定宽度编号文本升序排列 | 筛选排序耗时、16 次跳页的中位数／P95、峰值内存与额外磁盘占用；完整核对排序后的 10,000 条记录、源行号、金额和前导零编号 |
| 条件格式浏览器 | 2,400×48 多策略有色工作簿及百万行台账。逐段按墙钟位移，包含正向、反向与跳转，宽表另有横向阶段 | 首次可交互、完整着色、前台命中、FPS、P95／P99、落定延迟、文本及条件就绪率、服务峰值工作集、数据目录逻辑字节、句柄 |
| 合成像素 | 有色工作簿的原格式录屏与同坐标落定后的画面逐像素比较，计时对照另跑 | 报告符合调色板的有效像素、样式正确率和白闪。无适用规则或无可采样帧的比例记为空 |
| 单格条件求值 | 使用原生 Excel 对照样本中的相对引用规则，3 轮 | 纳秒、分配字节、分配次数与原始各轮值。该耗时不含 XML 解码和磁盘读取 |
| 单元格读取与样式 | 同一 80×8 视口分别读取普通内联文本与四片段富文本，各测试样式开／关，3 轮 | 四种组合分别记录每视口的纳秒、分配字节及分配次数 |

完整矩阵可用 `node tools/bench/release.cjs --out=validation/1.19.0/private/run.json --save-baseline=validation/1.19.0/performance-baseline.json` 重建。快速诊断使用 `node tools/bench/release.cjs --smoke --only=conditional`。诊断结果不会登记为发行基线。仅在主机、工具链、测量代码、样本摘要、数据规模和重复次数均一致时计算跨版本差值。

## 1.8.19 历史读取实验

2026-11-17，ExcelLens 1.8.19。测试使用项目自带的`tools/largeprobe`，通过实际工作簿读取接口计时。

### 环境与数据

| 项目 | 配置 |
| --- | --- |
| 系统 | Windows 10 x64，19045 |
| 处理器 | Intel Core i7-9750H，6核12线程 |
| 内存 | 64GB |
| 磁盘 | NVMe固态硬盘 |
| 工具链 | Go 1.27.3 |
| 文件 | UTF-8 CSV，3列：编号、金额、分组 |
| 行数 | 1,000,000及5,000,000行，包含1行表头 |
| 统计方式 | 每组3轮，各操作取中位数 |

工具生成前导零编号、固定金额及分组文字。每轮使用新的文件和独立的应用缓存目录；文件生成后开始测试，操作系统文件缓存保持系统默认状态。重复打开和随机读取复用该轮已经建立的索引。

### 结果

| 文件规模 | 文件字节数 | 首次打开并建立索引 | 复用索引再次打开 | 随机读取100个区域 |
| --- | ---: | ---: | ---: | ---: |
| 100万行 × 3列 | 34,997,991 | 807ms | 73ms | 52ms |
| 500万行 × 3列 | 174,989,991 | 3034ms | 276ms | 44ms |

每个随机区域为80行 × 3列，计时包含100次读取的总耗时。工具逐阶段计时，并按既有探针逻辑在阶段前后执行垃圾回收；测试对象是工作簿读取接口，浏览器绘制有独立的界面测试。

各轮数据、文件SHA-256和运行条件见[机器可读结果](../../validation/1.8.19/reading-benchmarks.json)。每轮均核对文件内容和行数，测试结束后的源文件摘要与生成后相同。

### 复现

在仓库根目录执行，三个轮次分别使用新的输出目录：

```powershell
foreach ($round in 1..3) {
    go run ./tools/largeprobe -rows 999999 -out "validation/1.8.19/private/read-csv-1m-$round"
    go run ./tools/largeprobe -rows 4999999 -out "validation/1.8.19/private/read-csv-5m-$round"
}
```

`-rows`指定表头之外的数据行数。工具同时核对搜索、筛选、分组和完整CSV写出，详细结果保存到每个输出目录的`result.json`。原始生成文件和缓存位于忽略目录，公开结果只保留当前版的测量数据。

## 滚动渲染专项

主区最多并发三次读取，预测读取最多占两路。每次预测按滚动方向、逻辑像素速度、可视宽高和近期读取与提交耗时计算，最多排入 12,000 个单元格，并按近期每格字节估算进一步缩小范围。主区结构化缓存最多 32 块、估算 24 MiB，冻结区另有 6 MiB。超过缓存预算的单块可供当前视口使用。挂载窗口按实际可见行列和文字溢出计算，离屏复用池最多保留 384 个格。样式位图按工作表坐标分块复用，最多 48 块，共用 4,194,304 个物理像素。普通数字格可以复用已验证的样式及边框，源值和可点击坐标逐格绑定。服务及浏览器的实际工作集另外测量。

从待比较的两份源码分别构建 `./tools/uiprobe`，在同一台机器用同一份 `render_perf_qa.cjs` 依次运行。两个输出放在同一目录，脚本会核对工作簿摘要。每版默认三轮，每轮在 1120 × 780 CSS 像素、100% 和 125% 工作表缩放下，分别启动隔离 Chrome 采集计时和截图。测试文件含 1,600 行、96 列、七种底色、四种边框、合并、公式及富文本。轨迹按经过时间推进，包含连续纵移、高速纵移、高速横移、反向移动和一次远距跳转。

```powershell
$env:QA_UIPROBE=(Resolve-Path artifacts/qa/before.exe).Path
node tools/qa/render_perf_qa.cjs artifacts/qa/scroll/before.json
$env:QA_UIPROBE=(Resolve-Path artifacts/qa/after.exe).Path
node tools/qa/render_perf_qa.cjs artifacts/qa/scroll/after.json
node tools/qa/compare_scroll.cjs artifacts/qa/scroll/before.json artifacts/qa/scroll/after.json artifacts/qa/scroll/comparison.json
```

- 合成帧以数据区外的像素标记绑定实际滚动坐标。每条轨迹从收到的合成帧中选取首、中段和末段最多四个位置，回到相同坐标等内容稳定后逐像素比较。分母是稳定图中能确认为源填充或边框颜色的像素，排除文字和抗锯齿过渡色。记录同色面积、异常纯白面积及单帧最大白块总面积。中性占位单独反映在缺失的真实样式覆盖中。
- 计时轮在最多九个分布点核对实际鼠标命中元素的坐标和源显示值。独立的 `tools/qa/scroll_state_qa.cjs` 通过 Chromium 输入接口在正向和反向滚动中点击格子，检查实际点击坐标、选区地址和公式栏。此专项还在读取挂起时检查状态栏和两种主题下的网格底色。停止输入后计至内容核对成功且主网格覆盖当前位置。记录每条连续轨迹的 FPS、P95、P99 帧间隔。单次跳转报告呈现延迟。汇总表中的 P95、P99 是各轮、各缩放各自分位数的中位数。
- 缓存命中率为需要更新挂载窗口时，已经返回的结构化数据能直接满足前台查找的比例。取消率取 DevTools 实际报告的已取消工作表请求数除以发出的工作表请求数。逐帧采集 JS 堆、已挂载格数及缓存估算，另读取独立服务和 Chrome 渲染进程的生存期工作集峰值。
- 常规发行的 60 秒 CSV 测量保留其历史口径。其中 `emptyFrames` 统计页面同时缺少网格节点和占位层的次数。样式覆盖与白块面积使用上面的截图专项。
