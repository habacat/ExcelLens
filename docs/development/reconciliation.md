# 双表对账实现与验证

F02使用项目自己的纯Go来源投影、外部排序和归并核对，不增加依赖，不修改源文件或缓存编码。开发树仍使用1.8.18版本号，第二阶段尚未发布。

## 实现

`internal/reconcile`拥有字段规则、精确主键编码、归并分组、完整CSV及有界样例；依赖`analysis`的精确数值和`workbook`的共享排序。`workbook.SortKeyStream`接收不解释的比较键与递增源位置，复用`ELSORT01`、CRC及共享资源预算；不会复制一份排序或建立整表map。两个按需迭代器分别分配32MiB排序预算，合并时仅保留当前键组的首条记录和少量源行，重复成员同步输出，不做笛卡尔积。

来源适配放在`server/reconcile_source.go`。工作簿来源捕获已经完成的索引及行缓存；编辑表按完整内容摘要绑定，再复制所选列，限每侧16MiB。字段名摘要、完整名称哈希、是否实际读取及截取状态分开保存；自动建议仅用唯一完整名称。SQLite缓存的类型损失和占位歧义在Value和SourceInfo中显式表示，不修改或升级旧缓存含义。

根App的缓存读写锁跨标签共享，来源引用计数覆盖附件、任务和排队导出，上传落盘到打开登记之间也受保护。`snapshotReconcile`在任务表锁内取得独立来源引用，结果被清除、附件被移除后，已有导出仍可读取捕获快照。普通打开在共享缓存读锁内打开并登记，发布新工作簿后再等待旧任务结束，避免与缓存维护互相等待。

完整CSV重新运行同一不可变来源快照，核对全量计数，再通过公共导出任务、共享导出槽位、Sync和原子发布流程交付。读取失败、源键漂移、输出失败和取消不发布部分成功。定位则额外检查当前来源：外部格式检查源状态，XLSX/XLSM核对ZIP部件指纹，编辑表核对保存内容摘要；失效时拒绝定位，但保留旧结果和已有CSV能力。

浏览器使用`reconcile.js`和公共`analysis-jobs.js`，后者的默认分析语义不变。字段请求绑定来源序号与工作簿epoch；作业绑定开始请求和服务ID，取消后仍回收迟到的自有ID。结果来源独立于可编辑配置，源文字仅作为文本渲染。跨文件定位创建独立浏览器会话，编辑表定位按真实分页加载后聚焦。

## 当前证据

- Go核心与服务回归：源类型、前导零、Unicode折叠、精确百分比/会计金额、复合键、缺缓存、重复来源、取消、输出错误、源键漂移、字段名称摘要、编辑表变化、排队导出与清理引用。真实Windows SQLite适配器覆盖类型未保留、NULL/BLOB占位及源文件不变。
- 浏览器专项：真实服务和隔离Chrome，覆盖添加来源不换主文件、精确核对、源文字安全、同本/跨文件定位、编辑表第650行分页定位、完整保护CSV、配置变更、迟到取消和切档清理。桌面/窄窗口截图保存在忽略的private目录。
- 30万规模收据：两侧各300,001条生成记录，加未匹配、重复及空键；真实CSV适配器、来源模型、外部排序和服务导出。逐条核对300,011行CSV的键、源行、源值、状态和精确差额；确认实际产生排序段，落盘后取消并回收文件，两侧源SHA256不变。
- 百万规模收据：两侧各1,000,001条基础记录，加同样边界项；逐条核对1,000,011行完整CSV，10,310组精确差额、重复成员与两侧真实源行均一致；落盘后取消及源哈希核对通过。
- 完整标准检查：Go测试、vet、包边界、离线依赖及195项JavaScript回归通过。专项收据记录真实版本，不把目录名当成发行版本。
- 完整竞态检查：通过指定MinGW工具链运行完整`check -race`，包括新的任务、跨标签缓存锁、来源固定引用与导出生命周期。

30万场景按100ms采样的Go堆约40MiB，排序段采样峰值约61MiB；百万场景的导出阶段Go堆采样峰值约44MiB，排序段约204MiB。两组实测的比较/完整导出分别约4.4/7.5秒和14.4/23.3秒，不含首次索引。这些是本机合成场景的观测值，不是整个进程的内存上限或性能提升对照。合成数据、HTTP和无头浏览器均不等于桌面人工验收；不声称已经完成亿级对账或所有格式的人工核对。

## 复现

```powershell
go build -o artifacts/qa/uiprobe.exe ./tools/uiprobe
$env:QA_OUTPUT_VERSION='1.8.19'
node tools/qa/reconcile_qa.cjs

$env:EXCELLENS_RECONCILE_PROBE='.\validation\1.8.19\private\reconcile-scale'
$env:EXCELLENS_RECONCILE_REPORT='.\validation\1.8.19\reconcile-scale.json'
go test ./internal/server -run '^TestReconcileScaleRealSources$' -count=1 -v -timeout 12m
```

规模测试默认跳过，必须显式指定隔离生成目录；可用`EXCELLENS_RECONCILE_ROWS`选择300,001至5,000,001条记录，不作为应用容量承诺。`tools/qa/browser_harness.cjs`只启动自有服务和隔离浏览器，后续专项可共用。
