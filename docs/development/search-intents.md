# 搜索取消重试与来源守卫

接续状态见[实施待办](improvement-progress.md#接续入口)。本包处理只读搜索的请求归属，不改变搜索模式、缓存值或源类型。

## 修改前证据

负对照已复现两处缺口：

- 排队/运行中的同条件搜索被取消后，状态尚未结束时立即重试仍复用已取消的任务，无法取得新结果。
- 普通搜索定义了`Book`和`WorkbookKey`，但未核对它们；带旧来源身份或旧内容指纹的请求仍返回200。恢复搜索已有来源守卫，普通搜索应保持相同的请求归属。

回归位于`internal/server/search_intent_test.go`，同时保留正确绑定、未提供绑定的旧客户端，以及已完成结果被迟到取消后仍可复用的正向控制。O03原冻结版本的长时运行已完整结束并收尾，保留为历史基线。

## 修复方案

复用只对已完成的不可变结果或未取消的运行任务成立；取消中的任务不能接管新意图。普通搜索提供来源绑定时先核对，不提供时保留旧API语义。来源不符时在创建任务前拒绝，不能静默将旧请求套用到当前工作簿。

修复后应重跑定向与完整检查，并将取消后立即重试及错误来源拒绝加入候选版的30分钟真实HTTP负载。候选版须验证新实现，不能用修改前长时结果代替。

## 当前实施

普通搜索在创建任务前核对已提供的`Book`/`WorkbookKey`；旧客户端未提供时保留原语义。同条件只复用完成结果或尚未取消的运行任务，完成结果被迟到取消后仍可复用。修改未改变搜索模式、结果上限、源解释或缓存编码。

修复后首轮及1.8.19当前定向PASS，后者也覆盖O03历史容量及恢复准入。前端搜索请求已携带捕获的`Book`和`WorkbookKey`，旧来源请求会在创建任务前拒绝。当前开发版本为1.8.19，完整标准六步/503项JS、完整竞态七步及Linux纯Go编译均PASS；候选构建及独立包核验状态统一见实施待办。

1.8.19新冒烟PASS：35万条CSV、原生OOXML及磁盘行序，3轮/6份完整导出下载、4次排队取消、2次搜索立即重试、4次旧来源拒绝及一次切档。该12.30秒运行只验证新负载，不是新的30分钟结果。

新30分钟长时已实际退出0并PASS：预热后1803.59秒、369轮/738份完整导出下载，额外覆盖144次排队查询取消、72次搜索立即重试、144次错误来源拒绝及36次切档。56个完整静止样本均释放来源和查询文件，趋势脚本通过，资源图已逐项查看。该证据验证当前实现及本负载，未进行桌面或Office/WPS人工验收，不推及任意资料和运行时长。
