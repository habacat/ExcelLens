# F13 选区快速分析

接续入口及唯一下一动作见[实施待办](improvement-progress.md#接续入口)。本工作包只读，不新增格式、不更改数字显示偏好或源缓存版本。

## 契约核对与设计（2026-11-16）

已核对`selectionstats.js`、`profile.js`、`analytics-charts.js`及现有回归，后端`selection_stats.go`、`profile.go`、`selection_snapshot.go`、`selection_rows.go`、`selection_row_plan.go`和公共单句柄源行读取。现有状态栏已经提供多选区精确合计/平均/计数，详细画像已经提供全选区数值摘要、常见值及异常位置；不重复新增这些功能。

增补三个实际缺口：

1. **逐列完整分布**：每列分别统计负数、零、正数、空白、其他值、错误、缺少公式缓存及无法解析的数值。类别互斥、总数可核对；不将符号分布称为数值区间直方图或分位数（精确区间和分位数另见F19）。原生文字不转数值，导入文字金额沿用`sourceCellNumeric`和`AccountingDecimal`，不检测日期。
2. **明确配对的两列差额**：用户选择被减列和减列，只计算同一选中可见行中的“被减列 − 减列”。仅两侧都有有效数值才形成一对，其他行计为未配对，不以0补空白。不跨行配对，不将两列各自合计相减冒充有效配对差额。
3. **有界趋势小图**：沿当前选中可见行序，将全部行连续分为最多60段，每段保留完整数值数量、精确合计/平均/极值、首末源行及极值源格。图上平均值只是绘图近似，精确数据表及提示保留原结果；无有效数值的段留空，不跨空段连线。该分段不是抽样，极值并不等于趋势折线的点。

## 工程边界

- 独立入口为选区右键、命令面板和Ctrl+Q；详细画像入口保留。仅显式运行时读取，一个连续矩形（含单格），不扫描无关整表。选区列按源区间包含隐藏列，界面明确说明；行采用当前筛选/排序/显隐视图及冻结前缀。可显式跳过第一条选中可见行，默认不猜测表头。
- 请求必须携带内容身份、路径身份、工作表、行视图ID、筛选ID及源/可视端点配对。复用`selectionSnapshot`、`selectionRowView.plan`、源固定、缓存锁及共享查询槽；不新建整表行号映射、后台任务或结果持久缓存。同步HTTP请求可以取消排队及读取，失败整次拒绝。
- `internal/analysis/quick.go`负责精确、定长分段累加；服务层负责源类型判定和一次公共流式读取。每个源数值只解析一次，两列差额复用同一行已解析值。无浮点金额求和，不存储完整数列。
- `internal/formats`统一规定最多400,000格、16列、60段、8KiB请求、4MiB响应、64MiB累计源行字节及32MiB所选原文预算。读取前以流式计划核对源行偏移和累计字节，读取时核对原文；超限明确拒绝，不返回样本成功。预算是本操作边界，不宣称整个Go进程驻留上限。
- 浏览器只持有一个完整结果；来源、精确索引对象、epoch、筛选、行视图、冻结前缀、选区及运行意图共同守卫。关闭/切档/换选区取消并清空；同一选区重试失败或取消保留上次完整结果并明确标识。源字符串只进入textContent；小图复用现有图表及数字显示，不新增格式器。
- 不改变源值、源类型、源坐标、公式缓存或工作区/方案版本。不自动提交、发布或替换发行包。

## 实现与最终验证（2026-11-16）

本工作包源码及自动化收尾已完成，当前无活动检查、未完成草稿或未解决失败。用户指南见[选区快速分析](../user/selection-quick-analysis.md)，下一工作包只由[待办](improvement-progress.md#接续入口)维护。

- 核心在`analysis/quick.go`、`formats/selection_quick.go`及`server/selection_quick.go`。源数值资格和精确解析共享`sourceCellNumber`，导入文字共享`AccountingNumericValue`；同一源数值只解析一次，源值/类型/坐标、缓存编码及公式缓存语义不变。
- 界面在`selection-quick-model.js`、`selection-quick.js`及`selection-quick.css`，右键、命令、Ctrl+Q和统计窗口共用一个弹窗。候选封套/完整分段先验证，来源/索引/视图/冻结/选区变化清理；同一选区失败或取消保留上次完整结果。段号横轴避免长坐标挤压，点击图点和精确表保留完整行序/源位置。
