# 整体验证与长时运行基线

当前接续状态见[实施待办](improvement-progress.md#接续入口)。O03完善现有只读范围；不新增编辑、保存、格式或运行依赖。

## 验证设计

- 使用隔离配置、缓存及合成来源，在同一服务进程中运行至少30分钟的真实本机HTTP工作负载。短时冒烟只检查验证器本身，不计作长时通过。
- 两个标签页分别处理实际CSV与OOXML，交替执行筛选/精确多级排序、搜索、精确分析、完整导出和清除；额外覆盖排队取消、清除后的独立导出引用及切档。逐次核对完整结果和下载，来源哈希在采样及结束时保持。
- 预热后按固定间隔记录Go堆/协程、任务历史、来源固定、共享槽、查询临时文件及Windows进程私有内存/工作集/句柄。资源回到静止点后再比较，不将正常的在途资源或高水位当作泄漏。
- 任务、来源和临时文件按具体所有权/容量断言；内存以本工作负载的预热基线及变化记录评价，不据单次观测声称所有资料的内存上限或普遍性能提升。
- 失败保留进度和采样，先定位具体原因再修复；修改生产实现后重新运行受影响的基线及必要完整检查。该测试不等于用户桌面或Office/WPS人工验收。

## 当前审查

普通筛选只限制结果快照，没有限制`filterJobs`任务历史。搜索的磁盘缓存命中路径跳过历史回收，而现有搜索回收按显示终态判断，可能在工作协程完成落盘前丢失其所有者。负对照已复现：80次完整筛选/清除仍保留80项任务，缓存搜索从60项增至61项，尚未退出的搜索由60项被提前淘汰至59项。最初夹具误用`contains`模式，已纠正为既有`value`模式，原始日志留存为`stability-history-before-fixture-mode.txt`，不修改生产搜索语义。

修复统一保留60项查询任务历史，只回收真正退出的最旧任务；无安全回收项时明确限流，不能删除活动拥有者。普通、磁盘缓存和恢复任务共用容量语义；新建但未接纳的恢复点按自身修订回收，恢复已有任务被拒绝时保留原确认点，不误删用户进度。该方案不改变筛选结果快照、独立消费者、搜索内容或源缓存编码。

## 当前实施与证据

`query_history.go`共享真正退出的最旧任务回收，容量由`formats.QueryTaskHistory`维护；普通和恢复的筛选/搜索及磁盘缓存命中全部接入。容量及恢复点回归PASS，覆盖两种任务的普通、新建恢复、已有恢复六分支以及三个原始缺口。原借用筛选结果在清除/淘汰后仍可读取。

长时采样器位于被测包旁的`stability_soak_test.go`，Windows进程指标仅在`stability_soak_windows_test.go`中通过系统API采集，不增加生产依赖。真实本机HTTP轮流完整CSV/ZIP，逐行核对筛选原序、原值/精确聚合、ZIP CRC及下载摘要；每10轮强制排队取消及切档，静止后采样并检查来源/槽位/临时文件，按30秒保存RUNNING收据。仅删除自己已校验的隔离导出，不清理查询文件掩盖泄漏。

小规模冒烟PASS：1000行CSV及4条OOXML、3轮/6份完整导出和下载，含排队取消/切档。初次草稿缺少测试import的编译日志已保留；该冒烟只验证采样器，完整和长时结果分别记录在下方。

当前35万行冒烟PASS（16.70秒）：3轮、6份完整CSV/ZIP及真实下载逐字节摘要，映射行序实际存在并在归还消费者后回收，完整原序/数值/精确聚合及源哈希保持，排队查询取消2次、切档取消导出1次。Windows私有内存/工作集/句柄与Go堆/协程均取得真实采样；该收据标记`smokeOnly:true`，不等同30分钟长时结果。

正式运行使用35万条实际CSV与4条原生OOXML，预热8轮后连续负载至少1800秒。`stability-http-long.json`每30秒更新RUNNING、实际进程ID、完整轮数/下载数及采样，最终才写PASS或FAIL；会话1439已实际退出0，总1871.33秒（含预热），长时PASS。最终资源趋势、图及代码核对均已完成，见“首轮长时收尾”；不用中途值代替最终结论。Linux纯Go编译已PASS。O02/O03维护说明已加入唯一发布清单，候选构建另由O04记录。

最终完整标准六步及503项JS和完整竞态七步均PASS，包含新的查询历史/恢复准入和既有功能回归；两会话均退出0。长时负载和趋势也已分别通过，保留各自收据，不以完整检查代替长时结果。

静止点的判定包括来源固定/来源预算和共享工作槽全部归零、查询临时文件归零、筛选/搜索历史不超过60项、分析不超过12项、导出不超过26项。第8轮预热后，GC后的Go堆相对基线增加超过128MiB、协程超过基线32个或句柄超过基线64个均判失败；进程私有内存/工作集记录为观测值，须在最终样本中检查趋势，不当作整个应用的通用上限。
