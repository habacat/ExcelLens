# 查询和导出恢复

F21已完成源码和自动化收尾。当前标准480项JS、Go完整竞态及浏览器11组均通过；收尾核对保存当前代码、实际服务资源、重启/下载、截图及边界。唯一下一动作见[实施待办](improvement-progress.md#接续入口)，历史基础收据不替代当前版本，源码及自动化通过不代表已经提交、发布或人工验收。

## 目标与边界

任务恢复独立于可清理的工作簿缓存，只在用户明确操作后执行；打开文件、重启、列目录和滚动不自动恢复或扫描。F01页面输入恢复、已完成搜索缓存和导出重试各有用途，不能替代实际任务续做。源文件继续只读，不新增格式、运行依赖或源缓存编码。

检查点绑定操作/驱动及语义版本、来源路径/内容/解析身份、声明式规则和范围。只确认完整记录或完整阶段；源变更、损坏、超限及无法确认的阶段必须拒绝或明确重跑，部分结果不能伪装成完成。缓存已清理或精确索引改变时，当前搜索驱动明确要求重新运行，不暗中重建后跳过已确认记录。

## 持久检查点基础

`internal/checkpoint`只拥有持久块和游标，不解释CSV、XML或查询算法。`os.Root`约束任务目录，Windows使用`LockFileEx`、常用Unix使用非阻塞`flock`；其他平台明确拒绝需要可靠租约的操作。跨进程只有一个写入者，目录准入同时计入已保留文件和进行中的空间预留。

`ELCPST01`严格JSON封套校验版本、长度、SHA256、唯一键和深度；`ELCPBL01`块校验完整字节/记录数、顺序及链式摘要。先写完整块并Sync，再原子安装确认游标；恢复验证整个确认前缀后才裁掉未确认尾部。失败或不确定写入保留证据，不盲目重试提交；主槽损坏直接拒绝，主槽缺失才明确标记备份。删除由用户触发，活动租约不能删除。

中央容量位于`internal/formats/checkpoint.go`：最多32任务、8 GiB共享空间，128 MiB单块、256 KiB清单、64 KiB游标/请求及固定64 KiB流式缓冲。单次搜索最多500项命中及16 MiB恢复预算；保留命中前按JSON最坏转义保守计费，容量失败不截断原文或伪造完成。普通搜索不套用持久搜索的字节容量。

## 搜索恢复契约

`workbook/search_resume.go`复用原普通值、公式、引用、高级DSL和外部行缓存读取器；不另写解释器。保留原值显示、真实坐标、共享公式、缺缓存公式文字、正则大小写和500项截断语义。只在完整源记录后前进游标；命中上限落在半行时保存独立终态，不将半行登记为完整记录。回调和初始状态使用独立副本。

`server/search_checkpoint.go`的`source-search`驱动语义版本为1；解释、呈现或恢复游标改变时必须更新该版本。来源路径/内容/解析及工作表原序与声明式规则共同绑定，普通搜索按既有大小写折叠，高级搜索保留大小写。`SearchSourceStamp`另绑实际Workbook拥有的精确索引、行缓存及源内容；可靠文件修订直接核对，不具备可靠修订时用有界缓冲SHA256回退，不能只相信大小或修改时间。

每4096条完整记录保存小游标，仅新增命中写入块。全簿按原工作表顺序确认完整阶段，重启可跳过已确认记录；完成任务重放不追加新修订。新驱动显式选择，既有普通全簿搜索的并发路径保留；不据此宣称普遍提速。

任务复用原搜索状态、取消、共享查询/索引槽、来源固定及切档/关闭生命周期。租约在排队前取得，收尾释放；取消保留最后确认点。`checkpoint_retry.go`仅对尚未改变持久状态的目录锁忙做最多约1秒、可取消的短重试；不确定写入、冲突、损坏、容量和磁盘故障直接返回。任务租约竞争仍明确拒绝。
