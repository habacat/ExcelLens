# 界面设计规范

适用 `internal/ui/web` 下的页面、样式和脚本。新增或修改界面时先读本文，再读相关实现与测试。

## 取向

网格是内容，界面外框是工具。外框使用中性底色和一种强调色，不与工作表里的原始格式争抢注意力。Excel 用户熟悉的位置保持不变：名称框和公式栏在网格上方，工作表标签和状态栏在下方，右键菜单和常用快捷键沿用 Excel 的习惯。

强调色取自应用图标的深绿色，用于主操作、选中状态和焦点。琥珀色只表示“查到的内容”，例如搜索命中、定位结果和审计标记。蓝色只用于单元格地址和公式引用。红色只用于失败和破坏性操作。

外框高度直接挤占网格行数。经典布局顶部单行高 37 像素，选项卡布局展开时顶部两行共 73 像素，公式栏 35 像素，底部工作表标签和状态栏共 49 像素；功能区折叠后顶部只剩 37 像素。新增常驻元素前先确认它不增加这些高度。

## 令牌

颜色、字号、圆角和阴影只在 `style.css` 开头定义。组件样式引用令牌，不写颜色字面量。护眼预设在 `themes.css` 中改写同一组令牌，组件不需要为预设单独写覆盖规则。

| 令牌 | 用途 |
| --- | --- |
| `--paper` | 网格和文档区域的底色 |
| `--surface` | 工具栏、弹窗、菜单、输入框和带边线按钮的底色 |
| `--inset` | 表头、状态栏、列表标题、弹窗内的说明块等凹陷区域 |
| `--canvas` | 首页和分析工作区卡片后面的页面底色 |
| `--ink` `--muted` `--faint` | 正文、次要文字、占位和快捷键提示 |
| `--line` `--line-soft` `--line-strong` | 控件边线、列表内细线、悬停边线 |
| `--accent` `--accent-strong` `--on-accent` | 主操作及其悬停状态、主操作上的文字 |
| `--active` `--accent-line` | 选中项和按下状态的底色与边线 |
| `--hover` | 中性悬停底色 |
| `--danger` `--warn` `--ok` 及各自的 `-soft` `-line` | 失败、提醒、成功 |
| `--ref` | 单元格地址、公式引用、链接 |
| `--mark` `--mark-soft` | 搜索命中、定位结果、审计标记 |

列表行、幽灵按钮和状态栏里的控件不设底色，悬停时才用 `--hover`。默认配色和深色预设里，三档文字在 `--surface` 和 `--inset` 上的对比度都不低于 4.5:1，深色预设由 `tools/qa/reading_theme_qa.cjs` 逐个面板核对。浅色预设沿用原有的柔和配色，次要文字在 `--surface` 上为 3.9:1 到 4.7:1，第三档文字在这些预设里与次要文字同色，不再变浅。

字号使用 `--fs-1` 到 `--fs-5`，对应 11、12、13、15、18 像素。界面文字不小于 11 像素，控件和正文使用 13 像素。数字使用等宽数字。公式和地址使用 `--font-mono`。

控件高度：状态栏内 22 像素以下，顶栏和公式栏的输入框 26 像素（`--ctl-bar`），工具栏按钮 28 像素（`--ctl-m`），弹窗内 32 像素（`--ctl-l`）。名称框、公式栏、输入类型和字体下拉在阅读和编辑两种状态下尺寸、字号和边线一致。圆角按元素大小取值：控件 6 像素，菜单和卡片 8 像素，弹窗 12 像素。

网格的行高、列宽、表头尺寸和选区线宽由脚本计算，不属于界面令牌，改动需按网格的像素验收流程进行。浅色预设通过叠色给网格着色，所以网格使用独立的 `--grid-*` 令牌，只有深色预设才让它们跟随调色板。分页预览纸面和 `.cell-rich` 的规则会被内嵌进导出的离线文件，必须保持字面量。

## 组件

同一种控件只有一种写法。新界面复用下表的类名，不新增同义类。

| 类名 | 用途 |
| --- | --- |
| `primary-button` | 弹窗或面板里的主操作，每个界面最多一个 |
| `mini-button` | 普通按钮 |
| `tool-button` | 功能区和工具栏按钮，图标加文字 |
| `icon-button` | 只有图标的按钮，必须带 `aria-label` 和 `title` |
| `field-control` | 输入框、下拉框和多行文本 |
| `float-dialog`、`dialog-head`、`dialog-title`、`dialog-close`、`dialog-body`、`dialog-actions` | 弹窗及其标题栏、正文和操作区 |
| `menu`、`menu-item`、`menu-divider` | 下拉菜单和右键菜单 |

图标只有一套，定义在 `index.html` 开头的 SVG 符号表里，以 `<svg class="icon"><use href="#i-名称"/></svg>` 引用。图标按 24 单位的方框绘制，描边宽度一致，图形的外接框中心落在方框中心；新图标偏离中心时调整符号的 `viewBox` 原点，不改引用处。不用字符充当图标。只含一个图标或字符的按钮用弹性布局居中，内边距为零，行高等于字号。

需要保持网格可见的工具使用不遮挡网格的面板，例如搜索、定位和追踪。只做一次设置的操作使用居中弹窗，例如导出、排序和冻结。打开后才填入内容的弹窗固定上沿，例如单元格信息，内容变长时标题和关闭按钮留在原处。

需要用户输入一个值或确认一次操作时，使用 `overlays.js` 里的 `ExcelLensOverlays.ask` 和 `ExcelLensOverlays.confirm`，不使用浏览器的 `prompt`、`confirm`、`alert`：它们样式不一致，会阻塞页面，被浏览器屏蔽后还会静默失效。输入无效时在弹窗内提示并保留输入；破坏性操作的确认按钮用 `primary-button danger`，默认焦点放在“取消”上。

通知只报告结果，不接收鼠标事件，不挡住下面的控件。右下角的显示设置面板打开时，通知移到面板左侧。

选区框固定为 2 CSS 像素，按每段实际表格线的中点定位。无表线时沿单元格几何边界绘制。7 CSS 像素见方的填充柄以可见右下角两段选线的交点为中心，整个方块可接收拖动。行列高亮延伸沿用同一套网格坐标。缩放、调整尺寸、显示或隐藏列这类不一定引起滚动的布局变化，经由 `relayoutGrid()` 统一重绘它们。

## 功能区

默认经典布局将常用命令排在文件名和可伸缩的“查找功能”之间。公式栏两侧只显示工具图标，名称通过悬停提示和无障碍标签提供。字体图标由统一样式的下拉选择框驱动，保留键盘选择、字体预览和当前字体高亮提示；所有单选下拉、文件选择、进度条与折叠控件均复用同一套表面、边框与悬浮菜单令牌，不暴露浏览器默认弹窗样式。保存结果按内容占宽，剩余空间给公式。两种布局移动同一组控件，偏好保存在用户配置目录，调整时不发起索引或分析查询。

选项卡布局的顶部第一行是文件名、选项卡和命令搜索，第二行是当前选项卡的命令。每个命令只出现在一个选项卡里，命令搜索列出全部命令。从命令搜索执行某个命令时，功能区切到它所在的选项卡。

| 选项卡 | 命令 |
| --- | --- |
| 开始 | 打开、导出、编辑副本、复制、搜索、筛选、清除筛选、排序、冻结、分析、统计、计算 |
| 数据 | 高级筛选、TXT 表头、查重、定位条件、数据规则、记录卡片、快速分析、转置 |
| 公式 | 显示公式、追踪引用、追踪从属、名称与表 |
| 视图 | 列、行与大纲、原格式、图片、字体、命名视图、分页预览、全屏 |
| 核对 | 对账、关联、标记、比较快照、任务恢复 |

宽度不足时，排在后面的命令收进“更多”菜单，不会消失；很窄的窗口只显示图标，名称留在悬停提示里。功能区可以折叠（Ctrl+F1），折叠后点击选项卡临时展开。文件名在任何宽度下都留在顶栏。进入编辑副本后，顶部只留一行：文件名、编辑状态和编辑命令；窗口较窄时命令另起一行。

命令搜索按空格分词，每个词都要出现在名称、检索词或快捷键里；名称匹配的排在前面。命令改名时把原名加进检索词，原来的叫法仍然能找到。

## 文案

界面只显示操作需要的标签、结果和状态。说明性文字放到用户文档。

- 按钮和菜单项用动词或名词短语，同一操作在按钮、提示和结果里使用同一个名称。
- 悬停提示只写名称和快捷键。
- 不重复“只读”“不修改源文件”之类的保证，文件名旁的状态标记已经表达。
- 影响操作结果的限制、未知状态和失败必须写明，并说明下一步能做什么。
- 进度文字与实际状态一致。扫描结束而结果还没显示时写“正在显示…”，结果可用之后才写“完成”。
- 空状态给出可以直接执行的操作。
- 首页标题“浏览数据”和副标题“浏览Excel、CSV、TXT与SQLite”是既定文案。文件能否打开由 `internal/formats` 判断，界面不另建支持名单。

## 验证

样式或结构改动后执行 `go run ./tools/project check`。涉及布局的改动另用无头浏览器核对，脚本在 `tools/qa`，需要先构建 `tools/uiprobe`，并用 `QA_OUTPUT_VERSION` 把开发期收据与已发行版本分开：

| 脚本 | 核对内容 |
| --- | --- |
| `toolbar_layouts_qa.cjs` | 经典布局、命令查找、两处切换与缓存清理后重开 |
| `toolbar_ui_qa.cjs` | 功能区在 8 种宽度和 4 种像素比下的可见性、溢出菜单、选项卡、折叠、命令搜索 |
| `edit_grid_ui_qa.cjs` | 编辑状态顶栏和公式栏在各预设、各宽度下的尺寸与对齐 |
| `reading_theme_qa.cjs` | 12 个护眼预设下各面板的底色、对比度和还原 |
| `icon_alignment_qa.cjs` | 图标在按钮内的居中、图形居中和点击目标 |
| `notifications_qa.cjs` | 四种通知语气的颜色和角色 |

截图和脚本产物放在忽略目录，不随包。单元测试和无头浏览器检查不等于桌面人工验收。
