# 工具栏、浮层与冻结刷新

本记录对应O05～O07，当前接续和整包门禁只由[实施进度](improvement-progress.md#接续入口)维护。保持现有纯Go运行依赖、源值/类型/坐标和只读语义，不更改缓存编码。

## 右键菜单的绘制归属

网格使用`isolation:isolate`保护单元格、合并、冻结及图片的绘制层级。原单元格菜单、尺寸菜单和提示位于该隔离层内；位于其外的彩色Sheet标签即使没有较高z-index，也能盖住菜单。三个固定视口浮层移到既有列菜单同级，保留原定位、事件和网格隔离。

修改前真实命中复现标签截获点击；修改后8组检查两类菜单覆盖/点击、1200/900/420px、不同DPR、冻结和更换活动彩色标签。菜单退出后Sheet标签仍可正常切换。

## 冻结表切回被误报为读取失败

暖切表等待冻结刷新时，普通调度也可能请求相同目标。原实现无条件取消前一次读取，使原生AbortError冒泡为整表读取失败；行视图过期后更换ID会让这条路径无法命中旧冻结缓存。

`FrozenPanes`以既有完整目标键共享在途读取，保留一个任务拥有者。新目标、重置和无有效冻结均取消旧读取；只有自身取消/已过期任务不再冒泡，当前真实读取失败仍抛出并取消兄弟部件，旧任务的finally不能清理新任务。三个部件完整成功及来源守卫通过后才绘制，不发布部分冻结状态。

行为负对照与最终定向分别保存失败/修复结果。私有样本修改前证明后端索引/读取正常且前端问题可复现，修复后摘要验证同一原文件切回正常、源SHA256不变；真实文件、名称和画面仅存忽略目录。

## 工具栏按实际空间布局

沿用白色`#fff`、分隔线`#dfe4e9`、主文字`#26384b`、次文字`#536274`和操作蓝`#2563a6`，保留Segoe UI/微软雅黑及11px按钮文字。布局以文件身份和常用操作为先，低频操作通过既有命令面板查找，不增加说明段落。

`toolbar.js`观察工具栏实际容器、可用状态和文字变化，合并到一次动画帧；实测按钮宽度及间距后按显式优先级收放。打开、搜索、筛选、排序、导出、分析和命令保持可达，必要时分行；首页、冻结、统计、计算等按空间显示，移出控件仍调用原按钮事件与禁用条件。移走正在聚焦的控件时将焦点交给命令入口。尺寸变化只改布局，不直接读取来源或运行分析。

公式栏按自己的容器宽度隐藏低频入口，字体和单格详情仍可使用。命令面板完整显示静态命令，匹配大量Sheet时只渲染当前键盘项附近的有界窗口；同步失败也进入已有错误反馈。

20项定向和实际浏览器验证320～1600px、不同DPR、单独容器变化、16个低频入口、7种实际控件及第80张Sheet的键盘选择；原源哈希不变。旧裁切与缩字失败收据保留，不将自动浏览器描述为用户桌面或Office/WPS人工验收。
