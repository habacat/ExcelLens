## 拟定方案

- 用户显式选择分布并分析才排序。全部数值按既有`sourceCellNumber`资格进入；原生文本、编号、空白、错误及缺结果保留原状态。不静默抽样；本包优先实现全量精确结果，超预算明确拒绝。
- 共用计算器的包含端点分位位置和精确插值，提供P5/P25/P50/P75/P95。计算只使用有理数，输出不经过float64；已有近似绘图和显示偏好不改写结果。
- 复用`SortKeyStream`背后的有界排序run/合并/共享磁盘预算，为已判定数值提供内部规范有理数键。不同源格式共用同一数值资格；该内部排序不能成为源文本的另一套识别器。
- 单次源扫描计算精确摘要及现有频次，外部排序输出阶段只保留需要的分位位置，并生成精确等宽区间计数。排序内存、源行、累计文字、请求和完整响应由formats统一维护，失败不发布部分分布。
- 沿用`selectionRowPlan`和公共源行引用流，保留完整筛选/可见行/冻结语义及源坐标，不展开百万行号。请求绑定内容/路径/Sheet/精确索引/筛选/视图，复用源租约和查询槽，读取前后核对。
- 沿用数据洞察弹窗；简短选项、结果表及条形区间即可，算法和追溯说明放本文及用户文档。取消/切档/行视图变化不能让迟到响应替换当前结果；缩放重绘不查询。

已核对`profile_fidelity_test.go`、`analysis_selection_test.go`、`row_view_test.go`、`work_budget_test.go`、`inspection.test.cjs`、`key_stream_test.go`及计算器扩展统计回归。旧`/api/profile`不带分布选项时保持原计数/范围语义；新增`distribution`显式选项，分布请求必须携带内容/路径及当前绑定视图。手输源范围仍可独立于当前可见视图，以绑定视图仅校验来源；拖选继续使用成对可视端点和冻结前缀，不能把这两种范围混用。

旧手输范围与完整筛选相交时，用`RowSet.LowerBound`及源位置顺序直接流式读取；可视拖选沿用`selectionRowPlan`。二者不展开行号数组。全量分布按包含端点的线性分位定义计算5个点、10个等宽区间（常量为1区间，无数值为空），区间只作精确计数，金额合计保持精确。

排序复用既有run格式和共享磁盘配额。数值键仅接受有长度限制的整数字符串或整数分数；float64只作单调的比较快路径，溢出饱和、相等时回到原有精确有理数比较，不能改写结果或扩大源文本资格。取消和任一失败释放临时文件，完整成功后才返回响应。下文按历史验证顺序保留证据，算法、接口和界面均已完成，最终结果见末节。
