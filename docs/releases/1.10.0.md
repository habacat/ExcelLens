# ExcelLens 1.10.0

在编辑副本里选中透视表，打开 **透视布局 → 日期筛选**。可以指定一天、一个区间，或让报表每次刷新时显示本周、上季度、年初至今等时段。区间默认包含结束日的全部明细。勾选 **精确到时间** 后，可比较到秒。已分组的日期也可直接筛选，各层小计和总计随筛选结果更新。 [编辑操作](../user/editing.md)

## 网格与公式

- 整块剪切可跨工作表移动并更新引用，粘贴可保留合并结构。支持重叠区域、撤销、重做和保存重开。 [区域传输核验](../../validation/range-transfer/transfer.json)
- 表尾输入或一次粘贴多行会扩展表格，带上计算列、汇总行和筛选范围。透视表可配置多个值字段，分别选汇总方式，并使用标签筛选和日期分组。 [表格范围](../../validation/table-resize/resize.json) · [透视布局](../../validation/pivot-fields/pivot.json)
- 公式录入可根据引用选择日期、金额、百分比和时长格式。十月费用表的 513 个公式共用跨表区域时，同机成对测量的单格确认中位数从 378 降至 69 毫秒，生成下载件从 1,203 降至 767 毫秒。 [原生格式矩阵与性能测量](../../validation/formula-formats/verification.json)

## 日期筛选核验

Excel 16.0 Build 20326 的参照覆盖 1900 和 1904 两种日期系统、整天与精确时刻、跨年周、年月季和日期分组。四川费用报表使用同一批 239 条明细建透视表，逐格核对了修改、刷新、两次撤销、两次重做，以及 Excel 再刷新、另存和重开。9 组共 498,960 格次，数值最大差异为两个双精度浮点间隔。 [日期筛选收据](../../validation/1.10.0/pivot-date-filters.json)

透视编辑适用于本簿内可刷新的矩形数据源。外部数据模型维持原有编辑边界。本次互操作核验使用原生 Microsoft Excel 和浏览器自动化，WPS 与桌面手工验收未执行。
