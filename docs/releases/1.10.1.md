# ExcelLens 1.10.1 本地试用

在编辑副本里输入 `=SUM`，按 **Tab**，再拖选一块区域。输入逗号后可以切换工作表，继续点选要相加的格。按 **Enter** 回到原工作表并确认公式。网格和公式栏共用函数候选、参数提示及引用选框。 [操作方法](../user/editing.md)

行列高亮可一直延伸到工作区底边和右边。切换配色、冻结窗格或调整窗口大小时，两侧延伸跟随当前单元格。选中区域继续使用原有选区样式。

本版供本地试用。十月费用报表的跨表公式已在 Microsoft Excel 中独立录入，对照修改、撤销、重做和另存重开的结果。另用带空格和单引号的工作表名称核对引用转义。

三组浏览器操作含 390 像素宽窗口，共在 Excel 打开及另存重开后核对 7,296 格次。高亮通过八个显示状态的几何核对，另在两种像素比例下比较网格内与两侧空白的色值。 [交互与像素收据](../../validation/1.10.1/interaction.json)
