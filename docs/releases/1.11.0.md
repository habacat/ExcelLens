# ExcelLens 1.11.0

编辑副本可拖动选框右下角，向四个方向复制公式或延伸数列。从 Windows Excel 或其他 ExcelLens 标签页粘入工作簿区域时，网格可接收单元格类型、公式、数字格式和合并区域。筛选后的多行粘贴按可见顺序落到对应的源行。

公式栏和格内输入支持 XLOOKUP、LET、工作簿名称及表字段补全。工作表标签旁的加号可新建工作表，在标签上点右键可复制、重命名或删除。长编辑历史会自动整理，重开副本后仍可撤销和重做最近的修改。[网格编辑](../user/editing.md) · [剪贴板](../user/clipboard.md)

发行前复核修正了隐藏行列的粘贴、共享公式原坐标、工作表活动页、公式补全取消及粘贴期间切换目标。Windows Excel 的筛选、隐藏行列和跨日期系统案例通过修改、撤销、重做和保存重开对照。十月报表的总账小选区热复制中位数从约 51 毫秒降至 15–21 毫秒。含 2,000 笔编辑的副本热重开从 107 毫秒降至 83 毫秒。[三轮复核](../../validation/1.11.0/prepublication-review.json)

工作表公式候选由 83 个增至 243 个。实际销售费用表的 16,602 个公式在原始、修改、撤销和重启后重做四态完成 66,408 格次核对。连续 4,101 笔编辑跨过原历史上限后，恢复修订、重试、撤销和重做均通过。19 组原生对照覆盖 57 个修改、撤销和重做状态，两个保存重开环节分别比较 1,619 格次。Windows Excel 到浏览器的 Ctrl+V 和右键粘贴另有独立验证。桌面人工与 WPS 验收未执行。[逐项核验](../../validation/1.11.0/workbook-editing.json)
