# ExcelLens 1.12.0

### 台账核查

- 工作簿版本比较支持按原坐标逐格核对，也支持在所选两张表上按业务主键对齐。报告列出新增、删除、相对移位、公式和类型变化，保留两期源坐标。重复或无效的主键逐行列为待核。
- 数值比较字段可设置绝对容差。精确一致、容差内的非零差额和超限差额分别呈现。核查包保存原件 SHA-256、字段映射、阈值、匹配规则、数量和明细，支持换批重跑与逐项跟踪。规则 1 的旧记录可以按原语义重跑。[双表核对与版本比较](../user/reconciliation.md)

### 阅读与交付

- ODS 可只读打开、搜索、筛选并导出。重复行列按区间索引，保留前导零编号、显式日期、布尔值及 OpenFormula 原文。[格式边界](../user/formats.md)
- 大选区先尝试完整的轻量 TSV，超过预算后直接进入选区导出。[复制与导出](../user/clipboard.md)
- 已确认的分页可导出成离线 HTML，通过浏览器打印或另存为 PDF。支持指定页段与整本可见工作表。[分页底稿](../user/printing.md)
- 可查看传统批注，将选中的复核标记写入独立副本，并在当前编辑修订上执行目标求解和单、双变量试算。[编辑与试算](../user/editing.md)

### 本地服务与兼容性

HTTP 入口按本机实际监听地址和端口校验 Host 及浏览器来源。查询、编辑、导出和工作簿会话分别管理资源，后台任务为前台定位和滚动保留名额。遇到安全问题可通过[维护者报告渠道](../../SECURITY.md)联系。

程序继续以纯 Go 构建，Windows x64 压缩包包含运行程序及离线指南。原生 Excel 对照覆盖传统批注另存重开和试算，WPS 与桌面人工验收待验。

在两张各 25,000 行的合成台账中，报告正确识别一处插入、一处删除、一处相对移位和一格值变化。规则 2 和规则 1 对同一组三笔非零差额分别识别一笔与三笔超限或精确差异。打印底稿逐页核对了两表的 126 条明细。[本版工作流核验](../../validation/1.12.0/workflow-verification.json)
