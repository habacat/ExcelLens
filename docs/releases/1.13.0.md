# ExcelLens 1.13.0

## 阅读和核对

- “开始、数据、公式、视图、核对”五个选项卡集中常用操作。Ctrl+K 支持按多个词查命令，也可以输入工作表名称。Ctrl+F1 折叠功能区，点选项卡可临时展开。[界面与快捷键](../user/interface.md)
- 窗口变窄时，次要操作进入“更多”，其中也可以选择显示字体。编辑副本时，顶栏显示文件名、修订状态和编辑操作。[编辑副本](../user/editing.md)
- 打开工作表后即可查看数据规则。缩放、调整列宽或隐藏列后，选区边框和行列高亮随网格重绘。快速分析会列出计入结果的隐藏列。[数据规则](../user/data-rules.md) · [快速分析](../user/selection-quick-analysis.md)
- 按钮、菜单和弹窗使用一致的配色和键盘焦点。护眼模式保留错误和提醒各自的颜色。删除标记的确认绑定发起操作的工作簿，行高与列宽输入无效时可直接在弹窗里更正。
- 筛选结果显示就绪后才提示完成，此时可以保存命名视图。[命名视图](../user/named-views.md)

## 验证范围

在独立的无头浏览器中核验了 320 至 1600 像素宽的功能区、编辑栏在 13 种配色与 5 种窗口设置下的 65 组布局，以及 XLSX 和 BIFF8 的 60 组字体、缩放与像素比组合。另行验证了两份工作簿使用相同标记 ID 时的删除确认。本版未进行桌面人工验收、原生 Excel 或 WPS 对照及整表性能测试。[本版工作流收据](../../validation/1.13.0/workflow-verification.json)
