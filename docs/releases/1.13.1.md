# ExcelLens 1.13.1

默认恢复经典单行工具栏。打开、搜索、筛选、排序、导出和分析与文件名同排，名称与表、数据规则、记录卡片、显示字体、复制和追踪回到公式栏。按钮沿用 1.13.0 的图标与配色，“查找功能”会随可用宽度伸缩。

右键顶部按钮区或 Windows 托盘图标，勾选“选项卡布局”即可使用五页功能区。两个入口共享用户偏好，重启后仍生效。[工具栏与托盘](../user/interface.md)

托盘新增“打开程序所在目录”和“清除所有缓存（含当前）”。确认清理后，各工作簿返回首页，再次打开时重新建索引。原件、上传副本、已保存的编辑修订、标记和设置均保留。

本版以生成工作簿验证 320 至 1920 像素宽的经典布局、选项卡模式、编辑栏及清理后的重开。实际 Windows 托盘指针交互及 Office 人工对照未执行。[工作流核验](../../validation/1.13.1/workflow-verification.json)
