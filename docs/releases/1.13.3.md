# ExcelLens 1.13.3

行列高亮现在按点击位置的实际行高和列宽穿过合并单元格。直接点击合并区域内部时，横线和竖线跟随落点，选框仍围住整个合并区域。阅读和编辑副本共用这一行为。

单选或拖选时，选框固定为 2 CSS 像素宽，中心对齐原工作表边线。遇到粗线、细线、双线或合并表头，选框保持同样粗细。无边框时对准单元格边界。右下角填充柄的中心位于右边线和下边线的交点，从方块内任意位置都可以开始拖动填充。修复部分显示比例下相邻行底色遮住表格线的问题。

经典公式栏的常用操作改用图标，鼠标悬停可查看名称，长公式获得更多显示空间。底部工作表标签按名称排布，标签间增加淡分割线。选框、行列高亮设置和双击编辑框随所选颜色更新。[界面与工作表](../user/interface.md)

状态栏的选区统计支持平均值、计数、数值计数、最小值、最大值和求和。可切换中文单位、千位分隔、万位分隔或原数。复制统计结果保留完整数值。

合并高亮修复通过了 27 组开关高亮前后的像素对照，覆盖不同行高和列宽、冻结行列、缩放、编辑副本及深色主题。在实际费用报表的 J2:Q2 合并表头，点击 J7、K7 和 L7 分别只标出 J、K 和 L 列。Windows 工程检查及 560 项前端回归通过。[工作流核验](../../validation/1.13.3/workflow-verification.json)

此前的填充柄修订在实际明细账、费用报表和合成工作簿上验证了 56 组选区，包含合并表头、冻结窗格、缩放和反向拖选。填充柄实绘中心与右下交点的最大偏差小于 0.003 个物理像素，拖动填充和撤销均通过。
