# ExcelLens 1.13.3

单选或拖选时，选框始终保持 3 CSS 像素宽，中心对齐原工作表边线。遇到粗线、细线、双线或合并表头，选框保持同样粗细。无边框时对准单元格边界。右下角填充柄支持拖动。修复部分显示比例下相邻行底色遮住表格线的问题。

经典公式栏的常用操作改用图标，鼠标悬停可查看名称，长公式获得更多显示空间。底部工作表标签按名称排布，标签间增加淡分割线。选框、行列高亮设置和双击编辑框随所选颜色更新。[界面与工作表](../user/interface.md)

状态栏的选区统计支持平均值、计数、数值计数、最小值、最大值和求和。可切换中文单位、千位分隔、万位分隔或原数。复制统计结果保留完整数值。

无头浏览器在实际明细账、费用报表和合成工作簿上验证了 89 组选区，包含普通、合并、冻结、缩放和反向拖选。Windows 工程竞态检查与 559 项前端回归通过。[工作流核验](../../validation/1.13.3/workflow-verification.json)
