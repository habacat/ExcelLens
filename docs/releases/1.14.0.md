# ExcelLens 1.14.0

## 备份与迁移

从「本地数据」提交备份或迁入，关闭页面后可重新查询进度、错误和完成位置。明文备份继续兼容 1.13.4。填写口令可加密文件内容、原始文件名和校验清单，使用 Argon2id 和分块 AES-256-GCM。外部原件需随备份另行转移。

恢复会先验证全部文件及目标冲突，再记录提交决定。程序中断后使用目标电脑上的暂存数据继续发布，核对已经迁入的单元。开始提交前可以取消。存储介质损坏仍需从完整备份恢复。

在「重定位来源文件」核验并确认新文件后，编辑历史和可恢复任务沿用已有修订。迁移记录保存原路径、历次路径和时间。新任务支持按内容核验重建的索引。在旧电脑上使用本版备份时，也会为可读取的旧来源和可验证的旧索引补充证明。旧备份缺少相应证明时会报告原因。[操作说明](../user/interface.md)

## 后台任务

搜索、筛选、独立分析、双表对账和导出在页面关闭后可继续执行。从「本地数据 → 后台工作簿任务」查看进度及结果。程序运行期间，任务完成后为离开页面的用户保留 15 分钟接回结果。显式保存的查询与导出可通过可恢复任务跨程序重启继续。

## 实现与验证

文件身份与修订缓存归入 `internal/fileidentity`，存储传输、认证加密、恢复事务以及后台会话租约分别由专门模块负责。页面传输和后台结果接管沿用同一工作簿与任务协议。[架构说明](../development/architecture.md)

专项回归覆盖已确认的编辑、迁移上传副本后继续搜索、明文兼容、加密空文件及多块文件、错误口令、密文篡改、提交中断和取消。

Windows 标准工程检查与 563 项前端回归通过。隔离 Chromium 验证了页面备份和迁入、后台结果接回，以及来源核验后在确认框中更新路径。两份各 10 GiB 的合成文件经真实 HTTP 入口完成加密备份，耗时约 11 分 20 秒，期间可持续查询任务。中断恢复使用受控故障注入；桌面人工验收和物理断电实验未执行。[专项收据](../../validation/1.14.0/workflow-verification.json)
