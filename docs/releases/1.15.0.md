# ExcelLens 1.15.0

## 本地数据与后台任务

恢复事务遇到文件冲突、目录权限或损坏记录时，启动会进入本地数据恢复页。页面显示具体原因、目录与分类占用。处理问题后可直接继续事务。对于已提交的迁入，重放使用本机目标卷上的暂存文件。

后台工作簿任务支持取消、丢弃结果和释放已关闭的会话。完成的搜索、筛选、分析、对账和导出结果可以独立接回。迁入会列出阻塞的工作簿和运行中的任务。已关闭页面的结果保留 15 分钟。

备份和迁入在复制前计算所需磁盘空间。配置目录与数据目录位于同一卷时合并预算，加密开销、临时文件和事务日志计入所需空间。传输期间会复核余量。取消与提交共享一次状态转换。进入提交后，任务中心显示发布进度。可在备份父目录识别和清理异常退出后的未完成备份。[操作说明](../user/interface.md)

## 前端

工具栏布局使用长轮询与跨标签广播同步，带内容摘要的静态资源可缓存。长表滚动、缩放和冻结窗格复用现有视图。搜索分片加载，中文输入法选词时保留当前操作。分析面板弹窗、按钮与图标使用共享组件。

审阅修正了子会话回收后全局通知失效、同源标签占满 HTTP 连接、复用端口后静态资源陈旧、分析图标显示标记原文，以及切换工作簿后残留搜索高亮等问题。网格占位绘制、后台结果管理与恢复日志现有独立模块。

## 验证

Windows 标准六步检查和 566 项前端回归通过。隔离 Chromium 实测启动受限、处理冲突后重放、双标签清缓存后立即打开文件，以及迁入后逐项接回搜索、筛选、分析、导出和对账结果。16 个界面与 12 套阅读预设检查通过。另测 64 个活动页面、取消和提交竞争、程序被终止后的暂存清理。

真实 HTTP 入口完成 512 MiB 加密备份与迁入，两个文件的 SHA-256 均相符。80 GB 用例使用合成清单和模拟磁盘容量。存储综合脚本的全部业务断言通过，退出时删除 Chrome 临时数据库遇到 Windows 文件锁。桌面人工验收和物理断电实验未执行。[专项收据](../../validation/1.15.0/workflow-verification.json)
