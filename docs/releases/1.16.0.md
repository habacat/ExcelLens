# ExcelLens 1.16.0

## 搜索全部命中

搜索当前表或整个工作簿时，可勾选「全量搜索」。结果写入本机磁盘，按工作表和源坐标排序，每页显示 100 项。结果内筛选和 CSV 导出覆盖所有匹配行。页面会标出缩短的长文本预览，导出保留完整内容。勾选「保留进度」可在重新启动后继续。[操作说明](../user/interface.md)

## 本地数据与恢复

传输历史损坏后仍能备份。在「本地数据」点击「重建传输历史」并确认，会保存原始文件的诊断副本，再写入本次运行的记录。较高版本和当前不可读的历史文件会保留。

重启发现恢复事务时，程序立即提供受限页面，后台核验暂存及已发布内容。可以查看已处理的字节和数据单元。遇到冲突后，可在留存冲突文件或修正权限后重试。任务中心保护活动筛选行序及其他活动页的磁盘搜索结果。缓存清理遇到新占用时也会保留已有结果。

## 验证

Windows 标准六步、独立七步竞态检查及 566 项前端回归通过。隔离 Chromium 在 1,503 个命中上完成翻页、结果内筛选和单行 CSV 下载。第二页请求丢弃活动结果后，原页仍可读取指定行。另通过 30,000 个命中的中断恢复，逐条核对源坐标和顺序。[工作流收据](../../validation/1.16.0/workflow-verification.json)

本版建立发行性能基准，覆盖 CSV 和 XLSX 六种规模、60 秒滚动、两份百万记录台账对账、64 个活动标签页、100 轮回收和编辑保存。每次正式构建自动执行。发行页附带该标签实测的 Performance.json，含样本摘要、环境、实际计量和保真断言。[测量方法](../development/reading-benchmarks.md) · [基准数据](../../validation/1.16.0/performance-baseline.json)
