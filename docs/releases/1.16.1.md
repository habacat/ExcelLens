# ExcelLens 1.16.1

## 大表滚动

滚动时按视口大小、方向、速度及近期读取和绘制耗时预取。相邻缓存块共同提供可见单元格，已知的填充、网格线、边框和合并区域可以先于文字绘制。跳到未读取的位置时先显示当前主题的底色，读取进度显示在状态栏。

滚动中按下鼠标时，选区和公式栏立即绑定所点的源单元格。样式已画出而文字尚未挂载时，也可以从缓存取到准确值。冻结、筛选排序、隐藏行列、合并及编辑副本沿用各自的源坐标与修订。
