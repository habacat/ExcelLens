# ExcelLens 1.17.0

## 新增数据来源

- **XLSB。** 使用纯 Go 解析微软 BIFF12。支持多工作表、数字和日期、公式与缓存、富文本、样式、合并、冻结和显隐，以及批注、链接、图片、名称、数据验证和打印设置。按工作表建立磁盘索引，滚动时读取可见范围。公式令牌无法还原时会标明原因，继续显示已保存的值。部分复杂条件格式和样式可以查看源规则或限制说明。原文件按只读方式打开。
- **RAR。** 支持 RAR4、RAR5 的普通和固实压缩包。先列目录，选中成员后才解压并校验。加密和分卷需要先解压。
- **在线数据库。** 从「打开 → 在线数据库」或首页进入。支持 MySQL／MariaDB、PostgreSQL、Oracle、SQL Server 和 ClickHouse。Oracle 可选服务名或 SID，ClickHouse 可选 Native 或 HTTP／HTTPS。按需选表后生成本机只读快照，沿用同一工作表网格和搜索、筛选、排序、统计、分析、对账及导出。[格式与协议](../user/formats.md)

## 工程与验证

更新 Zstandard、LZ4、Go 加密和系统调用依赖。发布程序使用固定的 vendored 依赖构建，内置数据驱动和文件解码器。

XLSB 使用 Excel 生成的 1900／1904 日期系统同源样本核对数据、公式、样式、布局和元数据，并复验搜索、筛选、排序、统计、对账及导出。性能测试覆盖百万行、16,384 列、复杂样式和高基数共享字符串。[工作流核验](../../validation/1.17.0/workflow-verification.json) · [XLSB 性能测试](../../validation/1.17.0/xlsb-performance.json)

本机各跑三轮。1,000,001 行同源文件的冷索引中位数为 XLSB 3.60 秒、XLSX 8.52 秒，暖索引分别为 101 和 103 毫秒。25 万个不同共享字符串的合成 XLSB，启用顺序磁盘预读后冷索引从 7.00 秒降至 0.42 秒。各轮从空应用缓存开始，保留系统文件缓存。

MySQL、MariaDB、PostgreSQL 已用只读账号通过本机隔离服务测试，PostgreSQL 另验了 TLS 和自定义 CA。ClickHouse 使用公开实例核验 HTTPS 和 Native TLS 目录及读取。Oracle 和 SQL Server 经编译和驱动类型转换测试，实服尚待核验。界面使用隔离无头 Chromium 自动检查，桌面人工验收未执行。
