# ExcelLens 1.17.1

## 数据库快照

- 「保存并打开」将所选表的读取结果保存为独立来源。普通缓存清理会保留快照，快照随本地数据加密备份及迁入。
- 在首页或「打开 → 数据库快照」可离线重开和核验。旧版快照可显式保存，内容摘要从固化时起生效。
- 清单记录数据库来源、每张表的字段定义、读取起止时间、实际记录数、查询和排序口径。采集时计算行文件和索引的 SHA-256，打开或核验时确认摘要。
- 多表快照会标注「各表独立采集」。跨表统一时点及数据库侧列选择和查询条件属于后续工作。[操作说明](../user/formats.md#保存核验和迁移快照)

## XLSB 兼容性及复现

完整源码带有 Excel 生成并脱敏的 1900／1904 两组 XLSB／XLSX 配对样本。默认测试验证固定摘要，并比较原值、公式和缓存、样式、布局、元数据及下游 HTTP 操作。兼容性矩阵逐项记录 BIFF12 声明、实际解析和网格覆盖范围。[兼容性矩阵](../development/xlsb-compatibility.md)

## 验证

专项回归覆盖三种缓存清理、旧版固化、加密迁入、行文件和索引的同长度改写、PostgreSQL TLS 及 262,161 条合成记录的磁盘索引。桌面人工验收未执行。[验证范围](../../validation/1.17.1/workflow-verification.json)
