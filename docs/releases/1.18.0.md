# ExcelLens 1.18.0

## 条件格式与选区

同表条件格式支持相对和绝对引用、算术、逻辑、日期、文本查找及有界范围统计。可用 COUNTIF 标记重复编号，用 SUM 核对同行金额。源公式缺少保存结果、引用尚未读取或超过计算容量时，网格和详情保留原因。[条件格式说明](../user/formats.md#ooxml条件格式)

拖选区域或使用 Ctrl 多选时，行列标题和高亮色带随选区扩展。合并单元格中的单格点击保留实际落点，整行选择只高亮该行。

## 审计修复

- 修复分析仪表盘拆分后无法打开已保存报表，以及 BIFF8 工作表的列显隐越界。
- 修复 Excel 1900 闰日、早期星期、1904 日期边界、空白引用、文本布尔值及通配符查找偏差。
- 修复 Excel 另存为 XLSB 后，整张工作表因一个普通条件规则误报公式长度错误而丢失条件样式的问题。
- 限制连续乘积、多条件范围和通配符回退的计算开销，超限时保留原因。
- 六个后台操作接口在修改任务前校验完整请求。工作簿、归档、恢复、分析、读写及网格交互模块按职责拆分。
