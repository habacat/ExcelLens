# ExcelLens 1.18.1

## 条件规则中的名称

条件格式可以读取工作簿或当前工作表中定义的固定单元格名称，局部名称优先。若名称指向另一张工作表，先用已有行索引；目标表未索引时，按读取预算查找目标格。源公式没有保存结果、名称不唯一、动态名称及外部引用会显示原因。[使用说明](../user/formats.md#ooxml条件格式)

## 大表条件统计

整列 COUNTIF 查重、SUMIF、COUNTIFS、SUMIFS、精确 MATCH 和纵向滚动 SUM 共用工作表统计索引。大表在可取消的工作表索引阶段准备统计。新视口和重开后的工作簿可以直接读出计数、总额或首个匹配位置。统计文件使用有版本的独立缓存，未完成的构建不参与查询。清理工作簿缓存会移除该文件。

条件计数与求和可以在建索引时过滤固定比较条件。动态通配符、近似 MATCH、多列矩形和超过计划或磁盘容量的情况沿用有界读取。统计文件不可用时，小范围仍可求值。精确 MATCH 能把 0% 与源数值零匹配。对浮点累加顺序敏感的移动窗口按源序复核，超出单次复核容量时提示原因。

## 公式与工程验证

- 条件表达式语法树、A1 引用解析和共享统计存储已移入 `internal/conditional`。工作簿适配器提供有类型的源值、作用域、样式、取消和未知状态。
- 通用计算与条件格式共用 `internal/excelformula` 的日期序列、精确舍入、通配符标记、逻辑文本和比较操作。条件算术的二进制中间值与源值的精确比较分别处理。统计索引使用纯 Go bbolt 1.4.3，已固定并纳入离线 vendor 和第三方许可。
- 源码附带两种日期系统的 XLSX／XLSB 合成工作簿及 Excel 实际着色的期望值。默认 Go 检查验证四个文件共 272 格次，覆盖范围、文本数字、空白、错误、布尔、多条件、溢出、精度、局部名称及相对引用。安装 Excel 的维护机可运行 `tools/qa/conditional_native_matrix.py` 在单独目录再生对照。
- 百万行专项分别使用 1 万和 50 万个键，记录生成统计的时间、磁盘占用、首次及暖视口、重开时间。无头 Chromium 的十秒滚动记录与工作簿查询耗时分别报告。桌面人工和 WPS 实机验收未执行。[专项收据](../../validation/1.18.1/workflow-verification.json)

## 条件格式专项实测

每个样本有 100 万行，同时使用上述六种规则。每个视口核对 20 行、120 个条件样式，暖读取 16 个分散位置的中位数。

| 不同匹配键 | 首次准备统计 | 统计文件 | 暖视口 | 重开后首个视口 |
| ---: | ---: | ---: | ---: | ---: |
| 1 万 | 17.85 秒 | 64 MiB | 3.38 毫秒 | 5.68 毫秒 |
| 50 万 | 20.41 秒 | 256 MiB | 3.50 毫秒 | 5.02 毫秒 |

1,000 行的同源对照覆盖两个版本都能算出的范围。1.18.0 和 1.18.1 的 17 个相同视口均命中 2,040 格，暖视口中位数从 108.40 毫秒降到 1.99 毫秒。百万行浏览器测试在开启原格式时测得 42.16 和 56.25 FPS，关闭时为 47.26 和 57.35 FPS。最终四轮均无空白或未完整覆盖的帧，较早轮次仍出现过覆盖未齐。不同轮次的帧率波动较大。[测量数据与环境](../../validation/1.18.1/workflow-verification.json)
