# ExcelLens 1.19.0

普通行索引就绪后即可滚动、选格与查看源值。整列次数、求和和精确查找在后台准备。待计算的条件会保留状态和优先级，完成后更新当前窗口。关闭「原格式」、取消、重试和切换工作表都使用对应任务的标识。固定小范围复用当前视口，中等窗口复用行间计算，较大范围复用磁盘统计。[条件格式](../user/formats.md#ooxml条件格式)

## 稳定性与工程调整

- 并发生成索引时，在同一次发布操作内核算跨工作簿预算。显式导出和打印首次建立索引时也使用当前设置。闲置清理只处理符合缓存命名的统计文件，打开的工作簿与活动读者有独立保护。
- 保留有界的后台任务历史。迟到的取消响应按原任务 ID 处理，重试会等待该次取消完成。
- 精确滑动窗口在非二进小数或超精度大值离开后恢复增量求和。工作表最后一个合法的相对引用也计入窗口规划。
- 条件公式求值、行索引与行序、样式解析与显示格式、后台任务生命周期分别由 conditional、rowindex、styles、taskmanager 维护。适配层在创建求值器时绑定源读取回调，逐格计算只传当前操作数。原生文档编辑和封包保留既有职责。[架构说明](../development/architecture.md)

## 性能验证

第二版发行基线保留普通大表读取、搜索、对账、多页、回收与编辑副本，增加两种百万行键分布的三轮冷建、暖视口 P50／P95、缓存重开、逐格分配、服务资源及真实网格滚动。生成的源码 ZIP 支持离线运行后端验证。Windows 发行包附带同一标签的实际测量；源摘要、已采样条件样式和未覆盖帧分别记录。桌面人工及 WPS 实机验收尚未执行。[测量方法](../development/reading-benchmarks.md) · [专项核验](../../validation/1.19.0/workflow-verification.json)
