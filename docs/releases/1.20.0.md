# ExcelLens 1.20.0

工作簿、网格、编辑副本和分析面板现使用严格 TypeScript。主页面和存储恢复页各自加载一个嵌入 EXE 的脚本。

- 切换文件时终止旧工作簿的公式引用预览，同名工作表的索引、读格和缓存分别归属于各自的工作簿。
- 隐藏或恢复行后，记录卡和选区工具随可见行提交结果刷新。
- 不完整的 JSON 响应向调用方报告读取失败。格式注册表从服务端注入；失效配置不能复用先前的能力和容量。

经典工具栏在 671 像素宽度下可点击全部常用命令。22 项真实服务和无头浏览器专项通过，覆盖自适应布局、快照、关联导出、图表与长文本滚动。290.8 万行 TXT 在三种缩放和两种冻结状态下各完成 60 次缓存微滚动往返，核对可见行、命中格及源值。

严格 TypeScript、ESLint、分层与产物检查、613 个前端测试、Go 测试、go vet 和 Windows 全仓竞态通过。交互的逐项结果见[本版验证](../../validation/1.20.0/workflow-verification.json)。2026-11-27 用户确认本版人工验收通过，未指定桌面及 Office/WPS 的具体验收环境。
