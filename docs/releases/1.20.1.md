# ExcelLens 1.20.1

- 工作簿、视口、预览及样式按 Go 的 JSON 声明生成传输类型和运行时检查。视口返回损坏的嵌套字段时，读取失败，损坏的行不会进入缓存。
- 最近文件重开携带正确的来源标识。压缩包成员在解包完成后核验工作簿或嵌套目录，历史成员无法重开时保留当前目录。
- 工作表尺寸按操作顺序保存。窗口失焦、切换工作表或收到旧的保存回执时，当前工作表保留已确认的尺寸。
- 跨冻结行和排序区拖选时，分析同时传递源行号和显示行号。无行维度的总计可以下钻，稀疏空白行可以转置和复制。
- 网格样式、尺寸、条件统计任务、分析查询编辑各自由独立模块维护。Windows 单文件程序继续内嵌前端资源。

617 个前端回归测试通过。24 个真实本机服务与无头 Chromium 专项和一份图表往返核验均通过，涵盖排序冻结选区、稀疏区域转置、关联导出，以及 290.8 万行 TXT 的六种缩放与冻结组合。逐项结果见[交互验证](../../validation/1.20.1/workflow-verification.json)。用户已确认 1.20.0 人工验收通过，1.20.1 的验证记录单独维护。
