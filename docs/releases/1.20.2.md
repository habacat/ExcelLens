# ExcelLens 1.20.2

- 移除计算器“计算口径”常驻说明以及查重、导出、标记、分页预览、行头悬停等多处常识性或重复性的只读提示，使界面只保留操作所需标签、结果与必要状态。
- 统一界面术语与单位表述：将 `Sheet`、`画面选区`、`字段画像`、`允许残差`、`缺省`、`下钻`、`视口`、`十进制数`、`不小于/不大于`、`MiB/GiB` 等非标准或工程内部表达替换为更易理解的标准中文表格术语和 `MB/GB` 容量单位。
- 新增超链接已访问变色反馈：通过网格单击、冻结窗格单击、`Ctrl+Enter`、右键菜单或命令面板访问有效的内部跳转或外部超链接后，源单元格即时变色并在滚动、切换工作表与悬停提示（“已访问”）中持续保留，浅色与深色护眼主题均清晰可辨；无效链接不误标记，切换工作簿时自动清空。
- 统一全站原生控件样式：基于现代自定义下拉选择器（`appearance: base-select`，并保留兼容回退）将右上角字体选择器及全站所有单选下拉菜单统一为与右键菜单一致的圆角悬浮面板、主题底色与选中勾选样式，同时统一文件选择、进度条、搜索清除按钮、日期选择与对话框折叠控件样式。
- 易用性改善：字体下拉项直接以对应字形预览并在启用自定义字体时高亮字体图标，状态栏缩放比例支持单击一键重置为 100%。

619 个前端回归测试与全仓标准门禁通过。真实本机服务与无头 Chromium 浏览器验证涵盖经典／选项卡双布局字体菜单、命令面板、超链接浅／深色已访问状态及跨表回切、计算器与缩放重置、单元格信息、选择性复制与分页预览。逐项结果见[交互验证](../../validation/1.20.2/workflow-verification.json)。桌面人工验收与原生 Office/WPS 对照另行保留。
