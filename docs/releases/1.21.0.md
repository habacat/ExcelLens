# ExcelLens 1.21.0

## 界面语言

支持简体中文、繁體中文、English、日本語、한국어和 Русский。页面自动匹配浏览器偏好，Windows 托盘自动匹配系统显示语言。右键托盘图标，进入「语言」，可保存固定选择或恢复自动匹配。打开的工作簿在返回首页后应用新语言。首页对话框关闭且操作结束后会应用待切换的语言。消息目录随应用离线交付。[界面指南](../user/interface.md)

## 表格显示

相邻单元格共用边线及交点计算。冻结窗格读取边界相邻行列的样式，行号旁的 A 列边框使用相同规则。修复粗边框在主网格、行头、合并区和冻结边界的缺口。顶部源文件提示可收起到文件名旁的角标，并从角标展开。

## 验证

同机七轮已预热俄语首页生成微基准中，每次调用的中位耗时从 2.34 ms 降至 0.48 ms，分配从约 2.81 MB 降至 0.53 MB。测量范围为 Go 页面生成。可运行 `go test ./internal/ui -run '^$' -bench '^BenchmarkLocalizedIndex$' -cpu=1 -benchtime=200ms -count=7` 复测。

[工作流验证收据](../../validation/1.21.0/workflow-verification.json)记录语言切换、冻结边框、分页预览和只读源文件核对。译文经过常用术语校对。逐条母语审校、桌面人工验收及 Office/WPS 实机对照未执行。
