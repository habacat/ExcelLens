# ExcelLens 1.8.20 版本记录

2026-11-17，长表滚动根因修复。随包文档是构建时快照，最终构建、CI和发布状态以源码仓库[接续入口](../development/improvement-progress.md#接续入口)和GitHub Release为准。

## 修复

百万行TXT上下滚动时，旧跟随代码读取浏览器舍入后的CSS坐标继续计算，导致相邻行重叠、留下空白。现改为从公共数值行几何重新定位，普通/筛选及冻结前缀共享同一几何语义。源值、类型、坐标、只读约定和缓存编码保持不变。
