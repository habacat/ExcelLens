# ExcelLens 1.9.0

从上一个 GitHub 版本 1.8.20 升级后，可在原工作表网格中编辑副本。支持修改值和公式、输入原空白位置、跨表重算、操作 Excel 表格的计算列和汇总行、编辑受保护表的解锁单元格，以及调整受支持的多层透视表。生成件保存为独立文件。 [编辑副本](../user/editing.md)

1.9.0 将工作表读取、筛选、搜索、分析任务和结果导出按职责组织。编辑网格和透视面板使用同一修订的计算结果和源索引。在分页筛选中翻页时从上次读取的位置继续，改变搜索词可复用已读项目。数值、文本、日期和布尔项目保留各自的身份，撤销或恢复修订后使用对应来源。

前端共用列号与 A1 坐标解析，命令面板负责搜索和键盘选择。滚动缓存按工作表、筛选、冻结前缀及可见列匹配请求。重新显示隐藏列时会检查缓存是否真正包含该列。重复使用已覆盖的小窗口会保留相应缓存。分析源遇到重名表头时使用独立的列标识，错误响应正确声明 JSON 类型。

大表索引首次建成和重开时采用相同的行数阈值。搜索、网格读取及性能验证共用行访问接口，抽取固定行数时保留真实坐标，磁盘映射的大表也能准确限定扫描范围。

Go 更新至 1.27.4。更新 XZ、Brotli、LZ4、通用压缩库、Go 文本库及 go4 组件，依赖源码和许可随包保存。GitHub 在 Windows 和 Linux 上运行离线检查，使用 Node.js 26 LTS 验证前端。Windows 程序自身使用纯 Go。 [依赖及许可](../../THIRD_PARTY_NOTICES.txt) · [工程结构](../development/architecture.md)

下载 Windows x64 完整包并解压，退出旧版托盘程序后运行 `ExcelLens.exe`。源码包来自发行标签，每个文件均与对应 Git 对象校验。SHA256SUMS 附件给出两个 ZIP 的完整摘要。

验收使用 Microsoft Excel 16.0 比对 38 组透视操作。123 个状态在保存重开和 Excel 再刷新后各核对 37,083 格次，另外核对 138,478 个带类型的缓存值。跨表公式在修改、撤销和重启后重做等四个状态核对 66,408 次，均在记录的数值容差内。实际压缩包还验证了完整解压摘要，以及 345,030 行、39 列截断来源的逐字段结果。 [验收明细与数值容差](../../validation/1.9.0/engineering.json)

在 16,384 个不同项目中连续翻 32 页的同机微基准里，三次测量的中位耗时从 34.73 ms 降到 4.13 ms，每轮内存分配从约 11.87 MB 降到 1.66 MB。测量对象为透视分页读取。 [基准条件和分配次数](../../validation/1.9.0/engineering.json)
