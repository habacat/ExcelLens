# 分析方案

分析方案用于反复处理同类数据：保存一次分析的转换、筛选、分组和汇总设置，换一份文件后核对字段，再重新运行。源文件继续只读。

## 保存与复用

1. 打开“分析”，选择数据来源和字段，运行分析。
2. 点击左侧“数据源”旁的“分析方案”，填写名称并“保存方案”。保存的是当前已完成结果的设置；后来修改但尚未运行的设置不会混入。
3. 下次打开同类文件，在“分析方案”中选择已保存方案、目标表、表头行和目标范围，点击“读取字段”。目标可以是当前文件的工作表或已保存的分析编辑表。
4. 核对字段对应关系，完成需手动选择的项目，点击“运行方案”。完成后仍在原分析界面查看结果、下钻、提取明细或导出。

方案保留转换链、筛选、行列维度、多个汇总指标、排序、前N项、小数位、图表设置及CSV/XLSX导出选择。运行不会自动下载文件，打开列表也不会自动运行。工作簿网格的筛选、排序及布局由[命名视图](named-views.md)保存。

[疑似重复值核对](value-clustering.md)确认的精确文本映射，也随完成后的报表和方案保存。映射只接受可信文本或用户明确转换出的文本，不能把数值、布尔、错误或未知读取类型混成同一编号；未列入映射表的新原文仍保留。

## 层级查看

在左侧“布局”选择“层级展开”，运行后使用分组旁的箭头逐层展开或收起。只计算展开的层，父行保留自身的精确小计；平均值和去重计数不会由子行相加。方向键可展开、收起或在当前页定位，超过一页的结果使用表头下方的翻页按钮。

点击数值可查看该分组的来源明细；小计包含本分组的所有列分类，真实空白列只包含该空白分类。层级结果的“导出首层”和“首层编辑表”输出第一层的精确结果，不包含尚未计算的后代。报表和分析方案保留层级布局。

## 占比与累计

在每个“汇总指标”的“结果显示”中选择比较方式，运行分析后生效。不同指标可以使用不同设置，报表与分析方案会保存这些设置。

| 结果显示 | 计算含义 |
| --- | --- |
| 原始聚合 | 显示当前求和、计数、平均、极值或去重结果 |
| 占范围总计 | 当前分组聚合除以整个分析范围的同一指标 |
| 占行合计 | 当前交叉格聚合除以该行全部列的同一指标 |
| 占列合计 | 当前交叉格聚合除以该列全部分类的同一指标 |
| 累计 | 沿指定方向，把截至当前分类的源聚合状态合并 |
| 累计占比 | 累计聚合除以该方向的完整聚合 |

“沿行”按照分类的排序累计，数值排序使用原始第一指标；“沿列”按照列标签排序。先计算全部分类，再截取前N项，翻页不会重新开始累计。比如总额100，只显示第一类的金额20，占范围总计仍为20%。

累计平均使用原始有效数值的数量加权，累计去重合并原值集合；不会相加已舍入的平均值或去重数。平均、去重、最小/最大值的占比不一定相加为100%。有负数时按代数合计计算，比例可以为负或超过100%；分母为0、没有有效数值时明确显示原因。

层级展开时，每一层的范围是对应父分组；子层的“占范围总计”表示占父分组，不是占整个源表。悬停数值可核对原始聚合、精确分子和分母。点击累计数值查看的是当前分组的源记录，累计还包括此前分类。

CSV和生成的结果表保留精确比值，表头注明“比值，1=100%”；例如`0.25`表示25%，非终止小数保留`1/3`等分数。XLSX在Excel精度和数值范围允许时使用百分比样式，超长、极大或极小的数及非终止分数保留精确文字。图表只在绘图时近似，提示保留精确值。显示偏好仍在右上角“设置”调整。

窄窗口中，配置区位于结果区上方，两区分别滚动；顶部导航可横向滚动。保存过比较设置的工作区和分析方案需要支持该功能的版本打开，旧版会明确拒绝读取。

## 数字显示

分析工作区右上角“设置”可分别调整千分位分隔符和大数科学计数法。默认显示千分位；绝对值达到万亿（10¹²）时使用科学计数法，保留3位有效数字，例如`9.01e+15`。大数门槛可选十亿（10⁹）、万亿（10¹²）或千万亿（10¹⁵）。

保存后，汇总卡片、平铺表、已展开分组和仪表盘图表提示立即更新，不需要重新分析。悬停查看精确值；分数结果保留精确分数。关闭科学计数法可以查看完整的小数位显示，位数仍由本次分析的小数位设置决定。

这两项是跨文件的本机偏好，重启后保留，不随报表或方案改变。它们只调整汇总数值的呈现，不改写来源文本、编号、源类型、下钻明细或CSV/XLSX中的精确结果。多页面同时修改设置时，旧页面需点击“重新载入”再保存；保存失败会保留此前设置。

## 分析范围

分析工作区左侧可选择以下范围。表头行及它之前的源行不参与统计；表头按源行号判断。

| 范围 | 实际使用的数据 |
| --- | --- |
| 完整源表 | 全部源记录，按原顺序，包含隐藏行 |
| 完整筛选结果 | 已完成的筛选/排序结果，包含手动隐藏的匹配行 |
| 当前可见行 | 当前显隐和排序下的可见行，包含可见的冻结标题行 |
| 画面选区 | 当前网格的一个连续选区，只使用选中的源列和可见行 |

后三种范围先在工作簿当前工作表准备，再打开分析并选择。画面发生变化后，点击“重新捕获”才更新分析范围；已完成结果仍按原范围下钻、提取和导出。范围无法恢复时会报错，不能自动变成整表分析。结果标题下方会显示本次结果的范围。

保存报表会保留范围，重开及工作区备份恢复后仍按原规则读取。分析方案只将原范围记为来源说明；换目标时默认“完整源表”，需要复用当前分析范围时明确选择“当前分析范围”。只有目标表与当前分析来源相同时才可选择该项，预览数量和类型样本随目标范围变化。

## 字段和类型需要核对

仅名称完整、唯一且读取类型兼容的字段会自动匹配。列顺序可以不同；重名、截取、名称不全或混合类型需要明确选择，不能只凭同一个列号猜测。每个目标列只能绑定一次。

预览最多检查前8条记录，界面会注明范围。空样本需要手动选择；运行仍核对全部实际输入。后段遇到不兼容类型、缺少公式缓存，或预览后目标表发生变化时会停止，当前分析结果保留。

原生Excel里写成文本的金额，与CSV里可参与数值统计的金额文本语义不同，不能强行绑定。请在普通分析中明确转换并核对，保存适用于此类来源的新方案。日期只通过用户选择的转换规则处理，不因打开、滚动或匹配字段而猜测日期。

所需字段全为空、含错误或缺少公式缓存等不确定状态时，目前不能保存方案。SQLite缓存尚未保留完整源类型，目前也不能将这些字段保存为可靠的跨来源方案；普通查看和分析保持原有能力。

## 保存位置与取消

最多保存64个方案，名称最多80字。方案保存在本机用户配置目录的`ExcelLens/recipes/catalog.json`，缓存清理不会删除；其中保存设置、来源说明和字段摘要，不保存源记录。分析工作区JSON备份目前不包含这个全局目录。

保存时先核对完整输入类型，再写入方案目录。核对和运行均可取消；目录保存冲突时，刷新列表或更名后重试即可复用已核对草稿。目录损坏会报错并保留文件，不会自动清空。关闭窗口或切换文件会取消当前窗口拥有的任务，不会写回源文件。
