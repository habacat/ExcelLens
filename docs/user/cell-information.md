# 单元格信息

选择单元格，点击“单元格信息”、双击，或按F2/Ctrl+1打开。详情按需读取，关闭后取消未完成的读取。

- 原始值和源类型保留文件里的内容，显示值沿用当前格式；源文件不会被修改。
- “数值统计”表示这格能否作为源数值参与统计。原生Excel文本保持文本；导入文本金额按既有精确规则识别，前导零编号不转成数值。分析方案还可能有自己的范围、条件和显式转换，因此“可用”不代表它已被每份分析计入。
- 公式仅在实际存在时列出，分别显示已保存或未保存计算结果。无法还原的公式原文明确标识；有结果不代表应用已经重算过公式。
- 已应用的筛选和排序来自当前成功视图；尚未应用的对话框输入不会出现在这里。集合筛选可展开核对原文。

切换文件、工作表、当前格、筛选或行视图会关闭过期详情。读取失败可直接重试；单格信息超过读取容量时，使用选区或流式导出，不截断原文冒充完整结果。
