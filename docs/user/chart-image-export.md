# 导出图表图片

完成分析后，点击图表右上角的“导出图片”。仪表盘已加载的卡片有“图片”按钮；选区快速分析也可点击“导出趋势图片”。

选择PNG或SVG、宽高和背景，再点击“生成图片”。PNG可选1×/2×，例如1200×800、2×生成2400×1600像素；SVG保留矢量图形及文本，不受PNG倍率影响。默认沿用打开导出窗口时的阅读配色，也可选白底。

生成完成后预览图片，点击“下载图片”即可保存PNG或SVG；需要精确数据及范围说明时，点击“下载ZIP”。两个下载入口来自同一份已生成结果，调整选项后需重新生成，下载文件名始终对应已生成的图片类型。预览上方只显示图片格式、像素尺寸和易读大小，完整来源及统计条件保留在附件中。ZIP内包含：

- `chart.png`或`chart.svg`：带标题、来源范围、指标/单位、实际绘制分类/系列及截取说明的图片。
- `exact-data.json`：同一份已接受结果、来源身份、查询、字段、原始/派生精确字符串和缺值状态，以及图形、显示和输出设置。金额和分数不经过浮点近似，编号前导零保持原样。
- `README.txt`：附件范围及使用说明。

图片绘图使用近似坐标，精确值以JSON和现有结果导出为准。图表显示上限、Top-N和层级首层限制仍有效；饼/环只画所考虑分类中的有限正值及第1系列。JSON包含完整的**已接受结果**，不会补齐未返回的分类、未展开后代或整个源表。F13图片展示分段平均，附件保留完整分布和分段，不是逐行原始数据。

生成时不重新查询原表；已完成的报表快照即使服务任务过期仍可导出图片及其JSON。需要现有CSV/XLSX时继续使用“导出结果”，该入口保留任务有效期约束。

可以取消后重试。同一快照重新生成失败或取消时保留上次完整包，并明确标识；调整尺寸后需重新生成。切换文件、结果、指标、图形或关闭来源窗口会清理旧链接。原生PNG编码无法中途打断，取消后其画布在真实编码结束时释放，重试可等待该槽位。

逻辑尺寸限640–2400×480–1600，PNG最多2000万像素；精确JSON16MiB、PNG20MiB、SVG4MiB、整包40MiB。超限整次拒绝，不截断数据附件。SVG使用本机系统字体，不携带外部资源；长标签在图片中可能缩短，JSON保留完整内容。源文件保持只读。
