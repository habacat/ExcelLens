# 选择性复制与粘贴

## 从只读工作簿复制

选中一个连续区域，在右键菜单选择“选择性复制”，或按`Ctrl+Alt+Shift+C`。命令面板也可搜索“选择性复制”。

- **文字表格（TSV）**：可选显示值、原始值或公式文字。复制时同时提供文字表格的HTML，保留前导零及公式文字；目标程序只接受纯文本时使用TSV。
- **Markdown表格**：适合放入说明文档，转义竖线和HTML文字，用换行标记呈现多行内容。它用于排版；需要完整原文、类型及坐标时选择JSON。
- **JSON**：保留原始值、显示值、源类型、源行列、公式及缓存缺失状态。重复和空白表头以数组保留，不会因同名而合并列。数值保存在字符串中，避免大金额被JSON数值精度截断。

勾选“附带表头”后，可指定源表头行；该行可以隐藏或不在当前筛选结果中。选区已经包含此行时不会重复添加。数据按当前可见顺序复制，隐藏的数据行不混入结果。总容量包含表头，最多250行、50列、5000格；超限使用导出。

显示值沿用原表显示，原始值保留完整十进制和源文字。公式模式复制公式文字，非公式格保留原值。公式缺少缓存时不能伪造数值；无法还原的共享公式也不能当作有效表达式复制，可改选JSON保留真实状态。

## 粘贴到独立分析编辑表

在分析工作区的“编辑工作表”选择起始格，点击“选择性粘贴”，或在编辑格按`Ctrl+Shift+V`。直接`Ctrl+V`仍沿用普通粘贴方式。

1. 在文本框粘贴文字，或点击“读取剪贴板”。读取被浏览器限制时，仍可在文本框按`Ctrl+V`。
2. 选择TSV或JSON。JSON支持ExcelLens复制结果和二维文字数组，如`[["001","9007199254740993.31"]]`；数字必须加引号，`null`作为空白。ExcelLens JSON还可选择原始值、显示值或公式文字，表头默认不写入。
3. 按需要选择转置、跳过空白或跳过TSV首行。跳过空白只跳过空字符串，空格会原样保存。预览最多6行、8列，写入数量显示在下方。
4. 核对目标及预览，点击“确认粘贴”。整批校验成功后一次保存，可使用编辑表的撤销/重做整批操作。超出边界、内容不合法或容量不足时整批拒绝，不截断。

这里仅向独立分析编辑表保存文字，不修改原文件，不执行粘贴的公式文字，也不写入样式。输入最多2MiB、2000行、80列、20,000格；单格最多4000个Unicode字符，转置后的范围还需符合编辑表边界及整批请求容量。

其他页面修改了编辑表时，保存会提示版本冲突并保留输入；点击“重新读取目标”，核对预览后再保存。目标表或页面已经切换时，需关闭对话框重新选择。保存失败会保留输入和草稿，可按现有草稿流程明确重试。仅格式粘贴及有类型公式写入尚待编辑副本阶段实现。
