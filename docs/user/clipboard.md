# 选择性复制与粘贴

## 从网格粘贴到 Excel

阅读页普通复制会优先保留表格格式。超过容量时会复制纯文本，按各源格的基础显示值分列，保留可见行顺序。需要合并版式或条件格式时可选择带格式的文件导出。纯文本也超限时会打开“导出当前选区”，保留所选行列和筛选顺序，选择文件格式后点击“开始导出”。编辑副本的结构化复制和剪切使用当前修订及各自的容量限制。

按住鼠标拖动，或按住 **Shift** 用方向键扩展选区。外框标出复制范围，活动格保留工作表底色，右下角的小方块标出选区的边角。跨冻结窗格拖选时，四边仍随同一个选区移动。窗口下方的颜色设置可更改轮廓颜色。

在网格中选中单元格或区域，按 `Ctrl+C`，再到 Excel 的目标起点按 `Ctrl+V`。单击合并标题即可复制整个标题。拖选触及合并格时，选区会扩到包含它的完整矩形，旁边的数据按原位置粘贴。编辑副本中复制的是当前修订显示的内容；正在格内输入时，快捷键复制选中的文字。

在同一标签页的 Excel 工作簿副本中，**Ctrl+C** 可以复制完整的合并区域，保留标题、公式、类型和单元格格式。选一个起点按 **Ctrl+V**，或选中行列数都是来源整数倍的矩形来重复平铺。复制公式时，相对引用按目标位置平移。

从另一个 ExcelLens 标签页或 Windows Excel 复制到编辑副本时，可一并粘入公式、数值、文本、数字格式、字体、边框和合并区。相对轴随格子平移。跨工作簿公式如果显式指定源表、表对象或定义名称，需要创建外部链接或导入名称。此时会保留当前修订，可以改粘贴显示值。筛选或排序后多行粘贴按可见顺序进行，合并区须有连续目标行。Windows Excel 的结构化剪贴板不可用时，**Ctrl+Shift+V** 可粘贴显示文字。

从 Windows Excel 复制筛选结果时，公式按各自的原行号平移。手动隐藏行列后，普通复制可以带上隐藏单元格；在 Excel 选择“仅可见单元格”再复制时，会按可见顺序粘贴。若剪贴板给出的两种范围都符合所复制的内容，网格会显示行列数供选择。按 **Esc** 可取消这次粘贴。

**Ctrl+X** 标记待移动的矩形。选中另一处或切换工作表，按 **Ctrl+V** 完成移动。源区与目标区可重叠。直接引用已移动单元格的公式、已定义名称和普通图表序列随之更新。按 **Esc** 可以取消待剪切状态。右键菜单也可剪切、复制和粘贴。整次粘贴按 **Ctrl+Z** 撤销，按 **Ctrl+Y** 重做。粘到另一个标签页或外部程序时，原选区仍保留。

复制碰到目标合并区的一部分时，请换一个起点或先取消目标合并。剪切在重叠处按 Excel 的目标范围处理，原合并可能被解除。表格、透视结果、数组、保护和单独绑定的数据规则等结构阻止整块传输时，网格会说明原因。筛选或排序时，先恢复原表顺序再剪切。

经过筛选或排序后，复制采用屏幕上的行序。跨行合并需要对应的行按源顺序相邻。隐藏行不占粘贴结果的行数。使用右键菜单的“复制选区为纯文本”时，目标程序收到制表符分列的文字。

## 选择性复制

选中一个连续区域，在右键菜单选择“选择性复制”，或按`Ctrl+Alt+Shift+C`。命令面板也可搜索“选择性复制”。

- **文字表格（TSV）**：可选显示值、原始值或公式文字。复制时同时提供文字表格的HTML，保留前导零及公式文字；目标程序只接受纯文本时使用TSV。
- **Markdown表格**：适合放入说明文档，转义竖线和HTML文字，用换行标记呈现多行内容。它用于排版；需要完整原文、类型及坐标时选择JSON。
- **JSON**：保留原始值、显示值、源类型、源行列、公式及缓存缺失状态。重复和空白表头以数组保留，不会因同名而合并列。数值保存在字符串中，避免大金额被JSON数值精度截断。

勾选“附带表头”后，可指定源表头行；该行可以隐藏或不在当前筛选结果中。选区已经包含此行时不会重复添加。数据按当前可见顺序复制，隐藏的数据行不混入结果。总容量包含表头，最多250行、50列、5000格；超限使用导出。

显示值沿用原表显示，原始值保留完整十进制和源文字。公式模式复制公式文字，非公式格保留原值。公式缺少缓存时不能伪造数值；无法还原的共享公式也不能当作有效表达式复制，可改选JSON保留真实状态。

## 粘贴到独立分析编辑表

在分析工作区的“编辑工作表”选择起始格，点击“选择性粘贴”，或在编辑格按`Ctrl+Shift+V`。直接`Ctrl+V`仍沿用普通粘贴方式。

1. 在文本框粘贴文字，或点击“读取剪贴板”。读取被浏览器限制时，仍可在文本框按`Ctrl+V`。
2. 选择TSV或JSON。JSON支持ExcelLens复制结果和二维文字数组，如`[["001","9007199254740993.31"]]`；数字必须加引号，`null`作为空白。ExcelLens JSON还可选择原始值、显示值或公式文字，表头默认不写入。
3. 按需要选择转置、跳过空白或跳过TSV首行。跳过空白只跳过空字符串，空格会原样保存。预览最多6行、8列，写入数量显示在下方。
4. 核对目标及预览，点击“确认粘贴”。整批校验成功后一次保存，可使用编辑表的撤销/重做整批操作。超出边界、内容不合法或容量不足时整批拒绝，不截断。

这里仅向独立分析编辑表保存文字，不修改原文件，不执行粘贴的公式文字，也不写入样式。输入最多2MiB、2000行、80列、20,000格；单格最多4000个Unicode字符，转置后的范围还需符合编辑表边界及整批请求容量。

其他页面修改了分析编辑表时，保存会提示版本冲突并保留输入。点击“重新读取目标”，核对预览后再保存。目标表或页面已经切换时，需关闭对话框重新选择。工作簿副本的有类型粘贴、仅公式和仅格式操作见[编辑副本](editing.md#批量编辑)。
