# 比较快照

分析完成后，在图表旁点击“保存快照”，填写名称并保存当前指标。通过分析页的“比较快照”或命令搜索打开已保存结果。

选择基准和对比快照，查看小趋势、分类差额与变化率；有多个系列时可切换。差额为对比减基准，变化率为差额除以基准绝对值；基准为零、缺少分类或无法计算时保留明确状态。分类和指标定义不同不能直接计算差额。来源、分析时间和筛选条件在“来源与规则”中按需查看。

快照保留保存时的精确聚合与来源。打开、切换系列、翻页及调整窗口不重新运行分析，源文件关闭后仍可比较。小图使用近似绘图坐标，两侧共用刻度，表格精确值可在单元格提示中查看；空值断开，超出绘图范围不伪装为零。Top-N和层级根结果只包含已捕获分类，完整范围总计单列保留。

每份最多200个分类、12个系列和1MB，本机最多保存24份、总计16MB。超限需缩小分析范围或删除不用的快照，不自动截取。删除需再次点击确认；跨页面修改冲突时刷新目录再重试，损坏记录不会被空目录覆盖。

快照位于用户配置目录，独立于可清理的工作簿缓存；不写入源文件。编辑和源文件保存仍不属于本功能。
