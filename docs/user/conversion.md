# 按需数据格式转换

转换由用户操作触发。打开文件、建立索引、浏览和滚动时不检测整表，不改写原文件、缓存值或默认字段类型。

## 分析中的转换列

1. 打开「分析」，选定数据源与表头。
2. 在「数据加工」点击「格式转换」，选择来源列和目标类型；可设置转换列名称。
3. 需要时将新列拖入行、列或筛选区，点击「运行分析」。也可继续对转换日期提取年份、月份或年月。

日期标准化为 `YYYY-MM-DD`，时间为 `HH:mm:ss`，日期时间为 `YYYY-MM-DD HH:mm:ss`，保留实际存在的小数秒。这些标准格式用于分析分组、标签排序与日期/时间区间过滤，提取明细或生成编辑表时作为标准格式文本保留；本操作不会为整份源工作簿修改 Excel 单元格格式。

数值转换使用现有精确金额规则；转文本保留原值和前导零。需要 Excel 可计算日期/时间序号时，可使用下面的计算表转换。

| 输入格式 | 例子与处理 |
| --- | --- |
| 年在前 / 时间（自动识别） | `2026-11-11`、`2026/1/2`、`2026年11月11日`、`09:05`、带时分秒的日期；只在运行该转换列时识别 |
| 紧排年月日 | 用户明确指定后才把 `20261111` 解释为日期，避免把编号自动当日期 |
| 日/月/年 | `11/12/2026` → `2026-12-11` |
| 月/日/年 | `11/12/2026` → `2026-11-12` |

自动识别不猜日/月顺序，不将纯数字编号或 Excel 日期序号猜成日期，不移除或换算时区。含时区的文本需先明确处理规则；无法解析时保留原文并计入转换失败数量。空白保持空白；缺少公式缓存不会生成虚构日期。时间转换不会为没有时间部分的日期补上午夜。

区间条件可输入 `2026-01-01..2026-12-31`、`09:00..12:00` 或完整日期时间。日期时间区间按具体时刻比较；若按整天筛选，可先转为日期。失败原文保留在转换列，请根据结果提示核对并调整规则。

## 计算表的转换建议

例如输入 `=A2`，当前结果为日期文本 `2026/1/2`，结果旁会出现「转日期数值」。点击后本行公式改成 `=DATEVALUE(A2)`；时间使用 `TIMEVALUE`，日期时间使用两者相加。结果是 Excel 日期序号或一天的小数，可参与日期差、时长等运算，沿用当前工作簿的1900/1904日期系统。

建议只检查**本次计算的单个文本结果，最多256字符**，不读取其他单元格或遍历引用区域。数值、布尔、错误、长文本、纯数字编号、含糊日期不会触发建议。尚未点击时，公式、结果和源字段类型都保持原状；编辑公式后旧建议失效。

建议不覆盖所有计算错误。例如直接用无法识别的文本参加运算而报错，可先用 `=A2` 查看文本并转换，或明确输入 `DATEVALUE(A2)` / `TIMEVALUE(A2)`。转换仍受有效日历、公式长度和现有计算范围限制。
