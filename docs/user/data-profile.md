# 数据洞察与分位数

选择一列或连续区域，点击“统计”（Ctrl+Alt+S）。核对起止单元格后点击“分析”；勾选“分位数与分布”后会计算完整数值集合的中位数、5%/25%/75%/95%分位及区间数量。仅打开弹窗不会扫描数据。

原生Excel的文本金额保持文本。CSV/TSV/TXT/HTML/SQLite按既有导入规则识别金额，前导零编号不转数值。错误值、公式缺少保存结果、空白和其他文本不作为零参与分位数。所有数值结果保留精确数据，源文件不改动，源公式不重算。

手动输入起止地址表示源坐标范围；“仅筛选行”与完整筛选匹配集合相交，包括其中的隐藏记录。直接从网格拖选打开时沿当前可见顺序读取，保留排序、显隐和冻结前缀；改动地址后重新按源坐标解释。详情中的分位和分布均基于实际纳入的完整数值，不自动抽样。

分位数使用包含两端的线性插值，与PERCENTILE.INC定义一致。区间按完整最小/最大值等宽划分，左闭右开，最后一区间含最大值；所有值相同时只显示一个区间。无数值时不产生分位或区间。

常见值按已有显示文本统计。最多追踪10,000个不同显示值，达到数量或文字容量后标为“部分”，不同值数量给出下界；被追踪值的次数仍扫描全选区。公式缺少结果不伪装成空白频次。这个频次限制不影响完整数值的精确合计、分位数或区间计数。

分析最多400万个单元格；源行、累计源内容、文字和响应另有独立容量。超限整次拒绝，使用更小范围或流式导出。排序超过驻留预算时使用项目已有的临时文件与共享磁盘配额，取消或失败后释放。取消不会发布部分分布，读取失败可重试，已有完整结果保留。切换文件、工作表或行视图会关闭过期结果。

数字显示沿用分析设置中的千分位和科学计数法，改变设置或窗口尺寸不会重新查询。精确值保留在结果中，悬停数值可核对全文；非常接近的区间边界若科学计数显示相同，会显示完整边界以免混淆。
