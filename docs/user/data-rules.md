# 查看数据规则

打开并完成工作表加载后，点“数据”选项卡里的“数据规则”，或在单元格右键菜单中选择“数据规则”。

默认查看当前源单元格覆盖的规则，可切换“本表全部规则”，按类型或“需核对的定义”筛选。每页最多50条，保持文件保存的声明顺序。排序后的当前格仍按其源坐标查询。

选中规则后，可查看保存的条件、输入提示、错误提示、允许空白与下拉箭头设置。能确定的直接文字列表按原顺序显示，保留前导零和空白项；列表项与适用区域分别分页。来自引用、名称或不能完整解释的列表保留定义和原因，不自动读取候选值或运行公式。

“定位区域”选择保存的源区域，包括已用数据之外的空白位置。排序或筛选视图中的矩形范围须先清除筛选，再定位；不会替你清除当前视图。原始XML、属性和BIFF公式令牌/续记录可在“原始定义”中查看。

“已读取定义”只说明规则能够描述，不表示单元格的值通过了校验。若存在未完整读取或范围未知的规则，零命中会保留提示，不能据此判断当前格没有验证规则。普通与扩展规则的全局提示设置不一致时，也会明确标注。

读取可取消或关闭后重试，刷新失败保留已显示的结果。来源内容改变后应重新打开文件；切档或切表后重新读取对应来源的规则。支持范围由[格式能力](formats.md)决定：XLSX/XLSM和原生BIFF8 XLS提供只读规则查看，其他格式不推断Excel规则。此功能不修改源格、不选择写入下拉值，也不校验整表。

实际验证与实施边界见[实施清单](../development/improvement-progress.md)。
