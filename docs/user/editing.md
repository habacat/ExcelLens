# 编辑副本

打开文件，点工作簿工具栏的 **编辑副本**。工作表会保留原来的行列、格式和工作表标签。可直接点选单元格输入，也可双击、按 F2 或点上方编辑栏修改已有内容。编辑栏右侧的箭头可展开长内容。

1. 按 **Enter** 确认并下移，**Tab** 确认并右移，按住 **Shift** 可反向移动。点另一格也会确认输入。**Esc** 取消本次输入，**Delete** 清空当前格。修改确认后立即显示在表内。
2. CSV、TSV 按文本保存。XLSX 的自动类型保留原文本格、前导零与超过 15 位有效数字的编号。在编辑栏旁可显式选择类型。普通公式以 `=` 开头。可直接粘贴表格文本，一批一起撤销。需要预览、选择性粘贴、填充或设置数据规则时，点 **更多编辑**。
3. 点 **生成副本** 或按 **Ctrl+S**，完成核对后点 **下载副本**。在 **更多编辑** 中可打开已生成的文件，用搜索、筛选及分析工具查看该修订。**退出编辑** 返回原文件的阅读视图。

**撤销** 和 **重做** 也会保存修订。重新启动后，从 **最近打开** 打开原文件，再点 **编辑副本** 继续上次修订。**更多编辑** 中的 **已保存的编辑** 可切换到其他底稿。源文件须能访问且与创建时内容一致。若另一页面已提交新修订，点 **刷新修订** 查看并核对当前输入。

## 工作表、行列与透视图表

打开 **更多编辑** 后，文件名在标题下方，当前表名和单元格在工具上方。宽窗口点击工具标签，窄窗口使用 **编辑工具** 下拉框。底栏可以撤销、重做或生成独立副本。

- **工作表与行列** 提供重命名和整行整列的插入、删除、移动。起点和数量均从 1 计数，移动目标填操作前的行号或列号。例如把第 2、3 行移至原第 8 行之前，起始行号填 2，数量填 2，目标填 8。移动后，第 2、3 行的原内容落在第 6、7 行。表名、公式、固定名称、合并和适用的规则随结构调整。撤销可返回原坐标。
- 点选网格中的透视结果或分页标签，工具栏会显示 **透视布局**，点击就能调整选中的透视表。也可在当前工作表打开 **更多编辑 → 透视表与图表** 后选表。分别在 **行字段**、**列字段** 和 **分页筛选** 下添加字段。用上下箭头调整顺序，用叉号移除。把已在其他区域的字段加到新区域会移动该字段。
- 展开分页字段下的 **全部项目**，可按名称查找并勾选一项或多项。**显示全部** 清除该字段的筛选。多个分页字段共同筛选源记录。选好值字段和汇总方式后点底栏的 **应用字段布局**。从网格进入时，应用成功会回到原选区，可以直接查看小计、总计和分页标签。改动源数据后点 **刷新透视表**。撤销、重做及生成副本都会一同切换布局、筛选、结果和缓存。
- 工作表中的普通图表使用本簿单行或单列序列时，可点 **刷新图表数据**。透视刷新会同步更新引用结果的受支持系列。仅有普通单元格的工作表只显示适用的工具。
- 在 **透视布局 → 值筛选** 中选择已有行字段或列字段，可按前后 N 项、累计金额、累计占比或数值区间筛选。前后 N 项包含边界处的并列值，内层字段在各自的父项内排名。选择 **清除筛选** 可恢复该字段的全部值。
- 展开 **计算项目**，选择所属字段，输入项目名称和公式。可以按名称引用同一字段的普通项目或其他计算项目，例如 `=东区+西区`。选回已存项目可更新或移除。小计和总计按当前可见明细的计算结果汇总。
- 同一工作簿内，上游透视结果直接或通过工作表公式为下游缓存供数时，一次刷新会按依赖顺序更新。关联的专用透视图表跟随类别、层级和系列变化。撤销、重做会同时切换透视结果、缓存和图表。
- 对象编辑适用于本簿固定矩形来源、一个值字段和支持的普通汇总。多值字段、日期和标签筛选、分组、数据模型、组合透视图表及需要外部数据的对象保留在原文件中。结果扩张遇到其他数据或受保护区域时会提示位置或原因。

## 编辑 Excel 表格和保护表

- 双击数据行中的格即可改值。计算列使用 Excel 默认开启的公式自动填充行为。例如在“金额”列输入 `=[@数量]*[@单价]`，其余数据格仍沿用同一列公式时，整列和引用它的汇总一起更新。把一格改成常量可以保留单行例外。列中另有例外时，再输入公式只修改选中的格。
- 在汇总行输入标签、公式，或按 **Delete** 清空。可输入 `=SUBTOTAL(109,销售表[金额])` 汇总可见行。直接输入数字或布尔值时，Excel 会把它保存为汇总标签。一键撤销会同时还原格值和表格列定义。
- 在表格边界外输入会写入普通工作表单元格。表的范围固定，新增字段或扩展表格行数需要在 Excel 中调整。
- 受保护工作表中，已解锁的格可改值或输入公式，原下拉规则继续生效。粘贴或计算列自动填充涉及锁定格时，整批输入会被拒绝。表格字段标题、数组结果格、需要密码解锁的范围继续由各自的保护规则管理。

## 批量编辑

- **表格文本**按文本粘贴，支持跳过空白。**复制有类型数据**按源坐标复制所选矩形，再选**仅值**、**仅公式**或**仅格式**。仅值使用公式在当前修订的结果，保留文本、数字、布尔值及错误类型。仅公式按复制位置和目标位置平移 A1 相对引用。仅格式沿用同一工作簿已有的普通样式，重启后请重新复制格式。
- **数据规则**可在单个矩形内设置文字列表、引用列表、整数、小数、日期或文本长度规则。文字列表每行一项，候选合计最多 255 个 UTF-16 码元（含分隔逗号）。日期条件可用 `YYYY-MM-DD` 或当前工作簿的日期序号。规则修改用于之后的输入。应用单格、粘贴和填充时会检查相关规则。
- **引用列表**接受同表的绝对地址，例如 `$D$2:$D$8`。一行或一列最多 256 个来源格，每格须为非空的单行文本。点 **读取选项** 查看当前修订的候选，编号会保留前导零。同一批修改来源和目标时，按修改后的名单校验。
- **填充**支持同行或同列的当前值、等差数列、日期、时间和普通公式。日期步长为天，时间步长为秒，越过午夜的时间序列会被拒绝。文字日期用 `YYYY-MM-DD`，文字时间用 `HH:MM` 或 `HH:MM:SS`，可附三位小数。已有日期或时间格式的 XLSX 数值按工作簿日期系统填充，预览会提示沿用起点格式。每批可一次撤销。
- 确认输入后，同表及其他工作表中依赖该输入的公式会更新。撤销、重做或重新打开编辑副本均按当前修订显示。公式栏保留表达式，网格使用原数字格式显示结果。生成 XLSX 时会清除失效的保存结果，并请求 Excel 重算。

## 支持范围

| 来源 | 可编辑内容 |
| --- | --- |
| CSV、TSV | UTF-8、UTF-8 BOM、UTF-16 LE/BE、可逆的 GB18030。保留原记录数、各行原有字段数、空字段和格内换行。缺字段的地址不支持写入。 |
| 普通 XLSX | 全包预检通过后，可编辑Excel 工作表地址范围内的普通值、样式、受支持的 A1 公式和数据规则。 |
| 复杂 XLSX | 全包预检通过后，可在未分配的格、行或空表中写值和公式。普通公式及共享公式均可逐格修改，数组通过左上角编辑。复制、粘贴、填充和恢复遵循同一坐标规则。 |
| 带批注或宏的台账 | 在工作表中编辑普通值、公式和空白格，保留批注框、已有样式及打印设置。通过预检的宏工作簿按 XLSM 输出，保留 VBA 项目、表单按钮和外部工作簿链接。 |

### 复杂 XLSX 的公式与区域

工作簿和工作表作用域的固定命名区域、区域别名、数值、布尔及文本常量，以及按工作表保存的打印区域、重复标题和筛选名称均可保留。引用普通名称的受支持源公式会按实际作用域跟踪其来源。动态、外部或含活动代码的名称会提示具体原因。

报表中的本簿数据透视表及缓存、静态自定义属性、内嵌 PNG/JPEG 图片、合并、已保存筛选和受支持的共享及数组公式随副本保留。尝试编辑受保护的格时，编辑栏上方会显示原因。

- 新增单元格可以位于原有数据之外。名称框可直接跳到地址，例如 `Y30`。新增格继承适用的行列样式，保存后已用区域随之扩展。Excel 工作表坐标上限为 XFD1048576。
- 双击或按 F2 修改普通公式和共享公式的任意成员。共享组内的其他成员保留各自的实际引用。格内和公式栏支持本簿引用、可解析的定义名称、整行整列、条件汇总及查找，例如 `=INDEX(B:B,MATCH(D2,A:A,0))`。也支持 `ROW()` 和 `COLUMN()` 获取公式所在的行列。
- 普通计算错误按原类型显示，如 `#DIV/0!`。循环依赖显示**循环引用**。受影响的多格数组、使用“以显示精度为准”的工作簿和超出本机计算容量的公式显示**待重算**。透视输出按布局使用上方的刷新操作或 Excel。
- 在网格拖选或按住 Shift 加方向键选择矩形，点 **区域编辑** 可以合并或取消合并。选区有多项内容时，确认后保留从上到下、从左到右找到的第一个值或公式。撤销可恢复原有内容和引用。
- 输入 `=SEQUENCE(A1,2)` 等数组公式后，在网格中改 A1 会同步更新溢出区域及跨表引用。遇到占用格时显示 `#SPILL!`，清除障碍后自动展开。可用 `=SUM(B2#)` 引用 B2 当前的整个溢出范围。
- 在 **区域编辑** 中选择 **设置固定数组**，填入目标矩形和公式，可以创建或调整传统数组。在数组任一格打开区域编辑可定位其原范围。使用 **清除数组** 释放全部结果，撤销可恢复公式、原范围和结果。每次范围编辑最多 10,000 格。
- 透视表的输出区域与数据源字段标题由透视表管理。可编辑其周围的格及可刷新的源数据。源数据或上游公式改变时，副本会标记受影响的缓存。支持的布局可立即手动刷新。需要 Excel 求值时，先执行**公式 → 开始计算**，再执行**数据 → 全部刷新**。源文件明确禁用刷新的缓存会保护其输入工作表和依赖。
- 副本保留源工作簿的计算模式和迭代设置。公式结构变更会移除可重建的旧计算链，未受影响的公式结果和结构部件随副本保留。未保护的普通格可以粘贴同簿中已有的单元格格式。受保护工作表沿用源格式，已有的复杂规则定义随工作簿保留。
- 已保存的跨表文本下拉可从**更多编辑 → 读取选项**选择，也可直接输入候选值。固定单行、单列和整列来源按当前修订取值。单个来源最多 256 个有值单元格。无法求值的条件会在应用该规则的格显示原因。
- 复杂台账中需要外部工作簿、VBA 或超出本机即时计算容量的公式，保存后在 Excel 中重算。有透视表时按保存提示刷新。数字签名、尚未识别的部件和无法核对的结构仍可能限制编辑。

CSV、TSV 生成时可选择源编码、UTF-8 或 UTF-8 BOM。默认在以 `=`, `+`, `-`, `@` 开头的公式形式文本前加单引号，副本记录会显示受影响格数。取消勾选可导出逐字保留的字段值。Excel 或 WPS 打开分隔文件时仍可能推断编号或数值类型。

预检处理最多 512 MB 的源文件和 200 万条文本记录。单条文本记录最多 8 MB，每个编辑格最多 256 KB，一批最多 10,000 格。XLSX另有部件解压限制。超限或核对失败会保留已确认修订，生成过的副本可以继续下载。
