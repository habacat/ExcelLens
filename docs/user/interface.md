# 工具栏和命令

打开文件、切换工作表、搜索、筛选或生成副本时，如果等待超过半秒，当前标签页会显示进度。从“最近打开”进入时，进度显示在文件名下。可以计量的任务显示真实进度或字节数，带“约”的百分比是当前操作的估算。系统开启“减少动态效果”时，可以直接查看静态进度。

顶部保留打开、搜索、筛选、排序、导出、分析和命令。窗口较窄时自动收放其他入口，必要时分行；按钮文字保持原字号。

点击“命令”或按Ctrl+K，输入功能名称即可查找。对账、关联、命名视图、行与大纲、原格式及图片开关等可从这里使用；不适用于当前来源的功能显示为禁用。

在命令面板中用上下方向键选择、Enter运行、Esc关闭。也可输入工作表名快速切表。常用快捷键见程序中的“快捷键与操作帮助”。
