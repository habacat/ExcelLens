# 工具栏与托盘

## 界面语言

ExcelLens 支持简体中文、繁體中文、English、日本語、한국어和 Русский。默认按浏览器语言打开页面，托盘按系统显示语言显示。右键 Windows 通知区域的 ExcelLens 图标，打开「语言」选择固定语言或恢复「自动」。选择会保存，空闲首页随之切换。已打开的工作簿在返回首页时切换。工作表内容、名称、公式和文件名按原文显示。

## 工具栏

打开文件、切换工作表、搜索、筛选或生成副本时，如果等待超过半秒，当前标签页会显示进度。从“最近打开”进入时，进度显示在文件名下。可以计量的任务显示真实进度或字节数，带“约”的百分比是当前操作的估算。系统开启“减少动态效果”时，可以直接查看静态进度。

默认使用经典布局。打开、搜索、筛选、排序、冻结、导出、编辑副本和分析等按钮与文件名同排。公式栏两侧的工具只显示图标，鼠标移上可看名称。左侧依次是名称与表、数据规则和记录卡片。右侧的“A”可切换显示字体，其后是复制公式、复制当前值、追踪引用、追踪从属和单元格信息。长公式可用公式栏右端的箭头展开。

框选单元格后，点击底部统计数值左侧的图标可选择平均值、计数、数值计数、最小值、最大值和求和。菜单同时列出这六项的当前结果。计数包含非空文本，数值计数按工作表的数值口径统计。数字可按中文单位、千位或万位分隔，再点一次当前分隔方式可显示原始数字。设置会自动记住，点击状态栏数值可复制完整数字。编辑副本的结果随已确认的修改和撤销更新。

窗口变窄时，顶部优先保留打开、搜索、筛选、排序、导出和分析。“查找功能”自动缩短，最窄时显示放大镜。点它或按 Ctrl+K，可按多个关键词查找命令，也可输入工作表名。使用上下方向键选择，按 Enter 执行或 Esc 关闭。

右键顶部按钮区域，或右键 Windows 通知区域的 ExcelLens 托盘图标。勾选“选项卡布局”可切换到“开始、数据、公式、视图、核对”五页功能区，取消勾选可恢复经典布局。设置会随用户保存。选项卡布局可用 Ctrl+F1 折叠，窄窗下的命令可从“更多”打开。

托盘里的“打开程序所在目录”会打开当前运行的 ExcelLens.exe 所在文件夹。“清理历史缓存”保留当前工作簿。“清除所有缓存（含当前）”经确认后会结束各工作簿的后台任务、清除索引及查询缓存，并让各页面返回首页。正在输入的内容应先确认或保存。原始文件、上传副本、已保存的编辑修订、标记和偏好仍可使用，下次打开工作簿时会重新建立索引。清理范围限于工作簿索引、查询和压缩包成员缓存。

## 搜索大量匹配

普通搜索最多返回 500 项。需要完整台账时，在搜索框勾选「全量搜索」，选择当前表或全部工作表后执行。每页显示 100 项，点击命中可回到原表坐标。结果内的文字与工作表条件作用于全部命中，修改条件会回到第一页。

复制按钮复制当前页的预览，长文本预览最多显示 512 个字符。「导出为 CSV」写出当前条件下的所有命中及完整文本。可能被表格软件当作公式的文本会带有保护性单引号。需要跨次启动继续时，在搜索前勾选「保留进度」。临时磁盘或检查点配额耗尽时，任务显示失败原因。

## 本地数据

首页右上角和工作簿工具栏的「本地数据」可查看各类文件的占用空间。页面按已分配给常规文件的磁盘字节统计，包含各目录项，硬链接按项计数。读取失败的分类显示未知和具体原因。展开数据名称可查看该分类的文件位置。「存储目录」列出当前账户的配置和本机数据根目录。

- **索引和上传副本。** 两项清理分别确认。历史索引可从原件重建。闲置上传副本可能是本机仅存的一份数据，清理前可先备份。正在使用的来源及确认的编辑或任务恢复来源会保留。
- **标记和布局。** 审计标记、手动行高列宽和冻结窗格保存在用户配置目录。备份或清理索引前会先迁入旧索引目录内的冻结设置。首次读取工作簿的旧记录时，程序会核验并复制到新位置。点击「迁入旧标记与布局」可一次处理其他工作簿。原位置的文件保留；新旧内容有差异时，继续使用配置目录中的版本。
- **备份与迁入。** 备份时填写目标父目录，迁入时填写生成的完整备份目录。需要保护内容时在「备份口令」输入密码，迁入加密备份时输入相同口令。口令遗失后无法恢复。索引可以重建，外部原件须另行保存。传输记录显示进度、结果及失败原因。关闭页面后可从首页重新查看。提交恢复事务前可以取消，开始提交后会完成各个数据单元。程序意外退出后再次启动会核验并继续已提交的事务。
- **传输历史。** 历史损坏后仍可创建备份。本次运行的传输记录暂存于内存。点击「重建传输历史」并确认，程序会在配置目录留下原文件的独立诊断副本，并将本次记录保存为新历史。文件在确认期间发生变化时，需要重新核对。较高版本的历史或无法读取的文件会保留，页面显示原因。
- **继续恢复。** 启动时如发现待处理事务，程序先打开「本地数据恢复」，并在后台核验、发布，显示已处理字节数和数据单元数。遇到冲突时，可按显示的位置留存冲突文件或修正权限，再点击「继续恢复」。完成后自动进入首页。
- **活动页面的筛选。** 任务中心显示「活动页面使用中」时，可在原页继续滚动、统计和复制。要释放行序，请在原页清除筛选或关闭标签页。其他活动页面正在读取的全量搜索结果也受到保护。
- **磁盘空间和残留。** 备份预算包含加密对象、清单和目标卷分配空间。迁入按卷统计需要暂存的文件、事务记录和余量，传输期间复核空间。要检查上次中断的备份，请指定备份父目录，展开「未完成的备份」并点击「检查目录」。有效标记和写锁可判断哪些暂存能够清理。旧版无标记目录会列出供人工核对。
- **重定位来源。** 迁入后在「重定位来源文件」中选择底稿或任务的来源，指定新路径，核对两处路径后确认。已迁入的上传副本会显示候选位置。原路径及每次确认的时间均可查看。同名不同内容会被拒绝。旧版任务若缺少整文件摘要或原索引证明，可以在旧电脑上用本版重新备份。旧证明无法补齐时，需要重新运行相应任务。
- **命令行迁入。** 先退出托盘程序，明文备份可执行以下命令。加密备份加上 `--password-stdin`，由标准输入提供一行口令。

```powershell
.\ExcelLens.exe --restore-data "D:\备份\ExcelLens-20261124-153000-12345"
```

关闭标签页后，会话会保留 45 秒供刷新恢复。如果浏览器退出时未能发出关闭通知，服务会在连续 10 分钟没有请求或心跳后回收。本机服务运行期间，如果浏览器完全冻结后台页超过该时限，该页返回后也可能需要刷新并重新打开工作簿。已提交的搜索、筛选、导出、独立分析与双表对账可继续执行。从「本地数据 → 后台工作簿任务」查看进度、取消任务、丢弃结果或释放已关闭的会话。迁入遇到在用工作簿或运行中的任务时会列出名称。已关闭页面的完成结果可独立保留，迁入结束后仍能接回。关闭原页面后可在这里查看结果；完成的内存结果通常保留 15 分钟；会话总量达到 128 个时，开新页可提前释放最早闲置且已完成的会话。程序退出时会释放内存结果。勾选「保留进度」的搜索、筛选和导出可以在重新启动程序后从「可恢复任务」继续。
