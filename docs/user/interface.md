# 功能区和命令

打开文件、切换工作表、搜索、筛选或生成副本时，如果等待超过半秒，当前标签页会显示进度。从“最近打开”进入时，进度显示在文件名下。可以计量的任务显示真实进度或字节数，带“约”的百分比是当前操作的估算。系统开启“减少动态效果”时，可以直接查看静态进度。

顶部第一行是文件名、五个选项卡和命令搜索，第二行是当前选项卡的命令。

| 选项卡 | 命令 |
| --- | --- |
| 开始 | 打开、导出、编辑副本、复制、搜索、筛选、清除筛选、排序、冻结、分析、统计、计算 |
| 数据 | 高级筛选、表头（文本文件）、查重、定位条件、数据规则、记录卡片、快速分析、转置 |
| 公式 | 显示公式、追踪引用、追踪从属、名称与表 |
| 视图 | 列、行与大纲、原格式、图片、字体、命名视图、分页预览、全屏 |
| 核对 | 对账、关联、标记、比较快照、任务恢复 |

当前来源用不上的命令显示为禁用或不显示。窗口较窄时，排在后面的命令收进“更多”；窗口很窄时按钮只显示图标，悬停可以看到名称。文件名始终留在顶栏。

点功能区右端的箭头或按 Ctrl+F1 可以折叠功能区，给表格腾出一行。折叠后点选项卡会临时展开，执行一个命令后自动收回。

名称框左侧的两个箭头返回和前进到之前的位置。名称框右侧是公式栏，最右端的按钮打开单元格信息。

点击“查找功能”或按 Ctrl+K，输入名称即可查找命令。可以用空格分开多个词，名称匹配的排在前面；以前的叫法（例如“转置阅读”“选区快速分析”“双表对账”）仍能找到。执行后功能区会切到该命令所在的选项卡。用上下方向键选择、Enter 运行、Esc 关闭。也可以输入工作表名快速切表。常用快捷键见右上角的“快捷键”。
