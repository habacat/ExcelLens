# 名称与表目录

点击名称框旁的“名称与表”，或按`Ctrl+F3`，查看当前工作簿保存的定义名称和表对象。在名称框输入一个名称后回车，也会打开目录并搜索。

列表可按名称、工作表和类型筛选，每页最多50项。选中条目可查看完整名称、作用域、隐藏状态、原始定义、注释和无法定位的原因。表对象另列出列名、表头行和合计行；列定义也分页显示。

“定位区域”使用源工作表和源坐标。含多个区域的名称先选择其中一个区域，再定位。普通名称中的常量、相对地址、外部引用和不能确定位置的表达式保留定义，不执行公式。筛选视图中的矩形范围需要先清除筛选，单格定位沿用已有筛选和显隐处理。

表对象需要核对工作表真实声明。普通索引已经完成这项核对时，可直接定位；否则选择下方工作表并点击“确认表对象”。未准备索引的表须先点击“打开工作表”，待加载完成后再确认。目录列表本身不扫描单元格、不建立其他工作表的索引。

读取期间可取消或关闭目录；取消后重试不会采用上次迟到的结果。切换文件会清除旧目录，即使两个文件的内容相同，也分别核对来源。较长的名称在列表中省略，详情保留完整原文。

XLSX、XLSM和原生BIFF8 XLS按[格式能力](formats.md)启用入口；HTML内容的XLS及其他来源不提供此目录。旧版XLS中的Web数据提供程序列、合计数组公式附加数据和未知结构会明确标注限制。此功能只读，不修改名称、表定义或源单元格。
