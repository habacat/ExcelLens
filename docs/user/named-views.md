# 命名视图

从“查找功能”选择“命名视图”，保存并复用工作表的筛选、排序和显示设置。

## 保存与应用

1. 完成当前工作表的筛选、排序和显示调整后，运行“命名视图”。
2. 填写名称，点击“保存当前”。一个工作簿最多32个视图，名称最多80字。保存的是实际成功执行的筛选与排序，尚未生效的对话框修改不会混入。
3. 选择已有视图，点击“应用视图”。软件先核对来源、工作表和字段；有筛选或排序时重新执行查询，成功后应用布局。取消或查询失败时保留当前视图。
4. “更新所选”用当前工作表的规则及显示设置更新所选项目；“删除所选”只删除该项本机配置。

视图包括筛选、五级排序及显式排序方式、冻结、行高、列宽、列显隐、字体、缩放、原格式和公式显示，也保存当前成功显示的行显隐与大纲展开状态；先准备完整显隐快照，再恢复画面，不只应用部分配置。TXT的字段栏也会恢复，并从真实源行重新读取字段名。应用另一个Sheet的视图时会回到它绑定的Sheet，不把相同列号套用到当前表。

## 来源与保存边界

视图按源内容指纹保存。同内容文件改名后可复用；内容不同的文件不会自动套用旧视图。字段匹配和规则版本失效时明确拒绝应用。视图不保存全表数据、行序临时文件或分析结果，也不执行源公式。

设置位于用户配置目录的`ExcelLens/named-views/`。清理索引缓存和上传副本不会删除它们；查看列表或重启应用不会自动运行视图查询。应用视图只改变当前页面；源文件保持只读。已有的普通显示设置和命名视图分别保存，不会因应用视图而改写其他页面的布局，也不会自动覆盖“行与大纲”单独保存的显隐偏好。需要下次打开仍使用新显隐时，在[行与大纲](row-visibility.md)中勾选“记住设置”后执行相应操作。

保存带修订号校验；其他页面修改了同一本工作簿的视图列表时，先“刷新”再重试。读到损坏、未知版本或超限文件会明确报错并保留原文件。单项配置上限256KiB、整个列表上限4MiB；达到限制时减少尺寸覆盖或删除不用的视图，不会静默截取配置。

当前自动化证据见[命名视图实现与验证](../development/named-views.md)。这些检查不等于桌面人工验收。
