# 打印区域与分页预览

打开文件并完成工作表加载后，按Ctrl+P，或点“视图”选项卡、右键菜单里的「分页预览」，查看只读分页。入口是否可用遵循来源格式能力；不支持打印设置的来源保持禁用。

## 查看与调整

- 使用上一页、下一页、页序输入框或画布中的PageUp/PageDown翻页。页序和源起始页码分别显示；只读取当前页内容。
- 「屏幕缩放」只改变纸张在窗口中的大小，不改变分页或重新查询源数据；窄窗口可先收起「页面设置」。
- 纸张、方向、打印缩放或适配页数、区域、重复标题和边距使用源设置。调整后点击「更新预览」才重新分页；「页面详情」标明源属性、规范缺省、预览补足和用户覆盖。
- 区域使用源地址，如`A1:H50`，多个区域用逗号分隔。重复行如`1:2`，重复列如`A:B`；留空沿用源定义，明确勾选「不重复行/列」才清除。适配页数的0表示该方向不限，至少指定一个方向。
- 预览按源表行列顺序和源隐藏状态分页，不采用画面中的排序、筛选或临时列宽。超大行列可跨页显示连续切片，重复标题按设置出现。
- 取消更新或读取失败时保留上一次成功预览，修改后的设置仍可重试。切换文件或工作表、关闭预览会释放原任务。

## 数值与还原边界

在分页预览底部选择当前页、指定页段、本表全部页或整本可见表，点击“导出打印底稿”。页段可输入 `1-3,5`。打开下载的离线 HTML，按 Ctrl+P，可打印或在打印窗口选择“另存为 PDF”。底稿固定纸张和分页，屏幕缩放不改变物理尺寸。整本输出使用当前表已确认的预览设置，其余可见表按各自的源设置分页。单次最多 250 页、64 MiB，超限可按页段导出。

缺少公式缓存的格在底稿上明确标识。底稿附上来源的近似或未支持提示，字体取决于打开底稿的系统。页段中的各页保留原有重复标题。源页眉、页脚和图形的支持范围与预览一致。

窄数值格显示`#`，避免只露尾数造成误读；悬停可核对完整显示值。主网格和冻结区使用同一提示，双击列边界可按内容自动调整列宽。源金额、文本编号、类型及坐标保持；前导零文本不会因宽度不足转成数值。公式缺少保存结果时保留该状态，不计算或补造结果。

纸张保留源颜色，周围工具界面跟随阅读主题。支持常见字体、富文本、条件呈现及合并边框；字体替代、列宽换算和未知设置会提示近似或限制。页眉页脚保留原定义供查看，页眉图形、其他工作表图形和打印机配置不作为已还原的单元格内容。预览不发送打印任务，也不写回源文件；Office/WPS和桌面人工打印一致性尚未验收。
