# 记录卡片

在工作表中选中一行，点公式栏的“记录卡片”，或从右键菜单打开。字段名和值纵向排列，适合查看宽表和长文本；卡片只读，不修改源文件。

- “上一条 / 下一条”按照当前排序、筛选和行显隐切换，冻结行保留在前面且不重复。卡片同时标明记录位置、源行号和源列，点击“定位 A2”等按钮返回源单元格。PageUp / PageDown 也可切换记录。
- “字段名所在行”默认使用当前表头行，没有表头设置时默认第1行；填0只使用列字母。起始列可输入字母或列号，点击“读取字段”应用。空白和重名字段按各自源列分别显示。
- 每次最多读取32个字段，用“上一页 / 下一页字段”浏览宽表，也可直接输入目标列。内容过大时减少“每页字段”后重试，或使用导出。取消或读取失败会保留最后一次完整结果。
- “显示值”沿用源单元格的显示文字，“原值”查看保存的原始字符串；不会把编号或文本金额转成数值。复制按钮始终复制当前模式的完整内容，长文本的“查看全文”按段展示，“复制完整内容”包括所有段落。
- 有公式时可单独查看可还原的公式文字。公式没有保存计算结果时会明确提示；无法还原的公式不会编造表达式，也不会把提示文字复制成数值。

切换文件、工作表、排序筛选或行显隐后，重新选中记录再打开卡片。原始文件仍按[格式说明](formats.md)中的能力和只读边界处理。
