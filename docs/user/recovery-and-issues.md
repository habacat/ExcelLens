# 输入恢复与异常核对

## 查询与导出任务恢复

在搜索、筛选、排序或导出时勾选“保留进度”，即可将进度保存到本机。有可继续的任务或可取回的结果时，首页“最近打开”标题旁会显示“任务恢复”。打开工作簿后，也可以从“查找功能”选择“任务恢复”查看已保存的任务。恢复时按提示打开原文件并选择操作。

原文件尚未打开时先点“打开原文件”，再点“继续”；完成的导出任务点“下载”重新生成下载文件。搜索结果回到搜索窗口，筛选/排序回到网格，导出仍使用导出中心。恢复筛选窗口只显示该任务的进度与取消；要建立新条件，关闭后从主界面打开“条件”或“排序”。来源路径改变时，可从「本地数据」核验新位置并确认。新任务会以内容摘要核对重建的索引；内容、解析规则或索引内容不符会报告失败。旧版任务的迁移条件见[本地数据](interface.md)。

关闭任务窗口会保留进度；运行中的查询/导出在各自窗口取消。只有“移除”才删除所选的恢复任务，不删除原文件。列表显示“运行中”时不能移除，任务状态变化后点“刷新”。任务恢复数据位于用户配置目录的`ExcelLens/task-checkpoints`，与输入草稿和普通缓存分开；最多32项、共享8 GiB，超限需移除不再使用的任务。

文本输出按完整记录确认；XLSX及ZIPCSV在完整工作表结束后确认，中断的工作表重新生成，已确认的工作表保留。保存导出范围尚未完成就中断时，须重新选择范围；不会接写未完整的CSV记录或XML片段。以上均为只读来源的任务恢复，不提供源文件编辑或保存。

## 计算表恢复

公式及备注会合并增量保存到本机恢复副本。计算窗口显示“已保存”后，表示当前输入已得到磁盘同步确认；“恢复保存中”或“恢复未保存”时，当前页面仍可能有未确认内容。突然断电或强制结束时，尚未确认的输入可能丢失。

同一页面刷新会恢复其副本。重新启动后，点击计算窗口的“恢复”，按时间预览并载入旧副本。其他计算表追加到本页末尾，旧副本保留。恢复后的公式显示“待计算”，只有按Enter或实际改动公式后才执行；切换焦点、修改备注不执行未改动的恢复公式。结果不作为旧快照恢复。

每个浏览器标签页使用独立副本。发现同一副本被其他页面修改时，保留本页输入并停止覆盖，点击“另存本页副本”继续。保存失败可重试；超过容量后先缩短或清除部分内容，再保存。单个用途的副本最多8 MiB、20,000条；这不是计算表或原始文件的行数上限。

## 分析草稿恢复

分析工作区中的“恢复草稿”找回未确认单元格输入。草稿按原文件内容身份、编辑表及坐标匹配，不会自动提交到已保存的分析表。本页同格新草稿优先保留。打开对应原文件和编辑表后，核对单元格提示中的“当前已保存值”，再点击“重试保存”。

“备份”和“导入备份”仍用于完整分析工作区；恢复草稿用于未确认输入，两者用途不同。旧确认响应不能清除更新的草稿。跨工作簿的草稿保留在各自身份下，不会写入当前无关文件。

恢复文件位于Windows用户配置目录的`ExcelLens/recovery`，与原文件、索引缓存和已保存分析工作区分开。缓存清理不删除恢复副本，旧副本不自动清除。日志损坏会明确报错，不将完整但校验失败的记录当作正常结束；未完成尾帧会先留存证据，再恢复前面的完整记录。

## 异常与排除项目

透视结果出现“核对项目”时，可以查看源位置、参与字段、原文、步骤输入及排除原因，点击源位置返回对应格。

这里的“项目”不是错误结论。同一行可能有多项；原生Excel文本本来就不隐式参与数值聚合。转换失败覆盖全部扫描记录，数值排除及缺缓存覆盖筛选后纳入的指标字段。多个指标共用一个字段时不重复计数。

界面最多显示前100项，原文片段最多512个Unicode字符，截取会标明。提取编辑表最多10,000项、16 MiB文本预算，单格超过4000字符时保留片段并标记“内容截取”。达到限制会显示提取数量与完整项目数。

完整CSV逐行写入磁盘，通过导出中心查看进度、取消和下载。它不受样例或编辑表条数限制，原文不截取；受可用磁盘和任务状态约束。CSV文本保护会给公式形式的文本加单引号，相关列名会注明；需要逐字保留原文时取消勾选。

提取绑定实际完成的分析任务和来源内容摘要。来源编辑表在分析后改变时，先重新运行分析；不会把新数据当作旧结果的异常明细。所有操作保留源文件只读语义。
