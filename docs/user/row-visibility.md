# 行与大纲

源文件保持只读，行号始终对应原始文件。显示或隐藏行、大纲展开与折叠仅改变当前视图。

打开工作表后点击“行与大纲”：

- “原始显隐”恢复文件中的隐藏、零行高和大纲状态；“显示全部”显示所有源行。
- 填写源起始、结束行号，点击“隐藏”或“显示”。排序后仍使用原始行号。
- 对分组点击“展开”或“折叠”，或选择“大纲层级”后点击“展开到此级”。展开父组会保留子组自身的折叠状态。
- 勾选“记住设置”后，操作成功才保存到本机；取消勾选则只影响当前画面。源文件不会改动。

方向键、冻结、复制和选区统计跳过隐藏行。地址框、搜索等明确定位到隐藏源行时，会临时显示该行；这个临时选择不会覆盖已保存的显隐。全隐藏时没有选中格，可用“显示全部”恢复。

画像等分析入口捕获画面选区时排除隐藏行；自己填写源范围时仍检查该范围的源行。导出选“当前可见行”包含可见冻结标题并保持排序；“完整筛选结果”包含手动隐藏的匹配行。应用命名视图可恢复显隐和大纲，但不会自动覆盖单独保存的显隐偏好。

源合并区域的起始行隐藏时，剩余格按原坐标显示；恢复起始行后还原合并。隐藏不会把起始格的值移到别的源行。

显隐设置损坏时会报告原因并保留原文件。点击“暂时显示全部行”可以继续查看；此时“记住设置”不可用，后续显隐只临时生效。修复本机设置后重新打开可重试，不会自动覆盖损坏文件。多个页面同时保存产生修订冲突时，刷新页面核对最新设置后再操作。
