# 选区快速分析

在工作表选择一个连续区域，按 **Ctrl+Q**，或在右键菜单里点“快速分析”，然后点击“运行分析”。统计窗口里也有入口。

- **逐列分布**：完整计数负数、零、正数、空白、其他值、错误、缺少公式缓存及无效数值。这是符号和类型分布，不是区间直方图。原生Excel文字保持文字，编号前导零不转换。
- **两列差额**：选择被减列和减列，按同一条选中可见行计算“被减列 − 减列”。两侧都有有效数值才计算；未配对的行单独计数，不补0。默认不比较。
- **趋势**：选择要查看的源列或差额。全部选中行连续分为最多60段，横轴为分段编号，折线表示每段数值的平均值；没有有效数值的段断开。点击图点查看对应选中行序和源行，展开“分段精确数据与源位置”查看完整合计、平均和极值；图不是逐行图或抽样，金额计算保持精确，绘图使用近似值。

需要去掉表头时，勾选“跳过首条选中行”，再运行。不会自动猜测表头、转换日期或重新计算源公式。统计遵守当前筛选、排序、隐藏行和冻结前缀；选区的源列区间包含隐藏列，源行号因排序可能不连续。

支持单格及最多16列、40万格的一个连续选区。超出格数、源行字节或所选文字预算会明确拒绝，不返回少量样本冒充完整结果。更大的分析请使用分析工作区。

合计及差额使用精确十进制/有理数。不能有限表示的平均值保留精确分数；显示沿用分析的千分位和科学计数法设置，悬停查看精确值。极值旁的地址可定位源单元格，差额极值定位同一行的被减列。

可以取消并立即重试。同一选区重试失败或取消会保留上次完整结果并说明；修改设置后需重新运行。关闭、换选区、切换文件/工作表或更新行视图会清除旧结果。结果只在本次窗口保留，不写入源文件。
