# 多表追加与字段对齐

在“分析”左侧点击“多表追加”，将多份数据按字段向下合并，再进行透视、画像或明细分析。源文件保持只读。

1. 选择各份文件和工作表；“添加文件”可打开其他数据文件。
2. 设置表头行和范围，点击“读取字段”。“当前分析范围”只可用于对应的当前来源，范围改变后需重新读取。
3. 核对“字段对齐”。完整且唯一的原始表头会建议对应；重名或未匹配项需选择字段，也可明确设为空列。搜索字段名或列字母可选择宽表末尾列。
4. 点击“预览”，检查值和原行号，再点击“用于分析”。预览最多100条，分析读取全部范围。

类型提示只描述前8条样本。不同来源可以保持不同源类型；原生Excel文本金额继续作为文本，CSV等按既有金额规则统计。前导零编号、缺少公式缓存及未匹配空列不会被自动转换。

明细显示来源文件、工作表和原行号，点击有值的来源格可跳转到原位置。来源关闭、变化或范围失效时会报错，不能用新内容替换旧结果的来源。

“保存定义”保留文件身份、范围及字段对应，不复制源记录。最多8份来源、256个结果字段、32份已保存定义；普通上传最多附加4个文件。复用定义前需先打开对应文件，跨页面保存冲突时刷新目录后重试。

“保存报表”另保存本次分析和完整联合定义，重开仍使用原范围和映射。分析方案目前只支持单表，联合来源的该入口禁用。取消或准备失败会保留此前的分析结果。
