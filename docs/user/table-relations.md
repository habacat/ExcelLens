# 关联与未匹配提取

在命令面板（Ctrl+K）选择“关联提取”，按关联键组合两份表，或提取已匹配、未匹配和无效键记录。源文件保持只读。

## 操作

1. 选择左右文件和工作表，设置表头行后点击“读取字段”。0表示没有表头；已保存的分析表使用自己的列名，表头固定为0。“添加文件”不会替换当前主文件。
2. 核对关联键。相同且完整唯一的原始表头会建议对应，其他字段可搜索名称或列字母选择。最多4组键，所有键同时满足才匹配。
3. 在两侧“结果字段”中选择需要的列，每侧最多64列。关闭字段窗口会放弃此次选择，点击“确定”才应用。
4. 点击“运行关联”，再选择提取类别。切换类别复用此次预检，不重新关联整表。

匹配方式与[双表对账](reconciliation.md#核对方式)相同：默认保留源类型；按显示文本或精确数值解释必须明确选择。编号`001`不会默认与数值`1`配对。空键、错误值、缺少公式缓存及不可信类型分别记为无效键，不算作确认未匹配。

## 提取类别

| 类别 | 输出 |
| --- | --- |
| 左表全部 | 每条左记录及对应的全部右记录；没有对应项时右侧为空，保留未匹配或无效原因 |
| 匹配明细 | 所有实际匹配的左右组合 |
| 左表已匹配 | 每条已匹配左记录输出一次 |
| 左表未匹配 / 右表未匹配 | 有效键在另一侧不存在的记录 |
| 左表无效键 / 右表无效键 | 空键、错误、缺少缓存等无法可靠匹配的记录 |

“左匹配”“右匹配”按原记录计数，提取数量按实际输出行计数。例如同一个键左侧2条、右侧3条，“匹配明细”输出6条，不只取第一条。结果保持左表原序，同一左记录内保持右表原序；仅右侧类别按右表原序。

预览最多100条，每页20条，宽表按可用宽度分页显示字段。点击源行或单元格可定位原位置，其他文件在新标签页打开。更改配置不会修改上次结果；失败或取消保留上次已确认结果。源文件或分析表内容变化后，需重新读取字段并运行，不能将旧结果跳转或提取为新来源。

## 完整导出

“导出结果”进入公共导出中心，按当前已确认结果与提取类别输出全部记录。格式可选CSV或ZIP；10万条起默认选ZIP，手动选择后不会自动改回。ZIP内是完整CSV，解压后与直接导出的CSV逐字节相同；直接流式生成，不先占用一份未压缩临时文件。

默认导出上限100万条，可明确调整至最多10亿条；预检超过所填上限时拒绝导出，不生成截断的成功文件。潜在组合的完整数量仍会精确显示，实际可用规模同时受共享临时磁盘和任务预算约束。

CSV保留原文和两侧源行，另附文件、来源指纹、快照、原列以及对齐的原类型、存在、缺缓存和不确定状态。不存在的一侧与存在但空白的格子分开。CSV不保存Excel显示格式；原类型在附加列中保留。

默认“文本保护”会给可能被表格软件执行为公式的文字添加保护前缀；需要逐字原文时可明确关闭。完整下载使用源记录，不从预览拼接。关闭关联窗口会保留本页结果，清除结果或切换主文件后需重新运行。清除结果不影响已经开始的导出；刷新页面后关联界面需重新配置。

工程及当前验证边界见[关联实现记录](../development/table-relations.md)。
