# 转置阅读

选中一个连续区域，从“查找功能”选择“转置”，或在右键菜单选择“转置查看”。顶部按原行号排列，左侧显示原列字母，便于横向比较记录。原表保持不变。

点击格子，在下方查看源坐标、源类型和完整内容。“显示值”“原值”“公式”切换只改变阅读方式，不重新查询；缺少公式保存结果或无法还原的表达式会保留未知状态，不能当作空白有效值复制。点击“复制”复制当前完整内容，“定位原格”返回主网格。

原行数较多时，使用上一页/下一页。窗口尺寸变化自动调整每页列数，不缩小字号或重读原表。长文字在格子中显示有限预览，下方可以查看和复制完整内容。富文本、数值格式与可用的条件呈现复用公共显示逻辑。

范围沿用公共复制语义，包括排序、行显隐及冻结选区中的源行对应；坐标始终是源坐标。合并格不展开成新的重复值，覆盖格保留自己的源状态。切换文件、Sheet、选区、筛选/显隐或冻结设置后关闭旧窗口，以免把旧内容当作新来源。

单次最多250个源行、50个源列、5000格，并受公共文字/样式容量约束；超限会明确拒绝。只读取所选范围，不把整张大表变成大量可见列。失败保留上次完整内容，可重新读取；取消或关闭后迟到的读取不会覆盖新内容。
