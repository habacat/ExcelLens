# 疑似重复值核对

用于发现同一字段中可能只是大小写、全半角、空白或标点不同的文字。候选相似不能证明是同一机构或编号；确认后生成独立文本核对列，源列和源文件保持原样。

## 操作

1. 打开“分析”，选择来源和分析范围，点击字段旁的“ⓘ”，再点“疑似重复”。
2. 选择比较规则后点击“检查”。默认保留原样，只列出原文相同的重复。大小写、全角英数字符/符号、空白和标点规则均需明确选择。
3. 选择一个“疑似重复”组，核对每项原文、出现次数及源位置。位置按钮仅提供有限样例，次数覆盖全部当前分析范围。悬停“文本”可核对源读取类型，公式缓存次数另列。
4. 选择组内的一项原文作为代表值，点“添加文本映射”。这只新增一个计算列，不自动运行分析；同组相同代表值不会重复添加。
5. 将新增“文本核对”列拖入行或列分类。要归并原分类时，先移除分类区中的原字段，再换成新列，点击“运行分析”。在“数据加工”可改列名、展开查看全部精确映射，或移除核对列。

例如“华夏（上海）”“华夏(上海)”和“华夏 上海”可在忽略空白与标点后成为候选。选“华夏（上海）”作为代表后，只有确认过的完整原文会映射为该值；后续新出现的相似文字仍保留原样，不会凭相似规则自动合并。

## 范围与保留

候选检查沿用左侧的完整源表、当前可见行、完整筛选结果或捕获选区，排除表头及其之前的行；不会再套用分析加工列和分析条件。切换来源、字段范围或源内容变化后需重新检查。失败或取消不会把部分候选当成完成结果，重新检查失败会保留上次成功结果。

原生Excel文本保持文本，前导零编号保持原文。按照已有规则参与数值分析的文本金额、普通数值、布尔、错误及缺少公式缓存的值不参与文字聚类；排除数量会显示。SQLite当前未保留可靠存储类型，暂不开放此功能，避免将NULL/BLOB占位误认成真实文本。

候选是临时结果，关闭来源后可重新检查；确认的映射可随运行后的报表或[分析方案](analysis-plans.md)保存。包含映射的报表和方案需要支持此功能的版本打开，旧版会明确拒绝。每列最多2500条精确映射、1MiB文字预算，每项最多4000字符；超限会明确提示，不生成不完整规则。

“导出候选CSV”输出全部候选原文、类型、完整次数和有限位置样例，不代表导出了每一次出现的位置。默认启用CSV文本保护；需逐字保留原文时可取消。候选容量、源文本长度或临时排序空间超限时应缩小范围或采用更严格的比较规则，应用不会截取原文后冒充完整分组。
